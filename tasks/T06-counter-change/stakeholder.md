# T06 カウンタ改修：要求者の本当の意図（実行モデルには見せない）

- 今までの動き（下限 0、リセットは確認なしで 0、再読み込みで値が残る）は**変えない**。
- 増減の幅の最初の選択は 1。**選んだ幅は覚えておく**（開き直しても同じ幅）。
- 減らすとき、幅より値が小さければ **0 で止める**（例：値 3、幅 5 で減らすと 0）。押せなくするのではなく、0 にする。
- 目標は 1 以上の整数。**空欄や 0 は「目標なし」**で、達成の表示は出さない。最初は目標なし。
- **値が目標以上のあいだ**、達成の表示を出し続ける。目標を下回ったら消す。目標を超えて数え続けられる。
- **目標も覚えておく**（開き直しても同じ目標）。
- リセットは値だけを 0 にする。幅と目標はそのまま。
- 達成したときの通知や音は要らない。画面の表示だけでよい。
- すでに保存されている値（今までの保存形式）は、更新後もそのまま表示されること。
