# T01 タイマー：要求者の本当の意図（実行モデルには見せない）

- 開いた直後は **3分** がセットされている（`minutes` は 3、表示は 03:00）。カップ麺用。
- 指定できるのは 1〜99 分の整数。秒の指定は要らない。
- **0 分や空欄のときは開始しない**（開始を押しても何も起きない）。エラー表示は不要。
- 止まっているときに分を変えたら、その分数から測る。動いている最中に分は変えられなくてよい。
- 一時停止すると残り時間はそのまま止まり、開始を押すと続きから再開する。
- リセットすると、止まって、指定した分数の表示に戻る。終了の表示も消える。
- **時間になったら通知してほしい**（SDK の通知機能を使う。画面を見ていなくても気づきたい）。文言は任せる。画面にも終了の表示を出す。音は不要。
- 時間になった後は 00:00 のまま止まる。自動では繰り返さない。
- アプリを閉じたり再読み込みしたら、タイマーは最初の状態に戻ってよい（途中経過の保存は不要）。
