# T08 読書記録：要求者の本当の意図（実行モデルには見せない）

- **題名は必須。** 空欄（空白だけも含む）では保存せず、メッセージ（トースト）で知らせる。フォームは開いたまま。
- 新しく登録するときの状態の初期値は「読みたい」。
- 一覧は**新しく登録した本が一番上**。編集しても順番は変わらない。
- **評価と感想は「読んだ」の本だけのもの。** 状態が「読んだ」以外のときは評価と感想の欄は使えない（無効か非表示）。「読んだ」から他の状態に戻して保存したら、**評価は消える**（一覧に★を出さない）。
- 評価は任意（「読んだ」でも評価なしでよい）。感想も任意。
- **キャンセルしたら、入力した内容は捨てる**（本は追加も変更もされない）。
- **削除は確認してから**消す。
- 絞り込みの最初は「すべて」。**選んだ絞り込みは覚えなくてよい**（開き直したら「すべて」）。
- 件数は、絞り込んだ後に表示されている本の数。
- 表紙は撮り直せる。写真を外す機能は要らない。写真の大きさは SDK の既定でよい。
- 感想は一覧には出さなくてよい（編集フォームで読めれば十分）。
- 同じ題名の本を複数登録できてよい。
