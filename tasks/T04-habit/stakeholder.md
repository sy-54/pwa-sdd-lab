# T04 習慣トラッカー：要求者の本当の意図（実行モデルには見せない）

- 連続日数の数え方：
  - 今日チェック済みなら、**今日を含めて**さかのぼった連続日数。
  - **今日まだチェックしていなくても、昨日までの連続は途切れていない扱い**にして、昨日までの連続日数を表示する（夜にチェックするので、日中に 0 に見えると悲しい）。
  - 昨日もやっていなければ 0。
  - 今日のチェックを外したら、昨日までの連続日数に戻る。
- 日付の変わり目は端末の時刻で深夜 0:00。
- 日付が変わると「今日やった」のチェックは外れた状態から始まる（アプリを開き直したときに反映されていればよい）。
- 追加した直後の習慣は、未チェックで連続 0 日。新しい習慣は一番下に追加する。
- **同じ名前の習慣は追加できない**。空欄も追加しない。どちらもエラー表示は簡単でよい（なくてもよい）。
- **削除は確認してから**消す（記録が消えるので）。
- 習慣の名前の変更、並べ替えは要らない。
