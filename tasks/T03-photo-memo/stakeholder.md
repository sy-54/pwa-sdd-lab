# T03 写真メモ：要求者の本当の意図（実行モデルには見せない）

- **新しい写真が一番上**に来る（撮った直後に目に入るように）。
- 一言メモは、**入力したら自動で保存**される。保存ボタンは要らない。後からいつでも書き換えられる。メモは空でもよい。
- **削除は確認してから**消してほしい（間違えて消すと取り返しがつかない）。確認でキャンセルしたら何も変わらない。
- 撮影をキャンセルしたら何も追加しない。
- 写真の大きさは標準（SDK の既定）でよい。枚数の上限は気にしない。
- 撮影日時の表示は、あってもなくてもよい。
- 写真をタップして拡大する機能は要らない。
- カメラが使えないなどのエラーは、簡単なメッセージが出れば十分。
