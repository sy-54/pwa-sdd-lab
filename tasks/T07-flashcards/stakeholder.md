# T07 単語帳：要求者の本当の意図（実行モデルには見せない）

- **出題の順番は登録した順**。シャッフルはしない（順番で覚えたいので）。
- 「まだ」にしたカードは、**その回の列の一番後ろ**に回す。残りのカードが全部出た後に、もう一度出る。
- **「覚えた」「まだ」は、めくって裏を見てからでないと押せない**（めくる前は押しても何も起きない、または押せない）。
- カードが **1枚もないときは学習を始められない**（押しても何も起きない。メッセージはあってもなくてもよい）。
- **表か裏が空欄のカードは追加しない。** 前後の空白は取り除く。追加したら両方の入力欄を空にする。
- 一覧のカードは登録した順（新しいカードが下）。
- **カードの削除は確認なしで即座に消す。**
- 学習の途中でアプリを閉じたり再読み込みしたら、一覧に戻ってよい（途中経過は保存しない）。
- 結果の「1回で覚えた枚数」は、一度も「まだ」を押さずに「覚えた」にしたカードの数。
- 学習中、一覧の入力欄やカードは見えなくてよい（学習画面だけにする）。
- 同じ表のカードが複数あってもよい。
