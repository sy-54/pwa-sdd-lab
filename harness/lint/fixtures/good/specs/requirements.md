# カウンタ 要求仕様

> 数を数えるだけのミニアプリ。
> ボタンで増減し、値は端末に保存する。
> サーバーは使わない。

目的：回数を手早く数えて、あとで見返せるようにする。
利用者：本人（個人利用）。

## Must
- ボタンで数を増やす・減らすことができる
- 値をリセットできる
- 再読み込みしても値が残る

## Should
- 大きい文字で見やすい

## Won't
- 複数カウンタ、履歴

## 制約
- iOS Safari で動く。静的ファイルのみ

## UI契約
- エントリ：`apps/counter/index.html`
- ルート要素：`data-testid="app-root"`
- 値：`data-testid="count"`、操作：`inc` / `dec` / `reset`

## 改訂履歴
- 下限を 0 にした（壁打ちで決定）。負数は不要だった
- 次回：保存の要否は最初から Must に書く
