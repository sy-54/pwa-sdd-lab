# カウンタ 外部仕様

> 1画面。＋／−／リセットの3ボタンと現在値だけ。
> 値は 0 以上の整数で、端末に保存し再読み込み後も復元する。
> 未決事項なし。

## 画面と操作
- 現在値（`count`）を中央に大きく表示する
- `inc` で +1、`dec` で −1、`reset` で 0 にする

## 振る舞い
- 初回の値は 0
- 操作のたびに保存し、起動時に復元する
- 値が 0 のとき `dec` は無効（disabled）

## エラー時の挙動
- 保存値が壊れている（数値でない・負数）ときは 0 から始める
- 保存に失敗しても画面の値は更新する（エラー表示はしない）

## 受け入れ条件
### AC-01: 増やす
- Given 値が 0
- When `inc` を2回押す
- Then `count` は 2

### AC-02: 0未満にしない
- Given 値が 0
- When 画面を見る
- Then `dec` は disabled

### AC-03: リセット
- Given 値が 3
- When `reset` を押す
- Then `count` は 0

### AC-04: 復元
- Given 値が 2
- When 再読み込みする
- Then `count` は 2

- D2: リセットに確認ダイアログは出さない（Q2）
