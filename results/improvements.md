## 改善の記録

改善のたびに1行追加する。形式：`日付 [分類] 何を変えたか ← きっかけ（実行IDや課題）`。分類は スキル / SDK API / 検証 / モデルの限界。

- 11/14 [スキル] 02-design に「環境依存の機能はテスト環境で確かめられるかを対応表に書く」を追加 ← platform 開発（WebKit のテスト環境では IndexedDB に Blob を直接保存できず、Notification も未対応で、設計を途中で直した）
- 11/14 [スキル] 03-tasks に「不確かな技術要素は早いタスクで確かめる」「人間の作業もタスクに書く」を追加 ← platform 開発（Service Worker のオフライン確認を T11 に置いたが、動かなければ設計変更が大きかった）
- 11/14 [スキル] 04-impl に「設計どおり動かないと分かったら先に design/spec の該当行を直す」を追加 ← platform 開発（Blob の保存形式、iOS のエクスポート方法）
- 11/14 [スキル] 05-e2e に「画面のない AC はコマンド実行で確かめる」「時間依存は page.clock を使う」を追加 ← platform AC-13、課題 T01/T04 の準備
- 11/14 [スキル] 01-spec に「環境の制約でできないことは質問の選択肢で伝える」を追加 ← platform の通知（iOS ではサーバーなしの時刻指定通知ができない）
- 11/14 [検証] 静的サーバーに `/__health` を追加 ← ルートに index.html がないと Playwright の起動待ちがタイムアウトし、隠しE2E が 0/0 になった
