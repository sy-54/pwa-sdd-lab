# 写真メモ 外部仕様

> 写真を撮ってメモと一緒に保存し、一覧で見返すことができる。削除も可能。
> 新しく撮った写真がリストの上に表示され、アプリを閉じても データは残る。
> すべての仕様が確定。レビューで確認：UI契約の data-testid と AC の対応が正しいか。

## 画面と操作

### 初期画面
- ヘッダー：SDK の標準ヘッダー（`sdk-header`）を表示
- ボタン「撮影」：`data-testid="shoot"`（ボタン）、押すとカメラを起動
- 写真がある場合：メモ一覧を表示
- 写真がない場合：`data-testid="memo-empty"` に「📷 写真がありません」と表示

### メモ一覧
- 各メモ：`data-testid="memo-item"`（div または li）
  - 画像：`data-testid="memo-img"`（img タグ、撮影した写真を表示）
  - 説明文：`data-testid="memo-caption"`（input type="text"、メモのテキスト）
  - 削除ボタン：`data-testid="memo-delete"`（button class="danger"）
- 一覧の並び順：新しい順（最後に撮った写真が上に表示される）

## 振る舞い

- **撮影処理**
  - 「撮影」ボタンを押すと、SDK の `camera.takePhoto({ maxSize: 1280 })` でカメラを開く
  - 写真を選ぶと、その写真と空のメモ（初期値：空白）で新しいアイテムを作成し、リストの先頭に追加する
  - キャンセルした場合は何もしない
  - 撮影後の写真は Blob のまま保存し、表示時は `URL.createObjectURL(blob)` で表示

- **メモ編集**
  - 各メモの `memo-caption` に直接テキストを入力できる
  - 入力した内容は、edit イベント後に自動で storage に保存される
  - 長い文字列でも全て保存できる（上限なし）

- **削除処理**
  - 削除ボタンを押すと、`ui.confirm("このメモを削除しますか？", { ok: "削除", cancel: "キャンセル" })` で確認ダイアログを表示
  - 「削除」を選ぶと、該当のメモを storage から削除
  - 削除後、一覧から該当アイテムが消える
  - 「キャンセル」を選ぶと何もしない

- **保存と復元**
  - 写真とメモは `storage.set('memos', [...])` で array として保存される
  - array の各要素は `{ blob, caption }` の形式
  - アプリを閉じて開き直すと、storage から復元される
  - 保存データが壊れた場合は、空の配列として扱う

- **空のメモ一覧**
  - 写真がない場合は `memo-empty` を表示、写真がある場合は非表示にする

## エラー時の挙動

- **撮影キャンセル**：カメラを起動した後にキャンセルボタンを押した場合、`camera.takePhoto` は `null` を返す。何もしない。

- **壊れた保存データ**：storage から読み込んだデータが配列でない、または要素に `blob` や `caption` がない場合は、警告なしに空の配列として扱い、以降は正常なデータとして保存する。

- **ストレージ容量満杯**：写真の保存に失敗した場合（`storage.set` が例外を投げた場合）、toast で「保存に失敗しました」と表示し、アイテムは一覧から除去しない。

## 受け入れ条件

### AC-01: 撮影ボタンが表示される
- Given 初期状態
- When ページを開く
- Then 「撮影」ボタン（`data-testid="shoot"`）が表示される

### AC-02: 写真がないときは空状態を表示
- Given 初期状態で写真が0件
- When ページを開く
- Then `data-testid="memo-empty"` に「📷 写真がありません」と表示され、メモ一覧は表示されない

### AC-03: 写真を撮影して保存
- Given 初期状態
- When 「撮影」ボタンを押して、テスト画像を選択する
- Then `data-testid="memo-item"` が1件表示され、その中の `data-testid="memo-img"` に選択した画像が表示される

### AC-04: 新しく撮った写真が先頭に表示される
- Given メモが1件保存されている（caption: "テスト1"）
- When 「撮影」ボタンを押して新しい写真を選択する
- Then 新しいメモが `memo-item` の1番目に表示され、前のメモが2番目に表示される

### AC-05: メモを編集して保存
- Given メモが1件表示されている
- When 該当メモの `memo-caption` に「駐車場 B5」と入力
- Then input に「駐車場 B5」が表示される

### AC-06: アプリを閉じて開き直すと写真とメモが残る
- Given メモ1件が保存されている（caption: "テスト1"）
- When アプリを閉じて再度開く
- Then 同じメモが表示される

### AC-07: 削除時に確認ダイアログが出る
- Given メモが1件表示されている
- When 該当メモの `data-testid="memo-delete"` ボタンを押す
- Then 確認ダイアログに「このメモを削除しますか？」と表示される

### AC-08: 削除確認で「削除」を選ぶとメモが消える
- Given 確認ダイアログが表示されている
- When 「削除」ボタンを押す
- Then メモが一覧から消える

### AC-09: 削除確認で「キャンセル」を選ぶとメモが残る
- Given 確認ダイアログが表示されている
- When 「キャンセル」ボタンを押す
- Then メモが一覧に表示されたままである

### AC-10: 複数のメモが新しい順で表示される
- Given メモが3件保存されている（時系列：メモA → メモB → メモC）
- When ページを開く
- Then メモの順序は C, B, A である
