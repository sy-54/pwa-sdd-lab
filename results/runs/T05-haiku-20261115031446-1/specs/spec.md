# 支出メモ 外部仕様

> 金額と分類を入力して記録し、今月の出費と分類ごとの合計を表示する
> 記録は新しい順で表示され、削除時は確認ダイアログで確認
> 全ての曖昧さが Q1-Q5 で決定

## 画面と操作

- 置くファイル：`apps/expense/index.html`、`apps/expense/manifest.json`
- ルート要素：`data-testid="app-root"`
- 入力フォーム
  - 金額入力：`data-testid="amount"`（`input`、初期値空、プレースホルダ「金額」推奨）
  - 分類選択：`data-testid="category"`（`select`、初期値 `food`、選択肢は `food` / `daily` / `transport` / `other`。表示名は「食費」「日用品」「交通」「その他」）
  - 追加ボタン：`data-testid="add"`（押下可能な状態は常時、ただし無効な金額の場合は追加されない）
- 記録一覧（新しい順）
  - 各記録：`data-testid="expense-item"`
    - 金額表示：`data-testid="expense-amount"`（3桁区切りのカンマ、例 `1,200`）
    - 分類表示：`data-testid="expense-category"`（表示名「食費」「日用品」「交通」「その他」）
    - 削除ボタン：`data-testid="expense-delete"`
- 合計表示
  - 今月の合計：`data-testid="total"`（3桁区切りのカンマ、例 `1,200`）
  - 分類ごとの今月の合計（Should）：各分類の合計を見えやすく表示

## 振る舞い

- **初期状態**：金額入力は空、分類は「食費」を選択
- **記録追加**：有効な金額（正の整数、0除く）と分類を入力して追加ボタンを押すと、記録が一覧の一番上に追加される。追加後、金額入力は空にリセット、分類は「食費」に戻る
- **一覧の並び順**：新しい記録が一番上。古い記録は下へ
- **保存**：記録は `storage` へ保存。アプリを閉じて再起動しても記録が残る
- **今月の範囲**：端末の今日の日付から今月の記録のみを表示し、合計を計算。表示のたびに今の日時から計算し直す（月が変わると自動的に前月の記録は表示されなくなる）
- **分類ごとの合計**：今月の記録の中で、各分類（食費・日用品・交通・その他）の合計を計算して表示

## エラー時の挙動

- **金額が空・0・負数・小数点を含む場合**：追加ボタンを押しても追加されず、トースト（`sdk-toast`）で「有効な金額を入力してください」などのメッセージを表示。データは変更されない
- **100万円以下を想定した大きな数**：通常どおり追加される。上限は特に設けない

## 受け入れ条件

### AC-01: 初期状態
- Given アプリを起動したときの初期状態
- When 画面を確認
- Then `amount` は空、`category` は `food`（「食費」）が選択

### AC-02: 有効な金額を入力して追加
- Given 金額が 1000、分類が `food`（初期値）
- When `add` ボタンを押下
- Then `expense-item` に1件の記録が表示され、`expense-amount` に `1,000`、`expense-category` に「食費」が表示される

### AC-03: 新しい記録が一番上に表示
- Given 記録が2件以上存在（1件目は 1000 `food`、2件目は 2000 `daily`）
- When 2件目を追加した後に画面を確認
- Then 2件目が一番上（`expense-item` の最初）に表示される

### AC-04: 今月の合計が表示される
- Given 記録が2件（1000 `food`、2000 `daily`）
- When 画面を確認
- Then `total` に `3,000` が表示される

### AC-05: 分類ごとの今月の合計が表示される（Should）
- Given 記録が複数（1000 `food`、2000 `daily`、500 `transport`、1500 `other`）
- When 画面を確認
- Then 各分類の合計が見えやすく表示（食費 1000、日用品 2000、交通 500、その他 1500）

### AC-06: 削除前に確認ダイアログが出る
- Given 記録が1件以上存在
- When `expense-delete` ボタンを押下
- Then 確認ダイアログ（`sdk-confirm-ok` / `sdk-confirm-cancel`）が表示される

### AC-07: ダイアログで削除を確認
- Given 確認ダイアログが表示されている
- When `sdk-confirm-ok` を選択
- Then 記録が削除され、一覧から消える

### AC-08: ダイアログでキャンセル
- Given 確認ダイアログが表示されている
- When `sdk-confirm-cancel` を選択
- Then 記録は削除されず、一覧に残る

### AC-09: 金額が空のときは追加されない
- Given 金額が空、分類が `food`
- When `add` ボタンを押下
- Then 記録が追加されず、トースト（`sdk-toast`）でメッセージが表示される

### AC-10: 金額が0のときは追加されない
- Given 金額が `0`、分類が `food`
- When `add` ボタンを押下
- Then 記録が追加されず、トースト（`sdk-toast`）でメッセージが表示される

### AC-11: 金額が負数のときは追加されない
- Given 金額が `-100`、分類が `food`
- When `add` ボタンを押下
- Then 記録が追加されず、トースト（`sdk-toast`）でメッセージが表示される

### AC-12: 金額に小数点を含むときは追加されない
- Given 金額が `100.5`、分類が `food`
- When `add` ボタンを押下
- Then 記録が追加されず、トースト（`sdk-toast`）でメッセージが表示される

### AC-13: 大きな数も追加される
- Given 金額が `1000000`（100万円）、分類が `food`
- When `add` ボタンを押下
- Then 記録が追加され、`expense-amount` に `1,000,000` が表示される

### AC-14: 記録が保存される
- Given 記録が1件追加されている
- When アプリを閉じて再起動
- Then 記録が残っており、一覧に表示される

### AC-15: 月が変わると今月のデータを再計算
- Given 今月の記録が複数件存在
- When 時間が進んで翌月になり、アプリを再起動
- Then 前月の記録は表示されず、今月のデータのみが表示される（今月の記録がなければ一覧は空、合計は 0）

## 決定事項

- D1: 空・0・負数・小数点のときは追加せず、トーストメッセージで知らせる。100万円以下を想定で上限なし（Q1）
- D2: 分類は初期値「食費」（`food`）。金額が無効なときはトーストメッセージで知らせる（Q2）
- D3: 新しい記録が一番上に表示される（新しい順）（Q3）
- D4: 削除時に確認ダイアログを表示（Q4）
- D5: 「今月」の計算は表示のたびに今の日時から計算し直す。表示は常に端末の今日時点の「今月」のデータのみ（Q5）
