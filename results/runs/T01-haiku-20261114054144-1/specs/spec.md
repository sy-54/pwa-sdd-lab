# タイマー 外部仕様

> 1〜99分を指定してカウントダウン。開始・一時停止・リセット・終了通知。
> 初期値3分。常に大きく表示。保存なし。
> 料理中に片手で使う。

## 決定事項

D1: 分の入力は1〜99分の整数。初期値3分。（Q1）

D2: 0分・空欄の状態で開始ボタンを押しても何も起きない。エラー表示なし。（Q2）

D3: リセット時に確認ダイアログを出さない。即座にリセット。（Q3）

D4: 時間になったら SDK の通知機能を使う。失敗時はトースト。画面にも終了表示を出す。（Q4）

D5: ブラウザ再読み込みで状態は復旧しない。初期状態になる。（Q5）

## 未決事項

なし

## 画面と操作

### 初期状態
- 分の入力フィールド：`data-testid="minutes"`（`input type="number"`）。初期値 3、最小 1、最大 99。
- 残り時間表示：`data-testid="time"`（`MM:SS` 形式。初期表示 `03:00`）。大きく表示（`.big` クラス使用）。
- 開始ボタン：`data-testid="start"`（常に表示）。開始・再開の兼用。
- 一時停止ボタン：`data-testid="pause"`。実行中のみ有効・目立つ。
- リセットボタン：`data-testid="reset"`。実行中・一時停止中のみ有効。
- 終了表示：`data-testid="done"`。時間になったときだけ表示（通常は `hidden`）。

## 振る舞い

### 初期状態
- 表示：分入力欄に 3、残り時間に `03:00`。
- 開始ボタンのみ有効。一時停止・リセットボタンは無効（`disabled`）。

### 開始直後
- 分入力欄を無効化（`disabled`）。
- カウントダウン開始。毎秒更新。
- 残り時間を `MM:SS` で表示（例 `02:59`, `00:01`）。
- 開始ボタンを無効化。
- 一時停止ボタンを有効化。
- リセットボタンを有効化。

### 実行中
- 毎秒 1 秒減算。
- 残り時間を `MM:SS` で更新。

### 一時停止
- 一時停止ボタン押下で、カウントダウン停止。
- 開始ボタン文言は「再開」のままを想定（テキスト変更は UI 契約にないので不要）。
- 開始ボタンを有効化（再開可能に）。

### リセット
- リセットボタン押下で、直ちに初期状態に戻す。
- 残り時間を `03:00` に戻す。
- 分入力欄を有効化。
- 開始ボタンのみ有効。

### 0 秒に到達
- カウントダウン停止。
- 残り時間を `00:00` で固定。
- 開始・一時停止・リセット全ボタンを無効化。
- SDK `notify.send` で通知を送信。送信可否に関わらず、画面上に `done` 要素を表示。
- ユーザーが手動でリセットするまで、タイマー表示は `00:00` で固定。

### 不正な入力
- 分の入力欄で 0 以下や空欄の状態のまま開始ボタンを押しても、何も起きない。カウントダウン開始なし。

## エラー時の挙動

- 通知送信失敗：SDK が自動的にトーストで代替。アプリ側は追加処理不要。
- 保存：保存なし（再読み込みで初期状態）。

## 受け入れ条件

### AC-01: 初期表示
- Given アプリを開いた直後
- When 何もしない
- Then `time` に `03:00`、`minutes` に 3、ボタンは `start` のみ有効

### AC-02: 開始から経過表示
- Given 初期状態で `minutes` に 3
- When `start` ボタンを押してから 2 秒経過
- Then `time` に `02:58` と表示

### AC-03: 一時停止と再開
- Given タイマー実行中で `time` に `01:30`
- When `pause` ボタンを押す
- Then カウントダウンが止まり、`time` は `01:30` のまま

### AC-04: 再開
- Given タイマーが `01:30` で一時停止中
- When `start` ボタンを押す
- Then カウントダウンが再開

### AC-05: リセット
- Given タイマーが `00:45` で実行中
- When `reset` ボタンを押す
- Then `time` が `03:00`、`minutes` が有効に戻り、ボタンは `start` のみ有効

### AC-06: 0 秒到達時の終了表示
- Given カウントダウンが実行中で 1 秒以下
- When 1 秒経過
- Then `time` が `00:00`、`done` が表示される

### AC-07: 通知送信
- Given カウントダウンが 0 秒に到達
- When 状態が遷移
- Then SDK `notify.send` が呼ばれ、通知またはトーストで知らせが表示

### AC-08: 0 分での開始禁止
- Given `minutes` に 0
- When `start` ボタンを押す
- Then カウントダウンが開始せず、画面状態は変わらない

### AC-09: 終了後のリセット
- Given タイマーが終了し `time` に `00:00`、`done` が表示されている
- When `reset` ボタンを押す（有効化後）
- Then 初期状態に戻る
