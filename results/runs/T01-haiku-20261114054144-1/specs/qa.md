# 質問

Q1: 分の入力に上限値はあるか。また初期値は。
- A: 上限値なし（テキスト削除まで）、初期値は 0
- B: 上限値 99 分、初期値は 0
- C: 上限値 60 分、初期値は 1

Q2: 0 分以下の入力（0、負の数）を入力フィールドで受け付けるか。
- A: 受け付けない（min=1 で禁止）
- B: 受け付けるが、開始時に1分以上の入力を促すトースト表示
- C: 受け付けて開始時にそのまま実行

Q3: 実行中のタイマーをリセット時、確認ダイアログを出すか。
- A: 出さない（即座にリセット）
- B: 出す（UI.confirm で確認）

Q4: 「時間になったら知らせる」を実現する手段は。
- A: OS 通知（notify.send）、出せなければトースト
- B: トースト表示のみ

Q5: ブラウザを再読み込みしたとき、実行中のタイマー状態を復旧するか。
- A: 復旧する（最後の分数と経過時間を保存）
- B: 初期状態になる（保存しない）
