# 習慣トラッカー 外部仕様

> 習慣を名前で追加・削除し、毎日「今日やった」をチェックする一覧アプリ。
> 連続日数は「チェックした瞬間」に確定し、未チェックの日は前日までの値を表示したまま変化しない。
> 未決事項なし。重複名・空欄入力・削除確認の挙動を決定事項にまとめた。

## 画面と操作
- `apps/habit/index.html`（`apps/habit/manifest.json` も置く）。ルートは `data-testid="app-root"`。
- 入力欄 `new-habit` と追加ボタン `add-habit`。追加に成功したら入力欄を空にする。
- 一覧は `habit-item` の繰り返し。各 `habit-item` の中に：
  - `habit-name`：習慣名のテキスト
  - `habit-check`：`input type="checkbox"`。今日やったかどうか
  - `habit-streak`：連続日数。数字のみのテキスト
  - `habit-delete`：削除ボタン
- チェック済みの `habit-item` には class `done` を付け、未チェックと見た目で区別する（Should）。

## 振る舞い
- 習慣追加：名前を1件ずつ一覧の末尾に追加する。追加直後は未チェック・連続日数0。
- 日付の判定は端末のローカル日付（日単位）で行う。
- 連続日数は「チェックした日」の積み重ねで決まり、未チェックの間は値が変わらない：
  - チェックする：直前にチェックした日が「前日」なら連続日数に1加える。前日より前に空きがある、または初回なら連続日数を1にする。
  - チェックを外す：チェックする直前の連続日数・直前チェック日に戻す（1回分の取り消し）。
  - 今日まだチェックしていない間は、前日まで積み上げた連続日数をそのまま表示する（日付が変わって新しい「今日」になっても、次にチェックするまで値は変わらない）。
- 保存：習慣の名前・チェック状態・連続日数・直前チェック日は `storage` に保存し、再読み込み後も復元する。

## エラー時の挙動
- 入力欄が空、または空白文字のみで追加ボタンを押した場合：何も追加されず、入力欄の内容もそのまま。
- 既存の習慣と同じ名前で追加しようとした場合：追加されない（エラー表示の有無は問わない簡易な扱いでよい）。
- 削除ボタンを押すと `ui.confirm` で確認し、OK のときだけ削除する。キャンセル時は何も変わらない。
- 保存データが壊れている（配列でない等）場合は、空の一覧として起動する。

## 受け入れ条件
### AC-01: 習慣を追加する
- Given 一覧が空
- When `new-habit` に「筋トレ」を入力し `add-habit` を押す
- Then 一覧の末尾に `habit-item` が1件追加され、`habit-name` は「筋トレ」、`habit-streak` は `0`、`new-habit` は空になる

### AC-02: 空欄では追加されない
- Given 一覧が空
- When `new-habit` が空のまま `add-habit` を押す
- Then `habit-item` は追加されない

### AC-03: 重複名では追加されない
- Given 「読書」という `habit-item` が1件ある
- When `new-habit` に「読書」を入力し `add-habit` を押す
- Then `habit-item` は増えず1件のまま

### AC-04: チェックすると連続日数が増える
- Given 「読書」の `habit-streak` が `3`（前日までチェック済み、今日は未チェック）
- When 「読書」の `habit-check` をチェックする
- Then `habit-streak` が `4` になる

### AC-05: 空いた後のチェックは1から再スタート
- Given 「読書」の `habit-streak` が `3`（直前のチェック日は2日以上前）
- When 「読書」の `habit-check` をチェックする
- Then `habit-streak` が `1` になる

### AC-06: チェックを外すと元に戻る
- Given 「読書」の `habit-streak` が `3`、前日チェック済みの状態からチェックして `4` になった直後
- When `habit-check` のチェックを外す
- Then `habit-streak` が `3` に戻る

### AC-07: 未チェックの日は値を保つ
- Given 「読書」の `habit-streak` が `3` で今日は未チェック
- When 画面を再読み込みする
- Then `habit-streak` は `3` のまま、`habit-check` は未チェック

### AC-08: 削除は確認後に実行される
- Given 「読書」の `habit-item` が1件ある
- When `habit-delete` を押し、確認ダイアログで OK を押す
- Then その `habit-item` が一覧からなくなる

### AC-09: 削除確認をキャンセルすると消えない
- Given 「読書」の `habit-item` が1件ある
- When `habit-delete` を押し、確認ダイアログでキャンセルを押す
- Then `habit-item` は1件のまま残る

### AC-10: 再読み込みしても記録が残る
- Given 「読書」を追加しチェックして `habit-streak` が `1` になった
- When 画面を再読み込みする
- Then `habit-item` が1件あり、`habit-name` は「読書」、`habit-check` はチェック済み、`habit-streak` は `1`

### AC-11: 未チェックは見分けやすい
- Given 「読書」（チェック済み）と「筋トレ」（未チェック）が1件ずつある
- When 一覧を見る
- Then 「読書」の `habit-item` には class `done` が付き、「筋トレ」の `habit-item` には付かない

## 決定事項
- D1: 今日未チェックのときは前日までの連続日数をそのまま表示し、チェックで+1する（R1-Q1）
- D2: 1日以上空いた後にチェックすると連続日数は1から再スタートする（R1-Q2）
- D3: 新しい習慣は一覧の末尾に追加する（R1-Q3）
- D4: 同じ名前の習慣は追加できない。エラー表示は簡易でよい（R1-Q4）
- D5: 見分けやすさは `habit-item` に class `done` を付ける方式にする（R1-Q5）
- D6: 削除は `ui.confirm` で確認してから行う（R2-Q1）
- D7: 空欄・重複での追加失敗時、エラー表示は不要。入力欄はそのまま残す（R2-Q2）
