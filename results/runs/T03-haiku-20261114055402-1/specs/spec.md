# 写真メモ 外部仕様

> 写真を撮ってメモを付けて一覧で見るアプリ。新しい順に表示し、削除時は確認する。
> 写真とメモはペアで保存され、撮影・編集・削除できる。
> 未決事項なし。SDK の camera と storage を使う。

## 画面と操作

**全体**
- ルート要素：`data-testid="app-root"`
- 撮影ボタン：`data-testid="shoot"`（最上部。写真を撮影できる）
- 写真リスト：複数の写真アイテムを縦に並べる
- 空表示：`data-testid="memo-empty"`（写真が1枚もないときだけ表示。「写真がありません」など）

**各写真アイテム**
- 親要素：`data-testid="memo-item"`（1つの写真単位）
  - 写真画像：`data-testid="memo-img"`（`<img>` 要素。撮った JPEG を表示）
  - メモテキスト：`data-testid="memo-caption"`（`<input type="text">`。初期値は空）
  - 削除ボタン：`data-testid="memo-delete"`（ボタン。削除を実行する）

## 振る舞い

**初期状態と読み込み**
- アプリ起動時、保存されている写真とメモを読み込む。初回起動は空。
- 写真がなければ、`memo-empty` を表示し、メモアイテムは表示しない。

**撮影**
- `shoot` を押すと、カメラが起動し、写真が撮れる。
- 撮影後、新しい写真が最上部に1つ追加される（新しい順）。
- `memo-empty` は非表示になる。
- 撮影をキャンセルした場合、何も起きない。

**メモの編集**
- `memo-caption` に文字を入力できる。
- メモの内容は自動で保存される（入力の直後、またはフォーカスアウト時）。

**削除**
- `memo-delete` を押すと、削除確認ダイアログが表示される（文言：「削除しますか？」など）。
- ユーザーが「OK」を選ぶと、その写真とメモが削除される。
- 「キャンセル」を選ぶと、何も起きない。
- 最後の写真を削除したとき、`memo-empty` が表示される。

**保存と復元**
- 写真とメモは `storage` に保存される。
- アプリを閉じて開き直しても、撮った写真とメモが残る。
- 各写真には一意の ID が付き、メモと対応付けられる。

## エラー時の挙動

- 撮影に失敗した場合、ユーザーには通知で「撮影に失敗しました」と伝える。リストは変わらない。
- 保存に失敗した場合、ユーザーには通知で「保存に失敗しました」と伝える。ただし、保存失敗時の復旧仕様は定めない（SDK に委ねる）。
- カメラが利用できない環境では、撮影ボタンは機能しない（アプリから通知で伝える）。

## 受け入れ条件

### AC-01: 初期状態で空表示
- Given アプリ初回起動
- When 画面を表示
- Then `memo-empty` が表示され、`memo-item` は0個

### AC-02: 写真を撮影して一覧に追加
- Given `memo-item` が0個の状態
- When `shoot` を押して写真を撮影
- Then `memo-item` が1個表示され、その中の `memo-img` に撮った写真が表示される

### AC-03: 新しい順に表示
- Given 写真が2枚以上ある状態
- When 新しい写真を撮影
- Then その写真が最上部の `memo-item` に表示される

### AC-04: メモを入力して自動保存
- Given `memo-item` がある状態
- When `memo-caption` に「駐車場 3階」と入力
- Then その `memo-caption` の値が「駐車場 3階」で保存される

### AC-05: 削除確認ダイアログ
- Given `memo-item` がある状態
- When その `memo-delete` を押す
- Then 確認ダイアログが表示される

### AC-06: 削除実行
- Given 確認ダイアログが表示されている状態
- When 「OK」を選ぶ
- Then その `memo-item` が削除される

### AC-07: 削除キャンセル
- Given 確認ダイアログが表示されている状態
- When 「キャンセル」を選ぶ
- Then ダイアログが閉じられ、`memo-item` は残る

### AC-08: 最後の写真削除で空表示
- Given `memo-item` が1個
- When その `memo-delete` を押して削除を確認
- Then `memo-empty` が表示される

### AC-09: 再起動後もデータ残存
- Given 写真とメモが保存されている状態
- When アプリを完全に閉じて再度開く
- Then 保存されていた写真とメモが表示される

### AC-10: 撮影キャンセル
- Given `shoot` を押してカメラが起動している状態
- When キャンセルを選ぶ
- Then リストは変わらない

## 決定事項
- D1: メモ保存は自動で実行（入力直後またはフォーカスアウト時の技術判断）（Q1）
- D2: 写真は新しい順に表示（Q2）
- D3: 削除時に確認ダイアログを表示（Q3）

- なし
