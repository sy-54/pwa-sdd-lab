# 読書記録 外部仕様

> 本を登録して、読みたい・読んでいる・読んだの状態を管理。読んだ本には評価と感想を残す。
> 表紙の写真も付けられ、状態で絞り込んで表示。すべてのデータはアプリ内に保存される。
> 決定事項は全9項目。不確定な部分はなし。

## 画面と操作

- 配置：`apps/books/index.html`、`apps/books/manifest.json`
- ルート要素：`data-testid="app-root"`

### 一覧画面
- 「新規追加」：`data-testid="book-new"`
- 状態フィルタ：`data-testid="filter"`（`select`。値 `all`/`want`/`reading`/`done`）
- 表示中の件数：`data-testid="book-count"`（数字のみ）
- 本：`data-testid="book-item"`
  - 題名：`data-testid="book-title"`
  - 状態：`data-testid="book-status"`（表示「読みたい」/「読んでいる」/「読んだ」）
  - 編集：`data-testid="book-edit"`
  - 評価（読んだ本のみ）：`data-testid="book-rating"`（★を数だけ、例 `★★★`）
  - 写真（あれば）：`data-testid="book-cover"`（`img`）

### フォーム（新規追加・編集時に表示、一覧は隠す）
- 題名：`data-testid="form-title"`（`input`）
- 状態：`data-testid="form-status"`（`select`。値 `want`/`reading`/`done`）
- 評価：`data-testid="form-rating"`（`select`。値は空/`1`〜`5`）
- 感想：`data-testid="form-note"`（`textarea`）
- 撮影（カメラ使える場合のみ表示）：`data-testid="form-cover"`
- 保存：`data-testid="form-save"`
- キャンセル：`data-testid="form-cancel"`
- 削除（編集時のみ表示）：`data-testid="form-delete"`

## 振る舞い

- 初期値：フィルタは「すべて」、フォームは非表示
- 新規追加：フォーム表示、状態初期値「読みたい」、評価・感想・写真は空、削除ボタン非表示
- 編集：フォーム表示、現在値を入力欄に設定、削除ボタン表示
- キャンセル：フォーム閉じて一覧に戻す、変更は破棄
- 保存：題名が空または空白のみ→トースト表示、フォーム開いたまま。題名入力→保存して一覧に戻す
- 削除：確認ダイアログ表示。OK で削除、一覧に戻す。キャンセルでダイアログ閉じてフォーム開いたまま
- フィルタ変更：選択状態の本のみ表示、件数更新
- 状態：「読みたい」「読んでいる」「読んだ」間で自由に変更可能
- 評価と感想：「読んだ」本のみ対象、両方とも任意
- 写真：カメラが使える場合のみボタン表示。撮影後サムネイル表示。キャンセル時は追加しない
- 永続化：`storage` に保存。アプリ再起動後も残る。破損データは空の一覧で再開

## エラー時の挙動

- 題名が空または空白のみ：トーストで「題名を入力してください」表示、フォーム開いたまま
- カメラが使えない環境：撮影ボタンは表示しない
- 保存データ破損：空の一覧から再開

## 受け入れ条件

### AC-01: 新規追加フォームを開く
- Given 一覧画面が表示されている
- When 「新規追加」ボタンをクリック
- Then フォームが表示され、`form-title` が空、`form-status` が「読みたい」に設定されている

### AC-02: 題名が空の場合、保存できない
- Given 編集フォームが表示されている
- When 題名を空のまま（または空白のみ）にして「保存」ボタンをクリック
- Then トーストメッセージが表示され、フォームは開いたまま

### AC-03: 正常に本を登録
- Given 編集フォームが表示されている
- When 題名「テスト本」を入力して「保存」ボタンをクリック
- Then フォームが閉じ、一覧に「テスト本」（状態「読みたい」）が表示される

### AC-04: 本を編集
- Given 本「テスト本」（状態：読みたい）が一覧に表示されている
- When その本の「編集」ボタンをクリック
- Then フォームが表示され、`form-title` に「テスト本」、`form-status` に「読みたい」が設定されている

### AC-05: 本の状態を変更
- Given フォームで本の状態を「読みたい」から「読んでいる」に変更
- When 「保存」ボタンをクリック
- Then フォームが閉じ、一覧で該当の本の状態が「読んでいる」と表示される

### AC-06: 読んだ本に評価を登録
- Given フォームで本の状態を「読んだ」に設定
- When 評価「★★★」（3）と感想「面白かった」を入力して「保存」ボタンをクリック
- Then フォームが閉じ、一覧で該当の本に「★★★」と表示される

### AC-07: 読んだ本の評価は任意
- Given フォームで本の状態を「読んだ」に設定
- When 評価を選択せず「保存」ボタンをクリック
- Then フォームが閉じ、一覧で該当の本に `book-rating` 要素は表示されない

### AC-08: 本を削除
- Given 編集フォームで「削除」ボタンをクリック
- When 削除確認ダイアログで OK をクリック
- Then ダイアログが閉じ、一覧から該当の本が削除される

### AC-09: フィルタで絞り込み
- Given 一覧画面に複数の状態の本が表示されている
- When フィルタを「読みたい」に変更
- Then 状態「読みたい」の本のみ表示され、`book-count` は該当の数が表示される

### AC-10: フィルタを「すべて」にリセット
- Given フィルタが「読みたい」に設定されている
- When フィルタを「すべて」に変更
- Then すべての状態の本が表示される

### AC-11: データが永続化される
- Given 本「テスト本」（状態：読んだ、評価：★★★）がアプリに登録されている
- When アプリを閉じて開き直す
- Then 「テスト本」が一覧に表示され、状態は「読んだ」、評価は「★★★」と表示される

### AC-12: 読んだ本から他の状態に戻せる
- Given 本が「読んだ」状態で保存されている
- When その本を編集して状態を「読みたい」に変更して「保存」ボタンをクリック
- Then 一覧でその本の状態が「読みたい」と表示される

### AC-13: 写真を撮影して保存
- Given 編集フォームが表示されており、カメラが使える環境
- When 撮影ボタンをクリックして写真を撮影する
- Then フォームに戻り、表紙写真がサムネイルとして表示される

## 決定事項

- D1: 題名が空または空白のみの場合、トーストメッセージで知らせ、フォームは開いたままにする（A1 回答より）
- D2: 新規追加フォームの状態初期値は「読みたい」（A2 より）
- D3: 読んだ本の評価と感想は任意（A3 より）
- D4: 削除時に確認ダイアログを表示する（A4 より）
- D5: 状態の変更はフォームの「状態」選択で行う（A1 ラウンド2 回答より、編集フォームを選択）
- D6: 「読んだ」状態から「読みたい」や「読んでいる」に戻すことが可能（A2 ラウンド2 より）
- D7: アプリ初回表示時のフィルタ初期値は「すべて」（A3 ラウンド2 より）
- D8: カメラが使えない環境では、撮影ボタンを表示しない（実装判断より、A4 ラウンド2 のお任せを活用）
- D9: 保存データの形が破損していた場合、空の一覧として扱う（SDK の決まりごとに従う）
