# 買い物リスト 外部仕様

> 商品名と数量を登録し、チェックで買った／未購入を切り替え、削除できるリスト。未購入の件数を表示する。
> 保存は `storage` の単一キー（配列）に全項目をまとめ、開き直しても内容が残る。
> 未決事項なし。入力の不正値とエラー時の挙動を中心にレビューしてほしい。

## 画面と操作
- ルート：`data-testid="app-root"`
- 入力欄：商品名 `data-testid="new-item-name"`（`input`）、数量 `data-testid="new-item-qty"`（`input`。空欄可）
- 追加ボタン：`data-testid="add"`。商品名欄・数量欄のどちらで Enter を押しても追加される
- 一覧：項目ごとに `data-testid="shopping-item"`。内側に `"item-name"`（商品名）、`"item-qty"`（数量。数字のみ）、`"item-toggle"`（`input type="checkbox"`。買った）、`"item-delete"`（ボタン）
- 未購入の件数：`data-testid="remaining-count"`（テキストは数字のみ）

## 振る舞い
- 初期状態：保存データがなければ一覧は0件、`remaining-count` は `0`
- 追加：商品名・数量を読み、検証OKなら一覧の**末尾**に項目を追加し、入力欄を空にする。登録順を保つ（並べ替えはしない）
- チェック切替：`item-toggle` で買った／未購入を切り替える。切り替えても一覧内の位置は変わらない
- 削除：`item-delete` を押すと確認なしで即削除する
- 同名の商品をもう一度登録しても、まとめずに別項目として追加する
- `remaining-count` は未購入（チェックなし）の項目数。買った項目をチェックすると、画面を開き直さずその場で減る
- 保存：追加・切替・削除のたびに全項目を `storage` の1つのキーへ保存する。再読み込み後も同じ内容・同じ並びで表示する

## エラー時の挙動
- 商品名が空欄、または空白文字のみ：追加しない。入力欄はそのまま残る（トースト等の通知はしない）
- 数量が空欄：**1個**として登録する
- 数量が 0・負数・小数・数字以外の文字：追加せず `ui.toast` で知らせる。入力欄の内容は消さない
- 保存データが壊れている（JSON破損・配列でない等）：壊れたデータは捨て、0件の一覧として起動する

## 受け入れ条件
### AC-01: 商品を登録する
- Given 一覧が0件
- When 商品名欄に「牛乳」、数量欄に「2」を入れて `add` を押す
- Then `shopping-item` が1件表示され、`item-name` に「牛乳」、`item-qty` に `2`、`remaining-count` に `1` と表示される

### AC-02: 数量を省略すると1個になる
- Given 一覧が0件
- When 商品名欄に「パン」を入れ、数量欄は空のまま `add` を押す
- Then 追加された項目の `item-qty` に `1` と表示される

### AC-03: 商品名が空だと追加されない
- Given 一覧が0件
- When 商品名欄を空欄（または空白のみ）のまま `add` を押す
- Then `shopping-item` は0件のまま、`remaining-count` は `0` のままになる

### AC-04: 数量が不正だと追加されずトーストで知らせる
- Given 一覧が0件
- When 商品名欄に「卵」、数量欄に「0」を入れて `add` を押す
- Then `shopping-item` は0件のまま、`sdk-toast` が表示される

### AC-05: 買った扱いにすると残り件数が減る
- Given 「牛乳」（未購入）が1件登録済みで `remaining-count` が `1`
- When その項目の `item-toggle` をチェックする
- Then `remaining-count` に `0` と表示され、その項目は一覧内の同じ位置に残る

### AC-06: 削除すると即座に一覧から消える
- Given 「牛乳」が1件登録済み
- When その項目の `item-delete` を押す
- Then `shopping-item` は0件になる（確認は出ない）

### AC-07: 同名でも別項目として追加される
- Given 「牛乳」（数量1）が1件登録済み
- When 商品名欄に「牛乳」、数量欄に「1」を入れて `add` を押す
- Then `shopping-item` が2件表示される

### AC-08: 再読み込みしても内容が残る
- Given 「牛乳」（数量2、未購入）を登録済み
- When ページを再読み込みする
- Then `shopping-item` が1件表示され、`item-name` に「牛乳」、`item-qty` に `2` と表示される

### AC-09: 壊れた保存データは空で起動する
- Given 保存データが配列でない値（壊れたデータ）になっている
- When ページを開く
- Then `shopping-item` は0件、`remaining-count` は `0` と表示される

## 決定事項
- D1: 商品名が空・空白のみなら追加しない（通知なし）。数量が空欄なら1個として追加。数量が0・負数・小数・数字以外なら追加せず `ui.toast` で知らせる（Q1）
- D2: 一覧は常に登録順（追加順）。チェックしても並びは変わらない（Q2）
- D3: 削除は確認なしで即実行する（Q3）
- D4: 同名商品も別項目としてそのまま追加する。まとめない（Q4）
- D5: 保存データが壊れている場合は、エラー通知なしで空のリストとして起動する（Q5。要求者の指定なし、仮に採用）
