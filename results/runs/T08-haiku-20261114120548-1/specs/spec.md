# 読書記録 外部仕様

> 本の登録・状態管理・評価記録の一覧。新規登録は一番上に、編集後も順番は変わらない。
> 状態で絞り込み、表紙写真と評価・感想は読んだ本のみ入力可。
> ストレージに保存され、再起動後も残る。

## 画面と操作

### 一覧画面（初期表示）
- ルート要素 `data-testid="app-root"`
- 「＋ 本を追加」ボタン `data-testid="book-new"`（押すとフォーム表示）
- 絞り込みセレクト `data-testid="filter"`（値：`all`（すべて）／`want`（読みたい）／`reading`（読んでいる）／`done`（読んだ））
- 表示件数 `data-testid="book-count"`（絞り込み後の件数。数字のみ）
- 本の一覧（各本の要素 `data-testid="book-item"`）
  - タイトル `data-testid="book-title"`
  - 状態 `data-testid="book-status"`（「読みたい」「読んでいる」「読んだ」のテキスト）
  - 編集ボタン `data-testid="book-edit"`（押すとフォーム表示）
  - 評価（読んだ本のみ）`data-testid="book-rating"`（★を評価数だけ。例：`★★★`）
  - 表紙写真（写真があれば）`data-testid="book-cover"`（img 要素）

### フォーム画面（追加・編集のみ表示）
- フォーム要素 `data-testid="book-form"`
  - タイトル入力 `data-testid="form-title"`
  - 状態セレクト `data-testid="form-status"`（値：`want`／`reading`／`done`）
  - 評価セレクト `data-testid="form-rating"`（値：空の選択肢／`1`〜`5`。「読んだ」状態でのみ入力可）
  - 感想テキストエリア `data-testid="form-note"`（「読んだ」状態でのみ入力可）
  - 撮影ボタン `data-testid="form-cover"`（カメラを開いて写真を撮影）
  - 保存ボタン `data-testid="form-save"`
  - キャンセルボタン `data-testid="form-cancel"`（フォーム閉じる）
  - 削除ボタン `data-testid="form-delete"`（編集時のみ表示。確認ダイアログを出す）

## 振る舞い

### 初期表示
- ストレージから本一覧を読み込む（キー：`books`）
- 絞り込みは「all」（すべて）
- フォームは非表示

### 本の追加
- 「＋ 本を追加」ボタンでフォーム表示
- 状態初期値は「読みたい」
- 評価・感想は非表示
- 保存時：タイトル必須。新規登録は一番上に追加

### 本の編集
- 各本の「編集」ボタンでフォーム表示
- 既存の値を表示
- 状態が「読んだ」の場合、評価と感想を表示＆入力可
- 保存時：順番は変わらない

### 本の削除
- フォームの「削除」ボタンで確認ダイアログを出す
- 「OK」で削除

### 状態変更
- フォームの状態セレクトで「読みたい」「読んでいる」「読んだ」を切り替え
- 「読んだ」を選んだ場合：評価と感想の入力欄を表示
- 「読みたい」「読んでいる」を選んだ場合：評価と感想の入力欄を非表示

### 評価と感想
- 読んだ本のみ。状態が「読んだ」のフォームで入力可
- 評価：1〜5 の選択肢（空も可）
- 感想：自由な文字列

### 表紙写真
- 撮影ボタンで手持ちカメラまたはカメラアプリを開く
- 撮り直し可（新しい写真で上書き）
- 削除機能なし

### 絞り込み
- セレクトで状態を選択：`all`（全部）、`want`（読みたい）、`reading`（読んでいる）、`done`（読んだ）
- 表示件数（`book-count`）更新

### 保存と復元
- 本の追加・編集・削除のたびに即座に保存（`storage.set('books', ...)`）
- アプリを閉じて開き直しても、データが残る
- 写真は Blob として保存

## エラー時の挙動

### 壊れた保存データ
- ストレージの `books` が不正な形式の場合、初期値の空配列 `[]` から始まる

### カメラ操作
- 撮影キャンセル：何もしない（既存の写真は残る）
- 撮影失敗：例外は SDK が処理。通常は続行

## 受け入れ条件

### AC-01: 本を追加する
- Given 何も本がない状態
- When 「＋ 本を追加」を押し、タイトルに「技術書」と入力して保存
- Then 一覧に「技術書」（「読みたい」状態）が一番上に表示される

### AC-02: 本の状態を変更する
- Given 「読みたい」状態の本「技術書」がある
- When フォームを開いて状態を「読んでいる」に変更して保存
- Then 一覧で「技術書」の状態が「読んでいる」に変わる

### AC-03: 読んだ本に評価と感想を残す
- Given 「読みたい」状態の本がある
- When フォームを開いて状態を「読んだ」に、評価を「★★★」に、感想を「面白かった」に設定して保存
- Then 一覧で「★★★」と感想が表示される

### AC-04: 読みたい本からは評価が見えない
- Given 「読みたい」状態の本がある
- When フォームを開く
- Then 評価と感想の入力欄は非表示

### AC-05: 本を削除する（確認あり）
- Given 「技術書」がある
- When フォームを開いて「削除」を押し、ダイアログで「OK」を選ぶ
- Then 一覧から「技術書」が消える

### AC-06: 状態で絞り込む
- Given 「読みたい」1件、「読んでいる」1件、「読んだ」1件がある
- When 絞り込みを「読んだ」に変更
- Then 「読んだ」の本だけ表示され、件数が 1 になる

### AC-07: 表紙写真を撮影する
- Given フォームが開いている
- When 「撮影」ボタンを押してカメラで写真を撮影して保存
- Then 一覧で写真が表示される

### AC-08: 表紙写真を撮り直す
- Given 写真がある本のフォーム
- When 「撮影」ボタンを押して新しい写真を撮影
- Then 新しい写真で上書きされる（削除機能なし）

### AC-09: アプリを閉じても本のデータが残る
- Given 「JavaScript入門」を追加
- When アプリを閉じて再起動
- Then 「JavaScript入門」がそのまま表示される

## 決定事項
- D1: 一覧順は新規登録時に上。編集後は順番は変わらない（A1）
- D2: 本を削除するとき、確認ダイアログを出す（A2）
- D3: 表紙写真は撮り直し可。削除機能は不要（A3）
- D4: 評価と感想は「読んだ」状態でのみ入力可（A4）
- D5: 新規登録時の状態初期値は「読みたい」（A5）
