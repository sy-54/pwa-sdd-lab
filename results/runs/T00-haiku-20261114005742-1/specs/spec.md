# カウンタ 外部仕様

> ボタンで数を増やす・減らす・リセット。
> ローカルストレージに値を保存し、再読み込み後も保持。
> 決定事項はすべて回答から派生。未決事項なし。

## 画面と操作
- ルート要素：`data-testid="app-root"`
- 数字表示：`data-testid="count"`（0から開始）
- 増やすボタン：`data-testid="inc"`
- 減らすボタン：`data-testid="dec"`
- リセットボタン：`data-testid="reset"`

## 振る舞い
- 初期表示時、count は 0
- inc ボタンで count が 1 増える（上限なし）
- dec ボタンで count が 1 減る（0 未満にはならない）
- reset ボタンで count が 0 に戻る
- 値は各操作後、ローカルストレージに即座に保存
- ページ再読み込みまたはアプリ再起動後、保存された値から再開

## エラー時の挙動
- ローカルストレージから読み込んだデータが不正な形式の場合、0 に初期化して開始
- dec ボタンが 0 で押されても値は変わらない

## 受け入れ条件

### AC-01: 初期状態で 0 が表示される
- Given アプリを初めて開く
- When ページが読み込まれた直後
- Then count に「0」と表示される

### AC-02: inc ボタンで 1 増える
- Given count が 0
- When inc ボタンを押す
- Then count に「1」と表示される

### AC-03: dec ボタンで 1 減る
- Given count が 2
- When dec ボタンを押す
- Then count に「1」と表示される

### AC-04: 0 で dec ボタンは効かない
- Given count が 0
- When dec ボタンを押す
- Then count に「0」と表示される

### AC-05: reset ボタンで 0 にリセット
- Given count が 5
- When reset ボタンを押す
- Then count に「0」と表示される

### AC-06: 値を保存して再読み込み後も残る
- Given count が 3
- When count を 3 に更新してページを再読み込みする
- Then count に「3」と表示される

### AC-07: 不正な保存データは初期化
- Given ローカルストレージに不正な値が保存されている
- When アプリを開く
- Then count に「0」と表示される

## 決定事項
- D1: 初期値は 0（Q1）
- D2: dec は 0 以下にしない（Q2-A）
- D3: 上限なし（Q3-A）
- D4: 1 ずつ増減（Q4-A）
- D5: 不正データは初期化（Q5 推奨適用）
