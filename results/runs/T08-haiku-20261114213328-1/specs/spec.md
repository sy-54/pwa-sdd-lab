# 読書記録 外部仕様

> 本の一覧を、状態ごとに管理。新規追加・編集・削除ができ、読んだ本には評価と感想を記入。
> アプリを再度開いても本や評価が残り、表紙の写真も保存される。
> 質問で状態の必須性、削除確認、並び順、フォーム挙動が決まった。

## 画面と操作

- 一覧表示：`filter`（初期値 `all`）、`book-new`（追加ボタン）、`book-item` 各行に `book-title` / `book-status` / `book-edit` / `book-rating` / `book-cover`
- フォーム：`book-form` に `form-title`（必須）/ `form-status`（初期値 `want`）/ `form-rating` / `form-note`（状態「読んだ」のみ表示） / `form-cover`（撮影） / `form-save` / `form-cancel` / `form-delete`（編集時のみ）
- 件数：`book-count`（フィルタで表示中の件数）

## 振る舞い

- 起動時：保存済みデータを読み込む。フィルタ「全て」にリセット。
- 一覧：追加順（新しい順）に表示。フィルタで全状態または該当状態のみ表示。
- 新規追加：状態デフォルト「読みたい」。「読んだ」でのみ評価・感想欄を表示。
- 状態変更：「読んだ」への変更で評価・感想欄表示、その他で非表示。
- タイトル空での保存：トースト表示、フォーム開いたまま、保存されない。
- キャンセル：編集中の変更を破棄、一覧は編集前の状態に戻る。
- 削除：確認ダイアログを経て実行。OK で本を削除、フォーム閉じる。
- カメラ：撮影後、写真を保存。編集時に置き換え可能。
- 保存：変更のたびに SDK `storage` に保存。

## エラー時の挙動

- タイトル空での保存：トースト「タイトルを入力してください」表示、フォーム開いたまま、本は保存されない。
- 写真撮影キャンセル：トースト表示なし。フォームは開いたまま。既存写真があれば表示継続。
- 写真保存失敗（SDK エラー）：トースト「写真の保存に失敗しました」表示、フォーム開いたまま。本は保存されない。
- 保存データ形式が壊れた場合：壊れたデータを無視し、一覧は空状態で起動。

## 受け入れ条件

### AC-01: 新規追加で本が一覧に追加される
- Given アプリ初期起動時、一覧が空
- When 「追加」ボタンを押し、フォームにタイトル「吾輩は猫である」と入力、状態「読みたい」のまま、「保存」ボタンを押す
- Then `book-item` に「吾輩は猫である」が表示され、`book-status` に「読みたい」と表示され、`book-count` に 1 と表示される

### AC-02: 状態変更で一覧の表示が更新される
- Given 一覧に「吾輩は猫である」（読みたい）が追加済み
- When 本の「編集」ボタンを押し、フォーム内で状態を「読んでいる」に変更、「保存」ボタンを押す
- Then `book-status` に「読んでいる」と表示される

### AC-03: 読んだ本に評価と感想が記入できる
- Given 一覧に「吾輩は猫である」（読みたい）が追加済み
- When 本の「編集」ボタンを押し、フォーム内で状態を「読んだ」に変更、評価を「★★★」（3選択）、感想に「面白かった」と入力、「保存」ボタンを押す
- Then `book-rating` に「★★★」と表示され、`book-item` に感想テキストが表示される

### AC-04: 表紙写真が保存・表示される
- Given 一覧に本が追加済み
- When 本の「編集」ボタンを押し、「撮影」ボタンで写真をアップロード、「保存」ボタンを押す
- Then `book-cover` （`img`）に写真が表示される

### AC-05: 削除は確認ダイアログを経て実行される
- Given 一覧に「吾輩は猫である」（読みたい）が追加済み
- When 本の「編集」ボタンを押し、「削除」ボタンを押す
- Then 確認ダイアログ（`sdk-confirm-ok` / `sdk-confirm-cancel`）が表示される

### AC-06: 削除ダイアログ OK で本が削除される
- Given 削除確認ダイアログが表示中
- When ダイアログの OK ボタンを押す
- Then `book-item` から「吾輩は猫である」が削除され、`book-count` に 0 と表示される

### AC-07: フィルタで状態に応じた絞り込みができる
- Given 一覧に「読みたい」1件、「読んでいる」1件、「読んだ」1件が追加済み
- When フィルタで「読んだ」を選択
- Then 「読んだ」の本のみ表示され、`book-count` に 1 と表示される

### AC-08: タイトル空での保存はトースト表示
- Given フォーム表示中（新規追加または編集）
- When タイトルを空のまま「保存」ボタンを押す
- Then トースト「タイトルを入力してください」が表示され、本は保存されない

### AC-09: キャンセルで編集は破棄される
- Given 一覧に「吾輩は猫である」（読みたい）が追加済み
- When 本の「編集」ボタンを押し、フォーム内で状態を「読んでいる」に変更、「キャンセル」ボタンを押す
- Then フォームが閉じ、一覧の本は「読みたい」のまま変わらない

### AC-10: アプリ再起動後、本と評価が復元される
- Given 一覧に「吾輩は猫である」（読んだ、評価★★★、感想「面白い」）が保存済み
- When アプリを閉じて再度開く
- Then 一覧に「吾輩は猫である」が復元され、`book-rating` に「★★★」、感想テキストが表示される

### AC-11: 読みたい・読んでいる状態では評価・感想入力欄が非表示
- Given フォーム表示中（新規追加または編集）
- When 状態が「読みたい」または「読んでいる」
- Then `form-rating` と `form-note` が非表示

### AC-12: 読んだ状態では評価・感想入力欄が表示される
- Given フォーム表示中
- When 状態を「読んだ」に選択
- Then `form-rating` と `form-note` が表示される

### AC-13: 新規追加時、状態のデフォルト値は「読みたい」
- Given 「追加」ボタンを押し、フォームが表示された
- When フォーム表示直後
- Then `form-status` の値が「読みたい」

### AC-14: フィルタの初期値は「全て」
- Given アプリ起動直後
- When 一覧が表示
- Then `filter` の値が「全て」に設定され、全状態の本が表示される

## 決定事項
- D1: 評価・感想は「読んだ」のみ入力可能（Q1）
- D2: タイトルのみ必須（Q1）
- D3: 削除は確認ダイアログ経由（Q2）
- D4: 本は追加順表示（Q3）
- D5: フィルタで全状態表示可能（Q4）
- D6: 新規追加時の状態は「読みたい」（Q1-R2）
- D7: フィルタ初期値は「全て」（Q2-R2）
- D8: キャンセルで編集前に戻す（Q3-R2）
- D9: 空タイトル保存時はトースト表示（Q4-R2）
- D10: 「読んだ」以外は評価・感想非表示（Q5-R2）
