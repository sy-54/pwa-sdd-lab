# タイマー 外部仕様

> 分（1〜99の整数）を指定するカウントダウンタイマー。開始・一時停止・再開・リセットができ、残り0になったら画面表示とOS通知で知らせる。
> 状態は保存しない。再読み込みすると常に初期状態（3分・未開始）に戻る。
> 未決事項なし。レビューはリセット時の挙動（決定事項D6）と入力欄の有効/無効の切り替え（D7）を中心に見てほしい。

## 画面と操作
- ルート要素：`data-testid="app-root"`
- 分の入力：`data-testid="minutes"`（`input type="number"`）。初期値 `3`
- 残り時間：`data-testid="time"`。`MM:SS` 形式のみ（例 `03:00`）
- ボタン：`data-testid="start"`（開始・再開）、`data-testid="pause"`、`data-testid="reset"`
- 終了の表示：`data-testid="done"`（時間になったときだけ表示。それ以外は `hidden`）

## 振る舞い
- 状態は「未開始」「実行中」「一時停止」「終了」の4つ。
- 初期状態（起動時・リセット後）：`minutes` = `3`、`time` = `03:00`、`done` は非表示、`minutes` は入力可能。
- `minutes` に入力できるのは1〜99の整数のみ。0・負数・小数・100以上・空欄は無効（D2）。
- **未開始のときのみ** `minutes` を編集できる。実行中・一時停止中は編集不可（D7）。終了状態でも編集不可（リセットするまで）。
- `start`（未開始の状態で押す＝開始）：`minutes` が有効な値なら、残り時間を `minutes * 60` 秒にして実行中へ移行し、1秒ごとに `time` を減らす。`minutes` が無効なら何もしない（D3）。
- `start`（一時停止の状態で押す＝再開）：止めた残り時間から1秒ごとに減らすのを再開する。
- `pause`：実行中のときに押すと、`time` の表示を止めて一時停止へ移行する。未開始・一時停止・終了のときに押しても何も起こらない。
- `reset`：どの状態からでも押せる。カウントを止め、`time` を `minutes` の現在値（開始時に使った値）から計算した `MM:SS` に戻し、`done` を非表示にし、`minutes` を編集可能にして未開始へ戻す（D6）。
- 残り時間が0になったら自動的に終了状態へ移行する：カウントを止め、`time` は `00:00`、`done` を表示し、`notify.send('タイマー', '残り時間がなくなりました')` を1回呼ぶ（D5）。
- 終了状態では `start`・`pause` を押しても何も起こらない。`reset` のみ有効。
- ページを再読み込みすると、実行中・一時停止中・終了のいずれであっても常に初期状態に戻る。状態は保存しない（D4）。

## エラー時の挙動
- `minutes` が無効（空欄・0・負数・小数・100以上）のまま `start` を押す：タイマーは開始せず、エラー表示もしない（何も変化しない）。

## 受け入れ条件
### AC-01: 初期状態
- Given アプリを開く
- When 何も操作しない
- Then `minutes` に `3`、`time` に `03:00` と表示され、`done` は非表示

### AC-02: 開始すると残り時間が減る
- Given `minutes` が `3`（未開始）
- When `start` を押して2秒待つ
- Then `time` が `02:58` になる

### AC-03: 無効な値では開始しない
- Given `minutes` を空欄にする
- When `start` を押す
- Then `time` は `03:00` のまま変わらず、`done` も表示されない

### AC-04: 一時停止で止まる
- Given `start` を押して1秒待った状態
- When `pause` を押してさらに2秒待つ
- Then `time` の値は `pause` を押した直後の値のまま変化しない

### AC-05: 再開で続きから減る
- Given `pause` で `time` が `02:59` の状態
- When `start`（再開）を押して1秒待つ
- Then `time` が `02:58` になる

### AC-06: リセットで初期状態に戻る
- Given `start` を押して1秒以上経過した状態
- When `reset` を押す
- Then `time` は開始時の `minutes` から計算した `MM:SS`（例 `03:00`）に戻り、`done` は非表示、`minutes` が編集可能になる

### AC-07: 時間になったら知らせる
- Given `minutes` に `1` を入れて `start` を押した状態
- When 60秒経過する
- Then `time` が `00:00`、`done` が表示され、通知が送られる

### AC-08: 再読み込みで初期状態に戻る
- Given `start` を押して実行中の状態
- When ページを再読み込みする
- Then `minutes` が `3`、`time` が `03:00` に戻り、`done` は非表示

## 決定事項
- D1: 初期値は `minutes = 3`、表示は `03:00`（Q1）
- D2: `minutes` の有効範囲は1〜99の整数のみ。0・負数・小数・100以上・空欄は無効（Q2）
- D3: 無効な値のまま `start` を押しても何も起こらない。エラー表示もしない（Q3）
- D4: 状態は保存しない。再読み込みすると常に初期状態に戻る（Q4）
- D5: 終了時は `done` 表示に加え `notify.send` で通知する（音は不要）（Q5）
- D6: `reset` は、開始時に使った `minutes` の値から計算した `MM:SS` に戻す（元の設定分数を保つ）
- D7: `minutes` の編集は未開始状態のときのみ可能。実行中・一時停止中・終了状態では編集不可
