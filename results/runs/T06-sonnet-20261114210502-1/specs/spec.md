# カウンタ 外部仕様

> ボタンで数値を増減・リセットする単一画面アプリ。増減の幅（1/5/10）と目標回数を選べ、目標到達中は表示される。
> 値・ステップ・目標は常にlocalStorageに自動保存し、再読み込み後も復元する。既存ユーザーの保存済みcountはそのまま残る。
> 未決事項なし。

## 画面と操作
- ルート要素 `data-testid="app-root"` 内に、現在値表示 `data-testid="count"`（数字のみのテキスト）と、ボタン3つ（`data-testid="inc"`、`"dec"`、`"reset"`）を表示する。
- `inc` を押すと現在値に、選択中のステップ分を加算する。
- `dec` を押すと現在値から、選択中のステップ分を減算する。ただし0未満にはしない。
- `reset` を押すと現在値を0にする（ステップ・目標は変えない）。
- 増減幅選択 `data-testid="step"`（`select`、選択肢は `1`/`5`/`10`）：選んだ値がその後の `inc`/`dec` の増減量になる。
- 目標入力 `data-testid="goal"`（`input type="number"`）：1以上の整数を入力すると目標として設定される。
- 達成表示 `data-testid="goal-reached"`：目標が設定され、かつ `count >= goal` の間だけ表示される。

## 振る舞い
- 初期状態：保存データがなければ `count` は0、`step` は `1`、`goal` は空欄（目標なし）。
- 状態が変わるたび（inc / dec / reset / step変更 / goal入力）に、値をlocalStorageへ即時保存する。
- 再読み込み時：保存値があれば `count`・`step`・`goal` にそれぞれ復元し表示する。
- 下限は0。`dec` は現在値がステップ未満でも0にクランプする（負値にはしない）。
- 上限なし（実質 `Number.MAX_SAFE_INTEGER` まで、それ以上の挙動は規定しない）。
- 目標の判定は都度 `count >= goal` で行う（ステップでちょうどの値を飛び越えても達成扱い。達成後に目標を上げたり `dec` で下げれば表示は再評価される）。
- 既存（更新前）の保存データには `count` のキーしかない。`step`・`goal` のキーがなければ、`count` はそのまま使い、`step`・`goal` は初期値（`1`／未設定）として扱う。

## エラー時の挙動
- 保存データが存在しない、パースできない、0以上の整数でない場合は、`count` を0として扱い、同時にlocalStorageを0で上書きする。
- `goal` に空欄・0・負数・小数・数値以外の文字を入れたときは「目標なし」として扱い、`goal-reached` は表示しない。保存データも「目標なし」に即時上書きする。
- 保存されている `step` の値が `1`/`5`/`10` のいずれでもない場合は `1` として扱い、保存データも `1` に上書きする。
- 保存されている `goal` の値が1以上の整数として解釈できない場合は「目標なし」として扱い、保存データも「目標なし」に上書きする。

## 受け入れ条件
### AC-01: 初期表示
- Given localStorageに保存データがない状態でアプリを開く
- When 画面を表示する
- Then `count` に `0` と表示される

### AC-02: incで増える
- Given `count` が `0` の状態
- When `inc` を1回押す
- Then `count` に `1` と表示される

### AC-03: decは0未満にならない
- Given `count` が `0` の状態
- When `dec` を1回押す
- Then `count` に `0` と表示される

### AC-04: resetで0に戻る
- Given `count` が `3` の状態（`inc` を3回押した状態）
- When `reset` を押す
- Then `count` に `0` と表示される

### AC-05: 再読み込みで値が残る
- Given `inc` を2回押して `count` が `2` の状態
- When ページを再読み込みする
- Then `count` に `2` と表示される

### AC-06: 壊れた保存データは0として初期化
- Given localStorageの保存値が不正な文字列（数値でも整数でもない値）になっている状態
- When 画面を表示する
- Then `count` に `0` と表示され、保存データも `0` に上書きされる

### AC-07: ステップ選択で増減幅が変わる
- Given `count` が `0`、`step` が初期値 `1` の状態
- When `step` を `10` に変更してから `inc` を1回押す
- Then `count` に `10` と表示される

### AC-08: ステップ未満の減算は0にクランプ
- Given `count` が `3`、`step` が `10` の状態
- When `dec` を1回押す
- Then `count` に `0` と表示される

### AC-09: 目標達成で表示される
- Given `goal` に `5` を入力し、`count` が `0`、`step` が `5` の状態
- When `inc` を1回押す
- Then `count` に `5` と表示され、`goal-reached` が表示される

### AC-10: 目標未達は表示されない
- Given `goal` に `10` を入力し、`count` が `0` の状態
- When 画面を表示する
- Then `goal-reached` は表示されない

### AC-11: 不正な目標入力は目標なしとして扱う
- Given `count` が `0` の状態
- When `goal` に `0` を入力する
- Then `goal-reached` は表示されない

### AC-12: ステップと目標は再読み込みで復元する
- Given `step` を `5` に変更し `goal` に `20` を入力した状態
- When ページを再読み込みする
- Then `step` は `5`、`goal` は `20` と表示される

### AC-13: 既存データ（ステップ・目標キーなし）の互換性
- Given localStorageに `counter:count` のみ `"7"` として保存され、ステップ・目標のキーが存在しない状態
- When 画面を表示する
- Then `count` に `7` と表示され、`step` は `1`、`goal` は空欄と表示される

## 決定事項
- D1: `dec` は0で下限、0未満にならない（Q1）
- D2: `reset` は常に0に戻す（Q2）
- D3: 増減のステップは初期値1（Q3。ラウンド2で `1`/`5`/`10` から選べるよう拡張）
- D4: 上限なし（実質無制限）（Q4）
- D5: 壊れた保存データは0として初期化し上書きする（Q5）
- D6: 目標は1以上の整数のみ有効。それ以外（空欄・0・負数・小数・非数値）は「目標なし」（ラウンド2 Q1）
- D7: 目標達成の判定は `count >= goal`（飛び越えても達成扱い）（ラウンド2 Q2）
- D8: 現在値がステップ未満の状態での `dec` は0にクランプする（ラウンド2 Q3）
- D9: `step`・`goal` も `count` と同様にlocalStorageへ保存し、再読み込みで復元する（ラウンド2 Q4）
- D10: 初期値は `step` が `1`、`goal` は空欄（未設定）（ラウンド2 Q5）
