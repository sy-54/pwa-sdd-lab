# ToDo 外部仕様

> やることの追加・完了切替・削除ができ、未完了の件数を表示する単一画面アプリ。
> 全項目（id・内容・完了フラグの配列）を `items` キーに保存し、再読み込みでも復元する。
> 未決事項なし。Q1〜Q5の回答で挙動はすべて確定している。

## 画面と操作
- 置くファイル：`apps/todo/index.html`、`apps/todo/manifest.json`
- ルート要素：`data-testid="app-root"`
- 入力欄：`data-testid="new-todo"`、追加ボタン：`data-testid="add"`。入力欄で Enter を押しても追加される
- 各項目：`data-testid="todo-item"`。その中に `"todo-text"`（内容）、`"todo-toggle"`（`input type="checkbox"`）、`"todo-delete"`（ボタン）
- 残り件数：`data-testid="todo-count"`（テキストは数字のみ）

## 振る舞い
- 初期状態：保存データがなければ項目0件、`todo-count` は `0`
- 追加：`new-todo` の値の前後空白を除いた文字列が1文字以上のとき、新しい項目を一覧の**末尾**に追加し、`new-todo` を空にする。重複する文字列もそのまま追加する。文字数の上限はない
- 追加ボタンは常に押せる状態（disabled にしない）
- 完了切替：`todo-toggle` のチェックを変えると、その項目の完了フラグが切り替わる。一覧内の位置は変えない。完了した項目は取り消し線など見た目で区別する（未完了との違いが分かれば手段は問わない）
- 削除：`todo-delete` を押すと確認なしで即座にその項目を一覧と保存データから取り除く
- `todo-count` は**未完了**の項目数を表示する。完了切替・追加・削除のたびに再計算して表示し直す
- 保存：`items` キーに `{ id, text, done }` の配列をまるごと保存する。追加・切替・削除のたびに保存し直す
- 再読み込み：保存されている `items` を読み込み、内容・完了状態・並び順をそのまま復元する

## エラー時の挙動
- `new-todo` が空、または空白のみのときに追加ボタン／Enterを押しても、何も起きない（項目は追加されず、入力欄の内容も変えない）
- 保存データが配列でない、または要素が `{ id, text, done }` の形でないなど壊れている場合は、空の一覧（0件）として扱う

## 受け入れ条件
### AC-01: 有効な入力を追加する
- Given `new-todo` に「買い物」と入力されている
- When `add` を押す
- Then 一覧の末尾に `todo-text` が「買い物」の `todo-item` が追加され、`new-todo` は空になる

### AC-02: 空白のみの入力では追加されない
- Given `new-todo` に空白のみ（`"   "`）が入力されている
- When `add` を押す
- Then 一覧に `todo-item` は追加されず、件数も変わらない

### AC-03: 完了に切り替える
- Given 「買い物」という未完了の `todo-item` が1件ある（`todo-count` は `1`）
- When その項目の `todo-toggle` をチェックする
- Then その項目は見た目で完了として区別され、一覧内の位置は変わらず、`todo-count` は `0` になる

### AC-04: 削除する
- Given 「買い物」という `todo-item` が1件ある
- When その項目の `todo-delete` を押す
- Then その項目は一覧から消え、`todo-item` は0件になる

### AC-05: 未完了の件数が表示される
- Given 項目が3件あり、そのうち1件が完了済みである
- When 一覧を表示する
- Then `todo-count` に `2` と表示される

### AC-06: 再読み込み後も内容が残る
- Given 「買い物」を追加し、別の項目を完了にした状態がある
- When ページを再読み込みして開き直す
- Then 追加した項目と完了状態がそのまま復元され、`todo-count` は再読み込み前と同じ値になる

## 決定事項
- D1: 空・空白のみの入力は追加しない（何も起きない）。重複はそのまま追加を許可し、文字数の上限は設けない（Q1）
- D2: 追加ボタンは常に押せる状態にし、無効な入力で押しても何も起きない（Q2）
- D3: 新しい項目は一覧の末尾に追加する（Q3）
- D4: 削除は確認なしで即座に行う（Q4）
- D5: 完了切替で一覧内の位置は変えない。完了した項目は見た目（取り消し線等）でのみ区別する（Q5）
