# 習慣トラッカー 外部仕様

> 毎日の習慣にチェックを付け、連続日数を追跡する。
> 習慣と各日のチェック状態、連続日数を保存する。
> 連続日数はアプリ起動時に日付を確認して判定する。

## 画面と操作

### ホーム画面
- 入力欄（`data-testid="new-habit"`）：習慣名を入力
- 「追加」ボタン（`data-testid="add-habit"`）：新しい習慣を追加
- 習慣リスト：各習慣は以下で構成（`data-testid="habit-item"`）
  - 習慣名（`data-testid="habit-name"`）：テキスト表示
  - チェックボックス（`data-testid="habit-check"`、`type="checkbox"`）：今日やったかどうか
  - 連続日数表示（`data-testid="habit-streak"`）：数字のみ
  - 削除ボタン（`data-testid="habit-delete"`）：習慣を削除

## 振る舞い

### 初期状態と操作
- アプリ起動時に保存済みの習慣一覧を読み込む
- 習慣がない場合は空の状態
- 入力欄に習慣名を入力し、「追加」ボタンをクリックするか Enter キーで新規習慣を追加
- 追加時に入力欄が空の場合は追加しない
- 追加された習慣は初期チェック状態が未チェック（false）、連続日数は 0

### チェック操作
- チェックボックスをクリックすると、その習慣の「今日のチェック状態」が反転（チェック ⇔ 未チェック）
- チェック操作は即座に保存される
- 連続日数は計算結果であり、チェック操作では直接変わらない

### 連続日数の計算
- 連続日数は「直近でチェックが切れずに続いた日数」
- アプリ起動時に「前日のチェック状態」を確認し、以下のように判定：
  - 前日がチェック済み：前日までの連続日数 + 1 日 = 今日の連続日数
  - 前日が未チェック：連続日数 = 0、かつ「今日のチェック状態」を未チェックに強制
- 開き直した日の日中は、その日の連続日数は「前日までの連続日数」を表示（翌日の起動時に判定が進む）

### 削除操作
- 「削除」ボタンをクリックすると確認ダイアログを表示
- 「OK」で削除、「キャンセル」で何もしない
- 削除された習慣はデータから完全に削除される

### 保存と復元
- すべての習慣データ（名前、チェック状態、連続日数、記録日時）を `storage.set` で保存
- アプリを閉じて開き直した時も、すべてのデータが復元される

### 日付判定
- 「今日」と「前日」の判定は、ブラウザのローカルタイムゾーン（`new Date()` の日付）で行う

## エラー時の挙動
- 入力欄が空のまま追加ボタンをクリック：何もしない、警告も表示しない
- 保存データが壊れている場合：初期状態（空の習慣リスト）で再スタート

## 受け入れ条件

### AC-01: 習慣の追加
- Given 習慣がない状態
- When 入力欄に「筋トレ」と入力して「追加」ボタンをクリック
- Then 習慣リストに「筋トレ」が表示され、チェックなし、連続日数は 0

### AC-02: 習慣のチェック
- Given 習慣「読書」がチェックなしの状態
- When チェックボックスをクリック
- Then チェックボックスがチェック状態になり、データが保存される

### AC-03: 連続日数の計算（初回）
- Given 習慣「筋トレ」が登録済みで、本日のチェックがない状態
- When チェックボックスをクリック
- Then 連続日数が 1 と表示される

### AC-04: 連続日数の計算（継続）
- Given 習慣「筋トレ」の本日チェック済み、連続日数 1 の状態
- When 明日になってアプリを開いて、チェックボックスをクリック
- Then 連続日数が 2 と表示される

### AC-05: 連続日数のリセット
- Given 習慣「筋トレ」の本日チェック済み、連続日数 2 の状態
- When 翌日になってアプリを開いたときに、チェックが未チェックのまま
- Then 連続日数が 0 にリセットされ、チェックボックスは未チェック

### AC-06: 習慣の削除
- Given 習慣「筋トレ」が登録済みの状態
- When 削除ボタンをクリック、確認ダイアログで「OK」をクリック
- Then 習慣が削除され、表示から消える

### AC-07: アプリ再起動後の復元
- Given 習慣「読書」（チェック済み、連続日数 3）が保存済み
- When アプリを閉じて開き直す
- Then 習慣「読書」がすべてのデータを保持して表示される

### AC-08: 空の入力欄で追加しない
- Given 入力欄が空の状態
- When 「追加」ボタンをクリック
- Then 何も追加されない

## 決定事項
- D1: 連続日数リセットは翌日に判定。その日の日中は前日までの連続日数を表示（A1）
- D2: 日付判定はブラウザのローカルタイムゾーン（A2）
- D3: アプリ起動時に日付変更と前日チェック状態を確認（A3）
- D4: 削除時に確認ダイアログを表示（推奨）
- D5: 習慣名の重複は不可（A5）
