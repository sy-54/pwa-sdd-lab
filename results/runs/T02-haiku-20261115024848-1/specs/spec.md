# ToDo 外部仕様

> やることを書き留めて、済んだら消し込むリスト。
> 追加・完了・削除ができ、未完了の件数が分かる。
> localStorage で永続化し、入力値の検証と完了済みの表示方法が決まっている。

## 画面と操作

**初期表示**
- ルート要素：`data-testid="app-root"`
- 入力欄：`data-testid="new-todo"`、型は `text`、プレースホルダー等は自由
- 追加ボタン：`data-testid="add"`、テキストは「追加」「Add」等自由
- タスク一覧：各項目は `data-testid="todo-item"` で、以下を含む
  - `data-testid="todo-text"`：タスクの内容（テキスト）
  - `data-testid="todo-toggle"`：`input type="checkbox"` で完了切り替え
  - `data-testid="todo-delete"`：削除ボタン
- 残り件数表示：`data-testid="todo-count"`、テキストは数字のみ（例：「3」）

**操作**
- 入力欄に文字を入力し、Enter キーまたは追加ボタンで新規タスクを追加
- チェックボックスをクリックして完了・未完了を切り替え
- 削除ボタンをクリックしてタスクを削除（確認ダイアログなし）

## 振る舞い

**初期状態**
- localStorage に保存されたタスクがあれば復元
- なければ空リスト

**タスク追加**
- 入力欄が空文字列または空白のみの場合、追加されない
- 新規タスクは一覧の一番下に追加される（入力順）
- 入力欄はクリアされる

**タスク管理**
- チェック（完了）：表示が打ち消し線になる。残り件数の分母から除外される
- 未チェック：打ち消し線が消える。残り件数に再度カウントされる
- 削除：タスク項目が一覧から消える

**保存と復元**
- タスク追加・削除・完了状態の変更のたびに localStorage に保存
- 入力欄の内容は保存しない
- アプリ再起動時に保存されたタスクが復元される

**残り件数**
- 未完了（チェックなし）のタスク数を表示
- 完了済みはカウントから除外

## エラー時の挙動

**不正な入力**
- 空文字列または空白のみ：追加ボタンが押されても何も起きない
- localStorage が利用不可の場合：エラー表示は不要（SDK がハンドル）

## 受け入れ条件

### AC-01: 新規タスク追加時に入力欄がクリアされる
- Given 入力欄に「買い物」と入力されている
- When 追加ボタンをクリック
- Then 入力欄が空になる

### AC-02: 空のタスクは追加されない
- Given 入力欄が空文字列
- When 追加ボタンをクリック
- Then タスク一覧に変化なし、`todo-count` が変わらない

### AC-03: 新規タスクは一覧の一番下に追加される
- Given 既存タスク「洗濯」「掃除」がある
- When 「買い物」を追加
- Then タスク一覧の順は「洗濯」「掃除」「買い物」

### AC-04: 残り件数は未完了のタスク数
- Given タスク「洗濯」「掃除」「買い物」がある
- When 「洗濯」をチェック
- Then `todo-count` に「2」と表示される

### AC-05: 完了済みは打ち消し線で表示
- Given タスク「洗濯」がある
- When 「洗濯」のチェックボックスをチェック
- Then `todo-text` に打ち消し線が引かれる

### AC-06: 削除ボタンでタスクが削除される
- Given タスク「洗濯」「掃除」がある
- When 「洗濯」の削除ボタンをクリック
- Then 一覧に「掃除」だけ残る、`todo-count` が「1」に更新される

### AC-07: ページ再読み込み後にデータが保持される
- Given タスク「洗濯」「掃除」（洗濯は完了）がある
- When ページを再読み込み
- Then タスク一覧と完了状態が同じ状態で復元される、`todo-count` に「1」

### AC-08: Enter キーで追加できる
- Given 入力欄に「買い物」と入力
- When Enter キーを押す
- Then タスクが追加される、入力欄がクリア

## 決定事項
- D1: 空のタスク（空文字列）は追加されない（Q1）
- D2: 「残っている件数」は未完了のタスク数を指す（Q2）
- D3: 完了したものは打ち消し線で表示される（Q3）
- D4: 新しいタスクは一覧の一番下に追加される（Q4）
- D5: タスク削除時に確認ダイアログは不要（Q5）
