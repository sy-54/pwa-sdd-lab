# 単語帳 外部仕様

> 表と裏のあるカードを登録し、学習モードでめくりながら覚える。
> 「覚えた」か「まだ」を選ぶと、「まだ」のカードは後ろに回されて繰り返し出現する。
> カード情報は永続保存するが、各セッション内の「覚えた」状態はリセットされる。

## 画面と操作

### 一覧画面
- 見えるもの：
  - テキスト入力 `card-front-input`（カードの表）
  - テキスト入力 `card-back-input`（カードの裏）
  - ボタン `add-card`（カード追加）
  - カード一覧：各カード `card-item` の中に `card-front`（表の内容）、`card-back`（裏の内容）、ボタン `card-delete`（削除）
  - ボタン `study-start`（学習開始）

### 学習画面
- 見えるもの：
  - テキスト `study-front`（カードの表）
  - テキスト `study-back`（カードの裏、めくるまで非表示）
  - ボタン `flip`（めくる）
  - ボタン `know`（覚えた）
  - ボタン `again`（まだ）
  - テキスト `study-progress`（進み具合：例 `2/5`）
- 表示：学習中だけ表示（`study-view`）

### 結果画面
- 見えるもの：
  - テキスト `result-known`（1回で覚えた枚数、数字のみ）
  - ボタン `study-finish`（一覧に戻る）
- 表示：学習が終わったときだけ表示（`study-result`）

## 振る舞い

### カード管理
- 初期状態：カードなし、入力フィールドは空
- カード追加：表と裏を入力して `add-card` ボタン押下でカード追加。入力フィールドをクリア。カード名は表示順で追加順で固定
- カード削除：`card-delete` で即座に削除。確認は不要
- 保存：カード情報はアプリを閉じて開き直しても残る

### 学習セッション
- セッション開始：カード数が1以上なら学習画面へ遷移。カード数が0なら何も起きない
- 学習中の流れ：
  1. カードの表を表示（裏は非表示）
  2. `flip` ボタンで裏を表示
  3. `know`（覚えた）を押すと、1回で覚えた枚数をカウント。次のカードへ
  4. `again`（まだ）を押すと、このカードをキューの後ろに送る。次のカードへ
  5. すべての新しいカードを見た後、「まだ」のカードだけで再度出現
  6. すべてのカードが「覚えた」状態になったら学習終了
- 1回で覚えた枚数：セッション内で初見で `know` を選んだカード数。`again` 後に `know` を選んでも数えない
- 進み具合 `study-progress`：「覚えた」カード数 / 全カード数（例 `2/5`）
- セッション状態の保存：なし。アプリを再起動したら次のセッションは最初から

### 結果表示
- 学習終了時に結果画面を表示
- `result-known`：1回で覚えた枚数を表示
- `study-finish` で一覧に戻る

## エラー時の挙動
- カード数0での学習開始：ボタンは押せるが何も起きない。メッセージなし
- 保存データ損傷：アプリ起動時に形を確認し、不正なら空カード一覧で開始

## 受け入れ条件

### AC-01: カードを追加する
- Given カードなし
- When `card-front-input` に「apple」、`card-back-input` に「りんご」を入力して `add-card` を押す
- Then `card-item` に「apple」と「りんご」が表示され、入力フィールドがクリアされる

### AC-02: カードを削除する
- Given 「apple」「りんご」のカード1枚
- When そのカードの `card-delete` を押す
- Then カードが消える

### AC-03: カード情報が永続保存される
- Given 「apple」「りんご」のカード1枚
- When アプリを閉じて開き直す
- Then カードが残っている

### AC-04: 学習画面でカードの表が表示される
- Given 「apple」「りんご」のカード1枚
- When `study-start` を押す
- Then `study-view` が表示され、`study-front` に「apple」が表示される

### AC-05: 裏をめくって表示する
- Given 学習中で「apple」を見ている
- When `flip` を押す
- Then `study-back` に「りんご」が表示される

### AC-06: 「覚えた」を選ぶと次のカードへ
- Given 「apple」「banana」のカード2枚で学習開始
- When 「apple」で `know` を押す
- Then `study-front` が「banana」に変わり、`study-progress` が「1/2」になる

### AC-07: 「まだ」を選ぶとキューの後ろへ
- Given 「apple」「banana」のカード2枚で学習開始
- When 「apple」で `again` を押す
- Then `study-front` が「banana」に変わり、apple はまだ見られない

### AC-08: 全カードを見た後、「まだ」のカードが再出現
- Given 「apple」「banana」のカード2枚、apple で `again`、banana で `know`
- When 3枚目のカードを見ようとする
- Then `study-front` が「apple」に戻る

### AC-09: 1回で覚えた枚数を計算する
- Given 「apple」「banana」のカード2枚で学習開始
- When 「apple」で `know`、「banana」で `again` を押して後で `know` を押す
- Then `result-known` に「1」と表示される

### AC-10: すべて「覚えた」で学習終了
- Given 「apple」のカード1枚で学習開始
- When 「apple」で `know` を押す
- Then `study-result` が表示される

### AC-11: 結果から一覧に戻る
- Given 結果画面
- When `study-finish` を押す
- Then 一覧画面に戻る

### AC-12: カード数0での学習開始は何も起きない
- Given カードなし
- When `study-start` を押す
- Then 学習画面に遷移しない

### AC-13: 新しいセッションは初期状態から
- Given 前のセッションで「apple」を「覚えた」
- When アプリを再起動して学習を開始
- Then `study-progress` が「0/1」から始まる

## 決定事項
- D1: 学習セッション後、「覚えた」状態は保存されない。アプリ再起動時も含めてリセット（Q1）
- D2: 「まだ」のカードはキューの後ろに送られ、すべての新しいカードを見た後に再出現。新しいラウンドではなく同じセッションの続き（Q2）
- D3: カードは常に追加順で固定、シャッフルなし（Q3）
- D4: 「1回で覚えた枚数」は現在のセッション内で初見で「覚えた」を選んだカード数（Q4）
- D5: カード数0での学習開始はボタン押下時に何も起きない。メッセージなし（Q5）
