## ラウンド1
### 質問
Q1: 分の入力値が 0、負数、小数、空、非数値のときの扱いは？
  A: 1以上の整数のみ許可。範囲外や不正な値では開始ボタンを無効化（またはエラー表示なしで開始不可）（推奨）
  B: 0や負数も許容し、0なら即 done にする

Q2: 開始（start）後、残りの入力欄（minutes）を編集できるか？
  A: カウント中は編集不可（input を disabled にする）（推奨）
  B: カウント中も編集可能だが、残り時間には反映しない（次回リセット時のみ反映）

Q3: 残り時間が 00:00 になったとき、start/pause ボタンの状態と time 表示はどうなるか？
  A: 自動的に停止し、time は `00:00` のまま、done を表示。start は「もう一度開始できない（reset必須）」として無効化（推奨）
  B: done 表示後も start を押せば同じ分数で再スタートできる

Q4: reset を押したときの残り時間は何に戻るか？
  A: 直前に入力した minutes の値（入力欄の現在値）に戻る（推奨）
  B: 常に初期値（空欄 or 0）に戻る

Q5: ページを再読み込みしたときに、進行中のカウントダウン状態を保持するか？
  A: 保持しない。再読み込みで初期状態に戻る（推奨）
  B: localStorage 等で状態を保持し、再開時に残り時間を復元する
