# タイマー 外部仕様

> 分数を入力してカウントダウンし、開始・一時停止・再開・リセットができる単一画面アプリ。
> 入力は1以上の整数のみ許可し、カウント中は入力欄を無効化、終了すると自動停止して done を表示する。
> 状態は保存せず、再読み込みで初期状態に戻る。未決事項はなし。

## 画面と操作
- `app-root` 内に以下を表示する。
- `minutes`（`input type="number"`）：カウントダウンする分数を入力する。
- `start` ボタン：カウントダウンを開始（停止中）または再開（一時停止中）する。
- `pause` ボタン：カウント中に残り時間を一時停止する。
- `reset` ボタン：カウントを停止し、残り時間を `minutes` の現在値に戻す。
- `time`：残り時間を `MM:SS` 形式で表示する（例 `03:00`）。
- `done`：時間になったとき（残り `00:00`）だけ表示する。

## 振る舞い
- 初期状態：`minutes` は空欄、`time` は `00:00`、`done` は非表示。`pause`・`reset` は無効化、`start` は `minutes` が未入力のため無効化。
- `minutes` には1以上の整数のみ入力可能とみなす。`minutes` が1以上の整数のとき `start` を有効化し、それ以外（空・0・負数・小数・非数値）のときは `start` を無効化する。
- `start` 押下（停止中）：`minutes` の値（分）を秒に変換して残り時間とし、`time` に反映してカウントダウンを開始する。`minutes` を disabled にし、`pause`・`reset` を有効化、`start` を無効化する。
- カウント中は1秒ごとに残り時間を1減らし `time` を更新する。
- `pause` 押下：カウントダウンを止める。`start`（再開用）を有効化し、`pause` を無効化する。`minutes` は disabled のままにする。
- `start` 押下（一時停止中）：止めた残り時間からカウントダウンを再開する。`pause` を有効化し `start` を無効化する。
- `reset` 押下：カウントダウンを停止し、残り時間を `minutes` の現在値（分）から再計算して `time` に反映する。`minutes` を有効化し、`done` を非表示にする。`minutes` が1以上の整数なら `start` を有効化、`pause`・`reset` を無効化する。`minutes` が不正なら `start` も無効化する。
- 残り時間が `00:00` に達したら自動的に停止し、`done` を表示する。`time` は `00:00` のまま、`start`・`pause` は無効化（reset のみ有効）にする。
- `done` 表示中に `minutes` を変更しても `time`・`done` は変化しない（`reset` を押すまで反映しない）。

## エラー時の挙動
- `minutes` が空・0・負数・小数・非数値のとき：`start` を無効化し、エラーメッセージは表示しない（押せないことで不正入力を防ぐ）。
- カウント中に `minutes` を直接書き換えることはできない（disabled のため発生しない）。

## 受け入れ条件
### AC-01: 分を指定して開始すると残り時間が表示される
- Given `minutes` に `3` を入力した状態
- When `start` を押す
- Then `time` に `03:00` と表示される

### AC-02: カウントダウン中に時間が減る
- Given `minutes` に `1` を入力し `start` を押して1秒経過した状態
- When 1秒が経過する
- Then `time` に `00:59` と表示される

### AC-03: 一時停止すると残り時間が止まる
- Given `minutes` に `1` を入力し `start` を押した状態
- When `pause` を押す
- Then `time` の表示がその時点の値で変化しなくなる

### AC-04: 一時停止後に再開できる
- Given `minutes` に `1` を入力し `start` を押した後 `pause` を押した状態
- When `start` を押す
- Then カウントダウンが再開し `time` が減り続ける

### AC-05: リセットすると入力中の分数に戻る
- Given `minutes` に `2` を入力し `start` を押して時間が進んだ状態
- When `minutes` を `5` に変えずに `reset` を押す
- Then `time` に `02:00` と表示される

### AC-06: 時間になると done が表示され自動停止する
- Given `minutes` に `1` を入力し `start` を押してカウントダウン中の状態
- When 残り時間が `00:00` になる
- Then `done` が表示され、`time` は `00:00` のままになる

### AC-07: 不正な入力では開始できない
- Given `minutes` が空欄の状態
- When 画面を確認する
- Then `start` ボタンが無効化されている

## 決定事項
- D1: `minutes` は1以上の整数のみ許可し、不正な値では `start` を無効化する（Q1）
- D2: カウント中は `minutes` を disabled にする（Q2）
- D3: `00:00` になると自動停止し `done` を表示、`start` は無効化。再開には `reset` が必要（Q3）
- D4: `reset` は `minutes` の現在値（入力欄）に戻す（Q4）
- D5: 再読み込みで状態を保持しない（初期状態に戻る）（Q5）
