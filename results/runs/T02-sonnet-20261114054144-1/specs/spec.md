# ToDo 外部仕様

> 入力欄とボタン1つで、やることを末尾に追加し、チェックで完了・未完了を切り替え、ボタンで即削除する単一画面。
> 項目は追加順を保ったまま保存し、再読み込み後も復元する。件数表示は未完了のみを数える。
> 未決事項なし。重複チェックなし・確認なし削除など、Q1〜Q5の回答どおりに実装する想定でレビューしてほしい。

## 画面と操作
- ルート要素 `data-testid="app-root"`。画面は1つだけ。
- 入力欄 `data-testid="new-todo"`（テキスト）と追加ボタン `data-testid="add"`。
- 一覧は `data-testid="todo-item"` の繰り返し。各項目に `data-testid="todo-text"`（内容）、`data-testid="todo-toggle"`（`input type="checkbox"`）、`data-testid="todo-delete"`（ボタン）を持つ。
- 残り件数 `data-testid="todo-count"`（テキストは数字のみ）。
- 完了した項目は見た目（例：文字に打ち消し線）で未完了と区別する。

## 振る舞い
- 初期状態：保存データがなければ項目0件、`todo-count` は「0」。
- 追加：`new-todo` の値の前後の空白を除いた文字列を、未完了の新規項目としてリストの**末尾**に追加し、入力欄を空にする。
- 入力欄が空、または空白のみのときは `add` を押しても何も起きない（追加せず、入力欄もそのまま）。
- 同じ内容の項目が既にあっても重複チェックはせず、そのまま新しい項目として追加する。
- 完了切り替え：`todo-toggle` の操作でその項目の完了／未完了を切り替える。並び順は変わらない（追加順を常に保つ。並べ替え機能はない）。
- 削除：`todo-delete` を押すと、確認なしでその項目を即座に削除する。
- `todo-count` は未完了の項目数のみを表示する（完了済みは数えない）。
- 保存：追加・切り替え・削除のたびに `storage` へ保存する。再度開いたときは保存された内容・並び順・完了状態をそのまま復元する。

## エラー時の挙動
- 保存データが壊れている（配列でない、要素の形が不正など）場合は、読めなかったデータを無視し、項目0件として起動する（`todo-count` は「0」）。
- `storage.set` に失敗した場合は、画面表示は変更前のまま保ち、`ui.toast` でエラーを知らせる。

## 受け入れ条件
### AC-01: 追加すると末尾に表示される
- Given 項目が0件
- When `new-todo` に「牛乳を買う」と入力して `add` を押す
- Then `todo-item` が1件表示され、その `todo-text` は「牛乳を買う」、`todo-count` は「1」

### AC-02: 空文字では追加されない
- Given 項目が0件
- When `new-todo` を空のまま `add` を押す
- Then `todo-item` は0件のまま、`todo-count` は「0」

### AC-03: 完了を切り替えると件数が減る
- Given 未完了の項目が1件（`todo-count` が「1」）
- When その項目の `todo-toggle` をチェックする
- Then `todo-count` は「0」になり、その項目は見た目で完了として区別される

### AC-04: 削除すると確認なしで即座に消える
- Given 項目が1件
- When その項目の `todo-delete` を押す
- Then 確認ダイアログは出ずに `todo-item` が0件になり、`todo-count` は「0」

### AC-05: 再読み込みで内容と並び順が残る
- Given 「牛乳を買う」「卵を買う」の順で2件追加し、「牛乳を買う」を完了にした状態
- When アプリを再読み込みする
- Then 同じ2件が同じ並び順（「牛乳を買う」が先）で表示され、「牛乳を買う」は完了のまま、`todo-count` は「1」

### AC-06: 壊れた保存データでも起動できる
- Given 保存データが不正な形（配列でない値）になっている
- When アプリを開く
- Then エラーにならず `todo-item` は0件、`todo-count` は「0」で表示される

## 決定事項
- D1: 新規項目はリストの末尾に追加する（Q1）
- D2: 入力欄が空または空白のみなら何もしない（Q2）
- D3: 削除は確認なしで即削除する（Q3）
- D4: `todo-count` は未完了の項目数のみを数える（Q4）
- D5: 同じ内容でも重複チェックせずそのまま追加する（Q5）
