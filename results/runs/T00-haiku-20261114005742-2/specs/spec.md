# カウンタ 外部仕様

> ボタンで数を増やす・減らす・リセットするカウンタアプリ。
> 値は localStorage に保存され、アプリを閉じても残る。
> 負数にはならず、0未満にはボタンで到達しない。

## 画面と操作
- `data-testid="app-root"` がルート要素
- `data-testid="count"` に現在の数値がテキストのみで表示（例：「5」）
- 3つのボタン：
  - `data-testid="inc"`: 現在値を 1 増やす
  - `data-testid="dec"`: 現在値を 1 減らす（0未満にはならない）
  - `data-testid="reset"`: 現在値を 0 にリセット

## 振る舞い
- **初期状態**：ページを初めて開いたときは 0 を表示
- **増減**：ボタン押下で 1 ずつ増減し、画面に反映
- **下限**：現在値が 0 のとき、dec ボタン押下は値を変わらない（負数にならない）
- **上限**：なし、いくらでも増やせる
- **保存**：値を変更するたびに localStorage の `counter-value` キーに保存
- **復元**：ページを再読み込みしたとき、localStorage から値を復元して表示

## エラー時の挙動
- localStorage の値が不正な形式（非整数など）だった場合は、0 として扱う
- localStorage から値を読み取れない場合は、0 から開始

## 受け入れ条件

### AC-01: 初期状態は 0
- Given ページを初めて開いた状態（localStorage は空）
- When ページが読み込まれた直後
- Then `count` に 0 と表示される

### AC-02: +ボタンで 1 増える
- Given `count` が 3 のとき
- When `inc` ボタンを押す
- Then `count` に 4 と表示される

### AC-03: -ボタンで 1 減る
- Given `count` が 5 のとき
- When `dec` ボタンを押す
- Then `count` に 4 と表示される

### AC-04: 0未満にはならない
- Given `count` が 0 のとき
- When `dec` ボタンを押す
- Then `count` に 0 と表示されたまま

### AC-05: リセットボタンで 0 に戻る
- Given `count` が 7 のとき
- When `reset` ボタンを押す
- Then `count` に 0 と表示される

### AC-06: 値が localStorage に保存される
- Given ページを開き `count` を 5 に変更した後
- When ページを再読み込みする
- Then `count` に 5 と表示される

### AC-07: 壊れた保存データは 0 にリセット
- Given localStorage に不正な値（「abc」など）が保存されている状態
- When ページを読み込む
- Then `count` に 0 と表示される

## 決定事項
- D1: 初期値は 0、負数は許可されない、上限値なし（Q1-A）
- D2: ストレージ実装は localStorage（Q2 より、シンプルさから採用）
- D3: リセットボタンは 0 にリセット（Q3-A）
- D4: フォント・レイアウトは実装者の判断に任せる（Q4-A）
