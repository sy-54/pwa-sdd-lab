# カウンタ 外部仕様

> ボタンで数値を増減・リセットする単一画面アプリ。増減の幅を1/5/10から選び、目標値に達したら表示する。値とステップと目標はlocalStorageに自動保存し、再読み込み後も復元する。
> カウント値は0以上の整数、ステップは1/5/10いずれか、目標は1以上の整数または未設定、上限なし。旧バージョンで保存したデータは、ステップ=1、目標=未設定として初期化。
> 未決事項なし。

## 画面と操作
- ルート要素 `data-testid="app-root"` 内に、現在値表示 `data-testid="count"`（数字のみのテキスト）、ボタン3つ（`data-testid="inc"`、`"dec"`、`"reset"`）、ステップ選択 `data-testid="step"`（`select`、値は `1` / `5` / `10`）、目標入力 `data-testid="goal"`（`input type="number"`）、達成表示 `data-testid="goal-reached"`（目標達成中だけ表示）を表示する。
- `inc` を押すと現在値に選択されたステップ値を加算する。
- `dec` を押すと現在値から選択されたステップ値を減算する。ただし0未満にはしない。
- `reset` を押すと現在値を0にする。
- `step` で 1 / 5 / 10 から増減の幅を選ぶ。
- `goal` に1以上の整数を入力すると、その値を目標に設定する。空欄または0を入力すると目標をなしにする。
- 現在値が目標以上の場合、`goal-reached` に達成を表示する。目標がないか現在値が目標未満の場合は表示しない。

## 振る舞い
- 初期状態：保存データがなければ `count` は0、`step` は1、`goal` は未設定（空欄）。
- 状態が変わるたび（inc / dec / reset / step 変更 / goal 変更）に、すべての値（count、step、goal）をlocalStorageへ即時保存する。
- 再読み込み時：保存値があればそれぞれを復元し表示する。旧バージョンで保存されたデータ（step と goal の情報がない）を読み込んだ場合は、step=1、goal=未設定として初期化し、新フォーマットで上書き保存する。
- 下限は0。`dec` は0のとき何もしない（0のまま）。
- 上限なし（実質 `Number.MAX_SAFE_INTEGER` まで、それ以上の挙動は規定しない）。
- 目標達成判定：現在値 >= 目標値（1以上の整数）のとき「達成」。目標が未設定または0のときは達成表示なし。

## エラー時の挙動
- count：保存データが存在しない、パースできない、0以上の整数でない場合は0として扱い、上書き保存する。
- step：保存データが存在しない、1 / 5 / 10 のいずれでもない場合は1として扱い、上書き保存する。
- goal：保存データが存在しない、またはパースできない場合は未設定（空欄）として扱い、上書き保存する。1未満の値（0や負数）は未設定と同じく扱う。

## 受け入れ条件
### AC-01: 初期表示
- Given localStorageに保存データがない状態でアプリを開く
- When 画面を表示する
- Then `count` に `0` と表示される

### AC-02: incで増える
- Given `count` が `0` の状態
- When `inc` を1回押す
- Then `count` に `1` と表示される

### AC-03: decは0未満にならない
- Given `count` が `0` の状態
- When `dec` を1回押す
- Then `count` に `0` と表示される

### AC-04: resetで0に戻る
- Given `count` が `3` の状態（`inc` を3回押した状態）
- When `reset` を押す
- Then `count` に `0` と表示される

### AC-05: 再読み込みで値が残る
- Given `inc` を2回押して `count` が `2` の状態
- When ページを再読み込みする
- Then `count` に `2` と表示される

### AC-06: 壊れた保存データは0として初期化
- Given localStorageの保存値が不正な文字列（数値でも整数でもない値）になっている状態
- When 画面を表示する
- Then `count` に `0` と表示され、保存データも `0` に上書きされる

### AC-07: stepで5を選ぶと5ずつ増える
- Given `count` が `0`、`step` が `1` の状態
- When `step` を `5` に変更して `inc` を2回押す
- Then `count` に `10` と表示される

### AC-08: stepで10を選ぶと10ずつ減る
- Given `count` が `20`、`step` が `1` の状態
- When `step` を `10` に変更して `dec` を1回押す
- Then `count` に `10` と表示される

### AC-09: goalに数値を入力する
- Given ページ表示直後、`goal` が空欄の状態
- When `goal` に `5` を入力する
- Then `goal` に `5` が表示される

### AC-10: 現在値が目標以上で達成表示
- Given `count` が `3`、`goal` が `5` の状態
- When `inc` を3回押して `count` を `6` にする
- Then `goal-reached` が表示される

### AC-11: 目標未満では達成表示なし
- Given `count` が `2`、`goal` が `5` の状態
- When ページを表示する
- Then `goal-reached` は表示されない

### AC-12: goalに0を入力すると目標なし
- Given `count` が `5`、`goal` が `10` で `goal-reached` が表示される状態
- When `goal` を `0` に変更する
- Then `goal-reached` は表示されない

### AC-13: goalを空欄にすると目標なし
- Given `count` が `5`、`goal` が `10` で `goal-reached` が表示される状態
- When `goal` を空欄にする
- Then `goal-reached` は表示されない

### AC-14: stepと目標が保存される
- Given `count` が `2`、`step` が `5`、`goal` が `10` の状態
- When ページを再読み込みする
- Then `count` に `2`、`step` に `5`、`goal` に `10` が表示される

### AC-15: 旧バージョンデータはstep=1, goal=未設定で初期化
- Given localStorageに `count` だけが保存されている状態（step と goal の情報がない）
- When ページを表示する
- Then `count` は保存値、`step` に `1`、`goal` が空欄で表示される

## 決定事項
- D1: `dec` は0で下限、0未満にならない（Q1）
- D2: `reset` は常に0に戻す（Q2）
- D3: 増減のステップは1/5/10から選択可能（Q3改訂）
- D4: 上限なし（実質無制限）（Q4）
- D5: 壊れた保存データは0として初期化し上書きする（Q5）
- D6: 目標値の初期状態は未設定（空文字列）で、1以上の整数のときだけ有効（Q1改訂）
- D7: ステップ変更時に選択値で増減する（Q2改訂）
- D8: ステップと目標値はlocalStorageに保存する（Q3改訂）
- D9: 現在値が目標以上なら即座に達成表示を出す（Q4改訂）
- D10: 旧バージョンデータはstep=1、goal=未設定として初期化（Q5改訂）
