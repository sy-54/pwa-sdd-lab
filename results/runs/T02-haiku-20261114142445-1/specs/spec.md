# ToDo 外部仕様

> やることを入力欄に書いて追加。チェックボックスで完了を切り替え、削除ボタンで取り消しできる。
> データはアプリを閉じても保存され、常に未完了の件数が表示される。
> 完了した項目は取り消し線で表示。

## 画面と操作

### 入力と追加
- 入力欄（`data-testid="new-todo"`）：やることのテキストを入力
  - Enter キーで追加ボタンと同じ動作
  - 入力欄の右に追加ボタン（`data-testid="add"`）
- 追加ボタン（`data-testid="add"`）：入力欄の内容を追加

### リスト表示
- 各項目は `data-testid="todo-item"` の要素（ul/li 想定）
  - 項目内容を表示（`data-testid="todo-text"`）
  - チェックボックス（`data-testid="todo-toggle"`、`input type="checkbox"`）：クリックで完了を切り替える
  - 削除ボタン（`data-testid="todo-delete"`）：クリックで削除
  - 完了時は項目全体に取り消し線を表示
  - 新しい項目はリストの下（最後）に追加

### 件数表示
- 未完了の件数を表示（`data-testid="todo-count"`）
  - テキストは数字のみ（例：「3」「0」）
  - 未完了の項目の数に自動更新

## 振る舞い

### 初期状態と読み込み
- アプリ起動時、保存されているやることの一覧を表示
- 初回起動（何も保存されていない）：リストは空で件数は「0」

### 追加時の動作
- 入力欄のテキストを新しい項目として追加
  - 項目はリストの最後に追加
  - 追加直後、入力欄は空になる
  - 未完了の件数が自動更新
- 保存は `storage.set('items', items)` で行う

### 完了の切り替え
- チェックボックスをクリック：完了 ↔ 未完了 を切り替える
  - 完了時：項目全体に取り消し線を表示、件数を−1
  - 未完了に戻す時：取り消し線を消す、件数を+1
- 変更直後に保存

### 削除
- 削除ボタンをクリック：その項目をリストから削除（確認なし）
- 削除後、リストから消える
- 削除した項目が未完了だった場合、件数を−1
- 削除後に保存

### 保存と復元
- すべての変更（追加・完了切り替え・削除）は即座に `storage.set('items', ...)` で保存
- 配列の形式：`[{ text: "...", completed: false }, ...]`
- アプリを再度開く時、保存されたデータから復元

## エラー時の挙動

### 空または空白のみの入力
- 追加ボタンまたは Enter を押した時、何もしない（警告なし）
- 入力欄は空のまま
- 見た目は変わらない

### 保存失敗
- `storage.set()` が例外を投げた場合：エラーを console に記録し、トーストで「保存に失敗しました」と表示
- データはメモリ上の状態で継続（リロード後は最後に成功した状態に戻る）

### 壊れたデータ
- 読み込んだデータが配列でない、または要素が `{ text, completed }` 形式でない場合
- 空の配列として扱い、リセットして表示
- トーストで「データをリセットしました」と表示

## 受け入れ条件

### AC-01: やることを追加できる
- Given 入力欄に「買い物」と入力
- When 追加ボタンをクリック
- Then リストの最後に「買い物」が表示され、`todo-count` に「1」と表示される

### AC-02: 複数のやることを追加できる
- Given 「買い物」と「勉強」を順番に追加
- When 2番目の項目を追加
- Then リストに上から「買い物」「勉強」の順で表示され、`todo-count` に「2」と表示される

### AC-03: Enter キーでも追加できる
- Given 入力欄に「返電話」と入力
- When Enter キーを押す
- Then リストに「返電話」が追加され、入力欄が空になる

### AC-04: 空欄で追加できない
- Given 入力欄が空のままか空白のみ
- When 追加ボタンをクリック
- Then リストは変わらず、`todo-count` も変わらない

### AC-05: 完了に切り替えられる
- Given リストに「買い物」が表示されている
- When 「買い物」の `todo-toggle` チェックボックスをクリック
- Then 「買い物」に取り消し線が表示され、`todo-count` が1減る

### AC-06: 完了を未完了に戻せる
- Given 「買い物」が完了（取り消し線表示）
- When チェックボックスをクリック
- Then 取り消し線が消え、`todo-count` が1増える

### AC-07: 削除できる
- Given リストに「買い物」「勉強」が表示され、`todo-count` に「2」と表示
- When 「買い物」の `todo-delete` ボタンをクリック
- Then 「買い物」がリストから消え、「勉強」のみ表示され、`todo-count` に「1」と表示される

### AC-08: 完了した項目を削除すると件数が変わらない
- Given 「買い物」が完了（取り消し線表示）で `todo-count` に「0」
- When 「買い物」の `todo-delete` ボタンをクリック
- Then 「買い物」がリストから消え、`todo-count` は「0」のまま

### AC-09: アプリを閉じて開き直すと内容が残る
- Given やることを3個追加し、1個を完了、1個を削除（未完了1個、完了1個が残る）
- When アプリを閉じて再度開く
- Then 最後に表示していたリストが復元され、`todo-count` に「1」と表示される

### AC-10: 未完了の件数のみカウント
- Given 「買い物」「勉強」「返電話」を追加
- When 「買い物」と「勉強」を完了
- Then `todo-count` に「1」と表示される（未完了は「返電話」のみ）
