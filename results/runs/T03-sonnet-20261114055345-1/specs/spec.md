# 写真メモ 外部仕様

> 撮影ボタンで写真を撮り、一言メモを付けて一覧に残す。新しい写真が一覧の先頭に来る。
> 写真とメモは1つの配列として `storage` に保存し、再読み込み後も復元する。
> 未決事項なし。レビューは削除確認とキャンセル時の挙動を重点的に見てほしい。

## 画面と操作
- ルート要素 `data-testid="app-root"`。上部に撮影ボタン `data-testid="shoot"`
- 一覧（新しい順）：各写真を `data-testid="memo-item"` で表示し、中に
  - `data-testid="memo-img"`（`img`、写真のサムネイル表示）
  - `data-testid="memo-caption"`（`input type="text"`、メモの一言。初期値は空文字）
  - `data-testid="memo-delete"`（削除ボタン）
- 写真が1枚もないとき：`data-testid="memo-empty"` を表示。1枚以上あるときは非表示（`hidden` 属性）
- 撮影ボタン押下で `camera.takePhoto()` を呼ぶ

## 振る舞い
- 初期状態：起動時に `storage` から一覧を読み、0件なら `memo-empty` を表示し一覧は空
- 撮影：`camera.takePhoto()` が Blob を返したら、新しい項目（写真・空メモ）を一覧の先頭に追加して保存する
- 並び順：常に「撮影した順で新しい方が先頭」。削除や再読み込みで順序は変わらない
- メモ編集：`memo-caption` の `input` イベントが起きるたびに、その項目のメモを更新して保存する（保存ボタンはない）
- メモの文字数に上限は設けない
- 削除：`memo-delete` 押下で `ui.confirm()` を表示する。OK なら対象の項目を一覧から消して保存する。キャンセルなら一覧・保存データとも変化しない
- 保存：一覧（写真Blobとメモを含む配列）を1つのキーとして `storage.set` する。変更（追加・編集・削除）のたびに全体を書き直す
- 復元：アプリを開き直すと、保存されている一覧がそのまま表示される

## エラー時の挙動
- 撮影キャンセル（`camera.takePhoto()` が `null`）：一覧に何も追加せず、画面に変化もメッセージも出さない
- 保存データの形が不正（配列でない、要素が壊れている等）：読めない項目は無視し、使える項目だけを表示する。全て読めない場合は0件として `memo-empty` を表示する。エラーメッセージは出さない

## 受け入れ条件
### AC-01: 撮影すると一覧の先頭に追加される
- Given 一覧に写真が0件
- When 撮影ボタン `shoot` を押し、`camera.takePhoto()` が写真を返す
- Then `memo-item` が1件表示され、その `memo-img` に撮った写真が表示される

### AC-02: 新しい写真が先頭に来る
- Given 一覧に写真Aが1件ある
- When 撮影して写真Bを追加する
- Then 一覧の先頭（1件目）の `memo-item` が写真Bで、2件目が写真Aである

### AC-03: メモを入力すると自動保存される
- Given 一覧に写真が1件ある
- When その `memo-caption` に「駐車場3F」と入力する
- Then 画面を再読み込みすると、同じ項目の `memo-caption` の値が「駐車場3F」である

### AC-04: 削除を確認して消す
- Given 一覧に写真が1件ある
- When `memo-delete` を押し、`ui.confirm` で OK を選ぶ
- Then 一覧から `memo-item` が消え、画面を再読み込みしても0件のままである

### AC-05: 削除をキャンセルすると何も変わらない
- Given 一覧に写真が1件ある
- When `memo-delete` を押し、`ui.confirm` で キャンセル を選ぶ
- Then `memo-item` は1件のまま残っている

### AC-06: 写真が0件のときは分かる
- Given 一覧に写真が0件
- When 画面を表示する
- Then `memo-empty` が表示され、`memo-item` は存在しない

### AC-07: 開き直しても残る
- Given 写真1件とメモ「3F」を保存した状態
- When アプリを開き直す
- Then `memo-item` が1件表示され、`memo-caption` の値が「3F」である

### AC-08: 撮影をキャンセルすると何も追加されない
- Given 一覧に写真が0件
- When 撮影ボタン `shoot` を押し、`camera.takePhoto()` が `null` を返す
- Then 一覧は0件のままで `memo-empty` が表示されている

## 決定事項
- D1: 一覧の並び順は新しい撮影ほど先頭（Q1）
- D2: 削除前に `ui.confirm` で確認し、キャンセルなら何も変わらない（Q2）
- D3: メモは `input` イベントごとに自動保存する（Q3）
- D4: メモの文字数に上限は設けない（Q4、お任せのため推奨案を採用）
- D5: 撮影キャンセル時は一覧に何も追加せず、メッセージも表示しない（Q5、お任せのため推奨案を採用）
