# 単語帳 外部仕様

> カードを追加して、表から裏へめくりながら学習するアプリ。
> 学習中は「覚えた」「まだ」を付け、覚えたカードは進み、「まだ」は末尾に移る。
> カードはアプリ再起動後も残り、学習中に閉じた場合は一覧に戻る。

## 画面と操作

### 一覧画面（デフォルト）
- テキスト入力 `card-front-input`（カードの表）、`card-back-input`（裏）
- 追加ボタン `add-card`
- 追加済みカード一覧：各カード `card-item` 内に表 `card-front` と裏 `card-back`、削除ボタン `card-delete`
- 学習開始ボタン `study-start`

### 学習画面 `study-view`（学習中だけ表示）
- 進捗表示 `study-progress`：「覚えた数／全体数」（例 `2/5`）
- カード表面 `study-front`：常に見える
- めくるボタン `flip`：押すと裏が見える
- カード裏面 `study-back`：めくるまで非表示
- ボタン `know`（「覚えた」）、`again`（「まだ」）

### 結果画面 `study-result`（学習完了時だけ表示）
- 1回で覚えた枚数 `result-known`（数字のみ）
- 一覧へ戻るボタン `study-finish`

## 振る舞い

**初期状態**
- 一覧画面表示、カード 0 枚、入力フィールドクリア

**カード追加**
- 表と裏を入力してボタンを押すと、末尾に追加される
- 入力フィールドはクリアされる

**カード削除**
- 削除ボタンを押すと即座に削除（確認なし）

**学習開始**
- カード 0 枚のとき：ボタンは disabled またはクリックしても何もしない
- カード 1 枚以上：学習画面に遷移、表が見える状態で開始

**学習中の操作**
- `flip` で裏が見える（複数回めくり可）
- `know` で「覚えた」として記録→次のカードへ
- `again` で「まだ」として記録→このカードを末尾に追加、次のカードへ

**学習完了**
- すべてのカードが「覚えた」状態になったら結果画面を表示
- `study-result` に「初回で覚えた枚数」を表示（最初から「覚えた」を選んだカード数）

**データ保存と復元**
- カード一覧は SDK `storage` で永続化（アプリ再起動後も残る）
- 学習中のデータ（進行状態、「まだ」リスト）は保存しない
  - 学習中にアプリを閉じて開き直したら、一覧画面に戻る

## エラー時の挙動

**保存データが壊れていた場合**
- カード一覧は空で開始

**カード 0 枚で学習開始を試みた場合**
- 何もしない（ボタンが disabled なら推奨）

## 受け入れ条件

### AC-01: 初期状態
- Given アプリを開いた直後
- When ページを見る
- Then `card-front-input` と `card-back-input` が空、`study-start` が表示される

### AC-02: カード追加
- Given 一覧画面でカードが 0 枚
- When `card-front-input` に「Apple」、`card-back-input` に「リンゴ」と入力して `add-card` をクリック
- Then `card-item` に「Apple」「リンゴ」が表示され、入力フィールドが空になる

### AC-03: 複数カード追加
- Given 一覧画面
- When カード 3 枚を順に追加
- Then 3 枚すべてが末尾順で表示される

### AC-04: カード削除
- Given 一覧画面にカードが 3 枚
- When 1 番目のカードの `card-delete` をクリック
- Then そのカードが削除され、残り 2 枚が表示される

### AC-05: カード 0 枚で学習開始ボタン
- Given 一覧画面、カード 0 枚
- When `study-start` を見る
- Then ボタンが disabled または無効化されている、またはクリックしても何もしない

### AC-06: 学習開始
- Given 一覧画面にカード 2 枚（表「Cat」「Dog」）
- When `study-start` をクリック
- Then `study-view` が表示され、`study-front` に「Cat」、`study-progress` に「0/2」が表示される

### AC-07: 学習中にめくる
- Given 学習画面で表が見えている状態
- When `flip` をクリック
- Then `study-back` が表示される（複数回めくり可）

### AC-08: 学習画面で「覚えた」
- Given 学習画面、1 番目のカード（表「Cat」）が見える状態
- When `know` をクリック
- Then 2 番目のカード（表「Dog」）が見える状態になり、`study-progress` が「1/2」に更新される

### AC-09: 学習画面で「まだ」
- Given 学習画面、1 番目のカード（表「Cat」）が見える状態
- When `again` をクリック
- Then 2 番目のカード（表「Dog」）が見える状態になり、1 番目のカードが末尾に移る

### AC-10: 学習完了
- Given 学習画面、すべてのカードを「覚えた」で処理
- When 最後のカードで `know` をクリック
- Then `study-result` が表示され、`result-known` にその回で「覚えた」を選んだ枚数が表示される

### AC-11: 結果から一覧へ戻る
- Given 結果画面
- When `study-finish` をクリック
- Then 一覧画面に戻り、カード一覧は変わっていない

### AC-12: アプリ再起動後のカード保存
- Given 一覧画面にカード 2 枚を追加済み
- When アプリを完全に閉じて再度開く
- Then カード 2 枚が表示される

### AC-13: 学習中に閉じて再度開く
- Given 学習中（1 番目のカード表示状態）
- When アプリを閉じて再度開く
- Then 一覧画面に戻り、学習データは保存されていない

## 決定事項
- D1: 学習中に「まだ」を選んだカードは末尾に追加される（Q3）
- D2: 学習中にアプリを閉じた場合、一覧に戻る（Q2）
- D3: カード削除時に確認ダイアログは不要、即座に削除（Q5）

## 未決事項
- 「1回で覚えた枚数」：初回で「覚えた」を選んだカード数（※繰り返し出たカードで再度「覚えた」を選んでも数えない）と仮採用。Q1 については、カード 0 枚時は disabled にすると仮採用。
- 空のテキストでのカード追加：許可する（表または裏が空でもカード追加可）と仮採用。
- 表と裏が同じ内容のカード：許可する（検証なし）と仮採用。
