# ToDo 外部仕様

> やることを入力して追加ボタンを押すと、リストの下にアイテムが追加される。
> 完了済みアイテムは打ち消し線で表示。残り（未完了）件数が常に表示される。
> 削除は確認なしで即座。ページをリロードしてもデータが残る。

## 画面と操作

| 要素 | data-testid | 説明 |
|---|---|---|
| 入力欄 | `new-todo` | やることを入力。入力内容が空白のみの場合、追加ボタンが無効 |
| 追加ボタン | `add` | クリックで新しいアイテムを追加。入力後は入力欄をクリア |
| 各アイテム | `todo-item` | リストの各項目を囲む要素 |
| アイテム内容 | `todo-text` | やることの文字。完了時は打ち消し線 |
| チェックボックス | `todo-toggle` | `input[type="checkbox"]`。クリックで完了／未完了を切り替え |
| 削除ボタン | `todo-delete` | クリックでアイテムを即座に削除（確認なし） |
| 残り件数 | `todo-count` | 未完了アイテムの個数。テキストは数字のみ |

## 振る舞い

- **初期状態**：保存されたアイテムを読み込む。初回は空
- **追加時**：空白のみは追加しない。有効な入力の場合、リストの下に追加
- **完了切り替え**：チェックボックスで切り替え。完了時は `todo-text` に打ち消し線
- **削除**：確認なしで即座に削除
- **残り件数**：未完了アイテムのみカウント。完了アイテムは含まない
- **リストが空**：メッセージなし。空のリストのまま表示
- **保存**：操作のたびに storage に保存（追加・完了切り替え・削除）
- **再読み込み**：保存されたデータが復元される

## エラー時の挙動

- **壊れた保存データ**：アイテム配列を初期化（空配列から再開）

## 受け入れ条件

### AC-01: アイテムを追加する
- Given 空のリスト
- When 入力欄に「買い物」と入力し、追加ボタンをクリック
- Then `todo-item` が1つ表示され、`todo-text` に「買い物」と表示される

### AC-02: 複数追加は順序が保たれる
- Given `todo-item` に「買い物」がある、`todo-count` に 1 と表示
- When 入力欄に「レポートを書く」と入力し、追加ボタンをクリック
- Then `todo-count` に 2 と表示され、「レポートを書く」が「買い物」の下に表示される

### AC-03: 完了をトグルして見た目が変わる
- Given `todo-text` に「買い物」がある（未完了）
- When `todo-toggle` をクリック
- Then `todo-text` に打ち消し線が表示される

### AC-04: 削除するとアイテムが消える
- Given `todo-item` に「買い物」がある
- When `todo-delete` をクリック
- Then `todo-item` が削除される

### AC-05: 完了アイテムは残り件数に含まれない
- Given `todo-item` に「買い物」（完了）と「レポートを書く」（未完了）がある
- When 状態確認
- Then `todo-count` に 1 と表示される

### AC-06: ページをリロードするとデータが残る
- Given `todo-item` に「買い物」（完了）と「レポート」（未完了）がある、`todo-count` に 1 と表示
- When ページをリロード
- Then `todo-item` が2つ表示され、「買い物」に打ち消し線がある、`todo-count` に 1 と表示される

### AC-07: 空白のみは追加されない
- Given 入力欄に「  」（スペースのみ）と入力
- When 追加ボタンをクリック
- Then 何も起こらない

### AC-08: 入力がないと追加ボタンが無効
- Given 入力欄が空
- When 状態確認
- Then 追加ボタンが無効（操作不可）

## 決定事項

- D1: 削除時に確認ダイアログは表示しない。確認なしで即座に削除（Q1）
- D2: 完了済みアイテムは打ち消し線で表示（Q2）
- D3: 新しいアイテムはリストの下に追加（Q3）
- D4: 空欄や空白のときは追加しない。入力があるときだけボタンが有効（Q4、推奨を採用）
- D5: リストが空のときはメッセージなし（Q5、推奨を採用）
