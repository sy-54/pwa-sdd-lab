# タイマー 外部仕様

> 分を入力してカウントダウンタイマーを開始。開始・一時停止・リセットで制御し、時間終了時に通知と画面表示。
> 初期値 3 分、1～99 分の範囲。状態は minutes 入力フィールドの変更で反映され、done は リセット時に消える。
> SDK の通知機能を使用。エラーハンドリング不要（UI契約で定義済み）。

## 画面と操作
- 分の入力フィールド：`data-testid="minutes"` type="number"、初期値 3、表示値 1～99
- 残り時間表示：`data-testid="time"` テキスト、`MM:SS` 形式（例 03:00）、初期値 03:00
- 開始ボタン：`data-testid="start"` テキスト「開始」（カウント中なら「再開」に見えるが testid は同じ）、クリックで開始・再開
- 一時停止ボタン：`data-testid="pause"` テキスト「一時停止」、クリックで一時停止
- リセットボタン：`data-testid="reset"` テキスト「リセット」、クリックでリセット
- 終了表示：`data-testid="done"` テキスト「終了」、時間になったときだけ表示、リセット時に非表示

## 振る舞い
- **初期状態**：minutes = 3、time = "03:00"、done は非表示、タイマーは停止状態
- **minutes 変更時**：
  - time を新しい値に更新（例 minutes = 5 → time = "05:00"）
  - カウント中なら一時停止（time は変更後の値で停止）
  - done は非表示に戻す
- **start ボタン**：カウントダウン開始。毎秒 time を `MM:SS` 形式で更新
- **pause ボタン**：カウントダウン一時停止。time はそのまま保持
- **reset ボタン**：
  - minutes の値にリセット（例 minutes = 5 なら time = "05:00"）
  - done を非表示に戻す
  - タイマーは停止状態
- **時間終了**：
  - time が "00:00" に到達したら、SDK の通知機能で通知を送信
  - done を表示
  - タイマーは停止状態（さらにカウントダウンしない）

## エラー時の挙動
- **不正入力**：minutes フィールドは `input type="number"` で制御。UI契約で範囲 1～99 を想定。範囲外の入力は防止（HTML属性 min/max で対応）
- **壊れた保存データ**：なし（ローカルストレージ等の永続化なし）

## 受け入れ条件

### AC-01: 初期状態
- Given アプリ起動直後
- When （なし）
- Then minutes に 3 が表示され、time に "03:00" が表示され、done は非表示

### AC-02: 分の入力で時間を変更
- Given minutes = 3、time = "03:00"
- When minutes フィールドを 5 に変更
- Then time に "05:00" が表示される

### AC-03: 開始ボタンでカウントダウン開始
- Given minutes = 3、time = "03:00"、タイマー停止状態
- When start ボタンをクリック
- Then 1秒後に time が "02:59" に更新される

### AC-04: 一時停止ボタンで一時停止
- Given time = "02:30" でカウント中
- When pause ボタンをクリック
- Then time は "02:30" で停止し、それ以上カウントダウンしない

### AC-05: リセットボタンでリセット
- Given time = "01:45"、done が表示されている
- When reset ボタンをクリック
- Then time が "03:00" に戻り、done は非表示

### AC-06: 時間終了で通知と done 表示
- Given time = "00:01" でカウント中
- When 1秒以上経過して time が "00:00" に到達
- Then done に「終了」が表示され、SDK の通知機能で通知が送信される

### AC-07: minutes 変更中にカウント中なら一時停止
- Given time = "02:30" でカウント中
- When minutes フィールドを 5 に変更
- Then カウントダウンが停止し、time が "05:00" に更新される

## 決定事項
- D1: SDK の通知機能を使って通知し、画面にも「終了」を表示。音は不要（A1）
- D2: 初期値 3 分、1～99 分の範囲（A2）
- D3: done はリセットボタンが押されたときのみ消える（A3）
