# 単語帳 外部仕様

> 一覧画面でカード（表と裏）を追加・削除し、学習画面で1枚ずつめくりながら「覚えた」「まだ」を付けて進む。
> データは端末に保存され、アプリを閉じて開き直してもカードが残る。
> 決定事項は Q1～Q5 で、未決事項なし。

## 画面と操作

### 一覧画面（初期表示）
- 置くファイル：`apps/flashcards/index.html`、`apps/flashcards/manifest.json`
- ルート要素：`data-testid="app-root"`
- 入力欄：`card-front-input`（表の入力）、`card-back-input`（裏の入力）
- 「追加」ボタン：`data-testid="add-card"`（表と裏の両方に入力がないと押せない）
- カード一覧：各カードは `data-testid="card-item"` で囲まれ、内部に：
  - `card-front`：表の文字
  - `card-back`：裏の文字
  - `card-delete`：削除ボタン（`data-testid`）
- 「学習開始」ボタン：`data-testid="study-start"`（カードが1枚以上あるときだけ押せる）

### 学習画面
- 表示：`data-testid="study-view"` で囲まれ、内部に：
  - `study-front`：表の文字（常に表示）
  - `study-back`：裏の文字（めくるまで非表示）
  - `flip`：めくるボタン
  - `know`：「覚えた」ボタン（めくった後に押せる）
  - `again`：「まだ」ボタン（めくった後に押せる）
- 進み具合：`data-testid="study-progress"` に `X/Y` 形式で表示（例 `2/5`）

### 結果画面
- 表示：`data-testid="study-result"` で囲まれ、内部に：
  - `result-known`：1回で覚えた枚数（数字のみ）
  - `study-finish`：一覧へ戻るボタン

## 振る舞い

### 初期状態
- 一覧画面を表示。保存データから最後のカード一覧を復元する。
- 「追加」ボタンは、表と裏の入力欄が両方埋まっているときだけ押せる。
- 「学習開始」ボタンは、カードが1枚以上あるときだけ押せる。

### 学習フロー
- 「学習開始」で学習画面へ。
- 最初のカードの表を表示。`study-back` は非表示。
- 「めくる」で `study-back` を表示。
- 「覚えた」を押すと、そのカードを学習済みに。次のカードへ。
- 「まだ」を押すと、そのカードを列の一番後ろに追加。次のカードへ。
- めくる前に「覚えた」「まだ」を押しても何も起きない。
- 全カードが学習済みになったら、結果画面を表示。
- 結果画面から「一覧へ戻る」で一覧画面に戻る。

### データ保存
- 各カードは `{ front, back }` の形で保存。
- 一覧に追加する度に、カード全体を `cards` キーで保存。
- 削除する度に保存。
- 学習中の「覚えた/まだ」の状態（途中経過）は保存しない。

### ページ再読み込み
- 学習中にページを閉じた場合、次に開くときは一覧画面に戻る。
- 学習中の「覚えた/まだ」の状態は破棄される。

## エラー時の挙動

- 表または裏が空の状態で「追加」を押しても何も起きない。
- カードが0枚の状態で「学習開始」を押しても何も起きない。
- 保存済みのカードは削除できる。削除後、カード一覧は即座に更新されて保存される。

## 受け入れ条件

### AC-01: カードの追加
- Given 一覧画面を表示し、カード一覧が空
- When 「表」に `apple`、「裏」に `りんご` を入力して「追加」を押す
- Then カード一覧に表 `apple`、裏 `りんご` のカードが表示される

### AC-02: 空の入力欄で追加はできない
- Given 一覧画面を表示
- When 「表」に `apple` を入力し、「裏」は空の状態で「追加」を押す
- Then カード一覧に新しいカードが追加されない

### AC-03: カード削除
- Given 一覧画面にカード（表 `apple`、裏 `りんご`）が表示されている
- When そのカードの削除ボタンを押す
- Then カード一覧からそのカードが消える

### AC-04: 学習開始
- Given 一覧画面にカード（表 `apple`、裏 `りんご`）が1枚表示されている
- When 「学習開始」を押す
- Then 学習画面が表示され、`study-front` に `apple` が表示される

### AC-05: カードをめくる
- Given 学習画面でカードの表 `apple` が表示されている
- When 「めくる」を押す
- Then `study-back` に `りんご` が表示される

### AC-06: 「覚えた」で次へ進む
- Given 学習画面でカードがめくられて、表 `apple`、裏 `りんご` が表示されている
- When 「覚えた」を押す
- Then `study-progress` が `1/1` に更新され、結果画面が表示される

### AC-07: 「まだ」で後ろに回る
- Given 学習画面に2枚のカード（1枚目：表 `apple`、2枚目：表 `orange`）がある
- When 1枚目をめくって「まだ」を押す
- Then 次に `orange` が表示される

### AC-08: データ復元
- Given 一覧画面にカード（表 `apple`、裏 `りんご`）が表示されている
- When ページを再読み込みする
- Then 一覧画面が表示され、同じカードが表示されている

### AC-09: 学習中断後の復元
- Given 学習画面を開いている
- When ページを閉じて、再度アプリを開く
- Then 一覧画面が表示される

### AC-10: 結果から一覧へ戻る
- Given 結果画面に「1回で覚えた枚数：1」と表示されている
- When 「一覧へ戻る」を押す
- Then 一覧画面が表示される

## 決定事項
- D1: 表と裏が両方入力されていないと、追加ボタンが無効（どちらか一方でも空欄なら追加しない）（Q1）
- D2: カードが0枚で「学習開始」を押しても何も起きない。メッセージは表示しない（Q2）
- D3: 学習中にページを閉じた場合、一覧画面に戻る。学習中の「覚えた/まだ」の状態は保存されない（Q3）
- D4: 「まだ」のカードは列の一番後ろに回り、残りのカードが全部出た後に出てくる（Q4）
- D5: 結果表示後、「一覧へ戻る」ボタンで一覧へ戻る。自動では戻らない（Q5）
