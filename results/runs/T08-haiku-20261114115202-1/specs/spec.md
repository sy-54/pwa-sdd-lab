# 読書記録 外部仕様

> 本を登録し、状態を変更できる。読了後に評価と感想を入力。状態で絞り込み表示。
> 本の一覧と詳細（題名、状態、評価、感想、写真）を storage に保存。
> 状態変更時の感想の扱いは仮決定（保持）。

## 画面と操作

### 一覧画面（初期状態）
- 本の一覧を表示
- ボタン `book-new`：新規追加
- セレクトボックス `filter`：状態で絞り込み（値：`all` / `want` / `reading` / `done`）。初期値：`all`
- テキスト `book-count`：表示中の件数（数字のみ）

### 各本のアイテム `book-item`
- テキスト `book-title`：本の題名
- テキスト `book-status`：状態の表示（「読みたい」「読んでいる」「読んだ」）
- ボタン `book-edit`：編集
- 要素 `book-rating`（存在時のみ）：評価を★の数で表示（例：「★★★」）。評価がない場合は表示しない
- 画像 `book-cover`（存在時のみ）：`img` タグ。写真がない場合は表示しない

### フォーム画面 `book-form`（追加・編集時のみ表示）
- テキスト入力 `form-title`：本の題名
- セレクトボックス `form-status`：状態を選択（値：`want` / `reading` / `done`）
- セレクトボックス `form-rating`：評価を選択（値：空 / `1` / `2` / `3` / `4` / `5`）。「読んだ」以外の状態でも、既存の評価は編集可能
- テキストエリア `form-note`：感想（複数行対応）
- ボタン `form-cover`：カメラで写真を撮影。既に写真がある場合は上書き
- ボタン `form-save`：保存
- ボタン `form-cancel`：キャンセル。フォームを閉じる
- ボタン `form-delete`（編集時のみ）：削除

## 振る舞い

### 本の登録
- 必須項目：題名、状態
- 任意項目：評価、感想、写真
- 「読んだ」状態での登録時も、評価と感想の入力は任意

### 本の編集
- 登録後、本の「編集」ボタンで編集画面に遷移
- すべての項目を変更可能
- 状態の変更制約なし。「読んだ」から他の状態に戻すことも可能

### 状態変更時の評価と感想
- 状態を変更すると、評価は削除され、一覧で★は表示されなくなる
- 感想は保持される（編集画面で確認可能）（未決、仮に保持と採用）

### 一覧表示
- 表示順：登録順（新しい順）
- フィルタで絞り込み可能。フィルタの値：`all`（すべて）/ `want`（読みたい）/ `reading`（読んでいる）/ `done`（読んだ）
- `book-count` は、フィルタ後の表示中の件数を表示

### 本の削除
- 編集画面で `form-delete` ボタンを押すと、確認ダイアログを表示
- ユーザーが削除を確認すると、本を一覧から削除
- フィルタは変わらず、フィルタ後の一覧を再表示

### 写真の扱い
- `form-cover` を押すと、カメラを起動
- 撮影完了後、Blob として保存
- 既に写真がある場合は上書き
- 撮影をキャンセルした場合、既存の写真は変わらない

### 保存と復元
- 各操作（登録、編集、削除）の後に、本の一覧全体を storage に保存
- key は `books`
- value は、本のオブジェクトの配列。各本は `{ id, title, status, rating, note, cover }`
- アプリ起動時に storage から復元
- 保存データが壊れている場合は初期化（空の一覧）

## エラー時の挙動

- 保存失敗時：toast に「保存に失敗しました」と表示。メモリに残る
- 壊れた保存データ：起動時に形を確認。異なる場合は初期化
- カメラエラー：例外時に toast に「カメラが利用できません」と表示

## 受け入れ条件

### AC-01: フォームを表示して本を追加
- Given 初期状態で一覧が空
- When `book-new` ボタンを押す
- Then フォーム `book-form` が表示される

### AC-02: 必須項目で本を登録
- Given フォームが表示されている
- When `form-title` に「つながる利他」、`form-status` に「want」と入力して `form-save` を押す
- Then 本が一覧に追加され、`book-count` は 1

### AC-03: 状態を「読んだ」に変更
- Given 本が「読みたい」で登録されている
- When その本の `book-edit` を押し、`form-status` を「done」に変更して `form-save` を押す
- Then 本の状態が「読んだ」に変わる。`book-status` に「読んだ」と表示される

### AC-04: 「読んだ」から他の状態に戻す
- Given 本が「読んだ」で登録されている
- When その本の `book-edit` を押し、`form-status` を「reading」に変更して `form-save` を押す
- Then 本の状態が「読んでいる」に変わる

### AC-05: 削除ボタンで確認ダイアログを表示
- Given 本が登録されている
- When その本の `book-edit` を押し、`form-delete` を押す
- Then 確認ダイアログが表示される（`sdk-confirm-ok` / `sdk-confirm-cancel`）

### AC-06: 削除を確認して本を削除
- Given 確認ダイアログが表示されている
- When `sdk-confirm-ok` を押す
- Then 本が一覧から削除される。`book-count` が 0 になる

### AC-07: 状態で絞り込む
- Given 「読みたい」「読んでいる」「読んだ」の本が各1冊登録されている
- When `filter` を「done」に変更
- Then 状態が「読んだ」の本だけが表示される。`book-count` は 1

### AC-08: 「読んだ」状態で評価と感想を入力
- Given 本が「読んだ」で登録されている
- When その本の `book-edit` を押し、`form-rating` に「5」、`form-note` に「おもしろい」と入力して `form-save` を押す
- Then 一覧で `book-rating` に「★★★★★」と表示される

### AC-09: 状態変更時に評価が消える
- Given 本が「読んだ」で、評価「★★★」が表示されている
- When その本の `book-edit` を押し、`form-status` を「reading」に変更して `form-save` を押す
- Then 一覧で `book-rating` が表示されなくなる

### AC-10: 状態変更時に感想は保持される
- Given 本が「読んだ」で、感想「おもしろい」が保存されている
- When その本の `book-edit` を押し、`form-status` を「reading」に変更して `form-save` を押す
- Then 再度その本の `book-edit` を押したとき、`form-note` に「おもしろい」が表示される

### AC-11: 写真を撮影して保存
- Given フォームが表示されている
- When `form-cover` を押して写真を撮影
- Then `book-cover` に撮影した画像が `img` で表示される

### AC-12: アプリを閉じて開き直しても本が残る
- Given 本が登録されている
- When アプリを閉じて開き直す
- Then 登録した本がまだ一覧に表示される

## 決定事項
- D1: 一覧表示の順序は登録順（新しい順）(Q1)
- D2: 状態遷移に制約はない。「読んだ」から他の状態に戻すことができる(Q2)
- D3: 状態変更時に評価は削除され表示されなくなる。感想は保持される（仮）(Q3)
- D4: 本を「読んだ」にするときに、評価と感想の入力は任意(Q4)
- D5: 本を削除するときに確認ダイアログを表示(Q5)
