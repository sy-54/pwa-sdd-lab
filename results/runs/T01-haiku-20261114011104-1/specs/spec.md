# タイマー 外部仕様

> 分を指定してカウントダウンタイマーを動かす。
> リセット時は分フィールドの値を保持し、残り時間と終了表示をリセット。
> 終了時はSDK通知と画面表示（done）で知らせる。

## 画面と操作

- **分の入力フィールド**（`data-testid="minutes"`）：入力型は `input type="number"`。1～99分の整数のみ受け入れ。開始中は無効化。
- **残り時間表示**（`data-testid="time"`）：MM:SS 形式。初期値は 00:00。
- **開始ボタン**（`data-testid="start"`）：分の入力が1～99かつタイマーが未実行なら有効。押下でカウントダウン開始。一時停止中なら「再開」として機能。
- **一時停止ボタン**（`data-testid="pause"`）：カウントダウン中のみ有効。
- **リセットボタン**（`data-testid="reset"`）：任意のタイミングで有効。カウントダウンを停止。
- **終了表示**（`data-testid="done"`）：時間が 00:00 になったときだけ表示。リセットで消える。

## 振る舞い

- **初期状態**：分フィールドは空（値なし）、残り時間は 00:00、done 非表示、開始ボタンは無効。
- **分入力時**：1～99の値を入力したら開始ボタンは有効になる。0、負の数、100以上、空欄では無効なまま。
- **開始後の状態**：分フィールドは無効化。秒単位でカウントダウン開始。
- **一時停止**：残り時間は進まず。再開ボタンで続行。一時停止中に分フィールド値を変更しても、残り時間への影響なし（カウント値は保持）。
- **リセット**：カウントダウンを停止。残り時間を 00:00 にリセット。分フィールドは入力済みの値をそのまま保持。done 表示は消える。分フィールドが再度有効化。
- **終了時**：残り時間が 00:00 に達したら、SDK の通知機能で知らせる（音を含む）。同時に done 表示が画面に出る。カウントは停止。分フィールドは有効化。

## エラー時の挙動

- **不正な入力**：0未満、100以上、小数、空欄の場合、開始ボタンは無効のまま。入力を拒否せず、警告も表示しない。
- **壊れたデータ（あとから手動で localStorage 改ざんなど）**：分フィールドまたは残り時間が範囲外なら、初期状態（00:00）にリセット。

## 受け入れ条件

### AC-01: 分を入力して開始ボタンを有効にできる
- Given 初期状態
- When 分フィールドに 5 を入力
- Then 開始ボタンが有効になる

### AC-02: 開始後にカウントダウンが進む
- Given 分フィールドに 1 を入力し、開始ボタンを押下した直後
- When 1秒待機
- Then 残り時間が 00:59 で表示される

### AC-03: 一時停止で時間が止まる
- Given カウントダウン中で残り時間が 00:30
- When 一時停止ボタンを押下
- Then 残り時間が 00:30 のまま変わらない

### AC-04: 再開で続行する
- Given 一時停止中で残り時間が 00:30
- When 開始ボタン（再開）を押下
- Then カウントダウンが再開される

### AC-05: リセット時に分フィールドは保持される
- Given カウントダウン中で分フィールドに 5、残り時間が 02:30
- When リセットボタンを押下
- Then 分フィールドは 5 のまま、残り時間は 00:00、done 表示は出ていない

### AC-06: 終了時にdone表示とSDK通知が出る
- Given 分フィールドに 1 を入力して開始し、カウントダウンが完了
- When 残り時間が 00:00 に達する
- Then done 表示が画面に出て、SDK通知が発火する

### AC-07: 不正な入力では開始できない
- Given 初期状態
- When 分フィールドに 0 を入力
- Then 開始ボタンは無効なまま

## 決定事項
- D1: 終了時通知はSDK通知機能と画面表示（done）の両方を使用（Q1）
- D2: 開始中は分フィールドを無効化（Q2）
- D3: リセット時は分フィールド値を保持、残り時間と done 表示をリセット（Q3）
- D4: 1～99分のみ入力可能。0分や空欄では開始しない（Q4）
- D5: 一時停止中に分フィールド値を変更してもカウントダウン値は変わらない（Q5、自由裁量で保守的に）
