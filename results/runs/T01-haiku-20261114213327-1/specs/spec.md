# タイマー 外部仕様

> 分を指定してカウントダウンするタイマー。開始・一時停止・再開・リセットができ、
> 時間になったら SDK 通知と画面表示で知らせる。0分や空欄では開始しない。
> 開始後は分の変更不可。リセット後も入力値は残る。

## 画面と操作

### 初期状態
- 分の入力欄（`data-testid="minutes"`, `input type="number"`）が見え、1～99の値を受け付ける。初期値は空（または0）
- 残り時間表示（`data-testid="time"`）には「00:00」が表示される（MM:SS形式）
- 開始ボタン（`data-testid="start"`）は常に押せる
- 一時停止ボタン（`data-testid="pause"`）
- リセットボタン（`data-testid="reset"`）

### タイマー実行中
- 分の入力欄は表示されるが無効（入力できない）
- 残り時間表示は1秒ごとに減る（MM:SS形式）
- 一時停止ボタンが押せる
- 開始ボタンと リセットボタンはある

### 一時停止中
- 分の入力欄は表示されるが無効
- 残り時間表示は停止したまま表示される
- 開始ボタン（再開の機能）が押せる
- リセットボタンが押せる

### 時間になったとき
- 終了表示（`data-testid="done"`）が画面に現れる
- SDK の `notify.send()` で通知を送る
- リセットボタンを押して初期状態に戻す

## 振る舞い

- **初期値と初期状態**：分の入力欄は空または0。残り時間は00:00。全ボタンが表示される
- **開始条件**：分の入力が1以上99以下の整数のときだけ、開始ボタンを押してタイマーが開始する
- **入力値が0または空**：開始ボタンを押しても何も起きない（エラー表示なし。ボタンの無効化は不要）
- **状態遷移**：開始中 ⇄ 一時停止 ⇄ リセット、または一時停止からリセット時は初期状態に戻る
- **リセット動作**：一時停止中にリセットを押すと、分の入力値は残ったまま、残り時間表示を指定した分に戻す
- **開始後の入力**：タイマー開始後（一時停止中も含む）は、分の入力欄は変更できない
- **終了の知らせ**：時間が0になったら、SDK の `notify.send()` で通知し、同時に画面に `data-testid="done"` の終了表示を出す。文言は実装者が決める

## エラー時の挙動

- **不正な入力（0以下、100以上、非整数、空欄）**：開始ボタンを押しても開始されない。エラーメッセージは出さない
- **壊れた保存データ**：分の入力値を0（または空）に初期化する

## 受け入れ条件

### AC-01: 1分以上99分以下の入力で開始できる
- Given 初期状態で分の入力欄に「3」を入力
- When 開始ボタンを押す
- Then `time` に「03:00」が表示され、1秒ごとに減る

### AC-02: 0分・空欄で開始ボタンを押しても何も起きない
- Given 初期状態で分の入力欄が空
- When 開始ボタンを押す
- Then `time` は「00:00」のまま変わらない

### AC-03: 開始後は分の入力欄を変更できない
- Given タイマーが実行中で、分の入力欄に「2」が入力されている
- When 分の入力欄をクリックして「5」に変更しようとする
- Then 入力欄は無効で変更できない

### AC-04: 一時停止と再開ができる
- Given 「3」で開始したタイマーが「01:30」で実行中
- When 一時停止ボタンを押す
- Then `time` が「01:30」のまま停止する
- When 開始ボタンを押す
- Then `time` が「01:29」「01:28」と続く

### AC-05: リセットは分の値を残し、表示を指定分に戻す
- Given 「5」で開始したタイマーが「02:15」で実行中
- When リセットボタンを押す
- Then `time` が「05:00」に戻り、分の入力欄には「5」が残っている

### AC-06: 時間になったら通知と画面表示を出す
- Given 「1」で開始したタイマーが実行中
- When 1秒が経過して時間が0になる
- Then `notify.send()` で通知が送られ、同時に `done` に終了メッセージが表示される

## 決定事項

- D1: 0分・空欄で開始ボタンを押しても何も起きない。エラー表示不要（Q1）
- D2: SDK 通知（`notify.send()`）と画面表示（`done`）の両方で通知。文言は実装者が決定（Q2）
- D3: リセット後も分の入力値は残る。表示は指定分に戻す（Q3）
- D4: 1～99分の制限（Q4）
- D5: 開始後（一時停止中も含む）は分を変更できない（Q5）
