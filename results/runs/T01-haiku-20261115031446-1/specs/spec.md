# タイマー 外部仕様

> カウントダウンタイマー。分を入力して開始し、時間になったら done が表示される。
> 一時停止・再開・リセットができ、リセット後は設定した分数に戻る。
> 片手で操作でき、開始中は分の入力を受け付けない。

## 画面と操作
- 置くファイル：`apps/timer/index.html`、`apps/timer/manifest.json`
- ルート要素：`<main data-testid="app-root">`
- 分の入力欄：`<input type="number" data-testid="minutes">` 初期値は空。最小値 1、最大値なし
- 残り時間表示：`<div data-testid="time">` 形式は `MM:SS`（例 `03:00`）。初期状態では空または分の入力から計算
- ボタン：
  - 開始・再開：`<button data-testid="start">`。初期状態は有効。分が空または 0 のときは無効化して開始できない
  - 一時停止：`<button data-testid="pause">`。実行中のみ有効
  - リセット：`<button data-testid="reset">`。どの状態からでも有効
- 終了表示：`<div data-testid="done">` 時間がゼロになったときだけ表示。テキストは任意（ユーザーが判別できれば OK）

## 振る舞い
- **初期状態：** 分の入力欄は空。残り時間は未表示または `00:00`。ユーザーが分を入力する
- **開始操作：** 分の入力欄に 1 以上の値があるとき、start を押すとカウントダウン開始。分の入力欄は無効化（変更不可）。残り時間が秒単位で更新される（例 `03:00` → `02:59` → ...）
- **一時停止：** pause を押すと、カウントダウン停止。残り時間は表示されたまま
- **再開：** 一時停止中に start を押すと、残り時間から続きが再開される（最初からではない）
- **リセット：** reset を押すと、カウントダウン停止。残り時間は元々の分数に戻る（例 3 分で開始したなら `03:00` に戻る）。done が表示されている場合は消える。分の入力欄は再び有効化
- **終了：** 残り時間が 0 になったら、カウントダウン停止。done が表示される。ユーザーが reset や start を押すまで表示は消えない
- **保存：** 保存は不要。タイマー終了やアプリ切り替えでリセット

## エラー時の挙動
- **空欄または 0：** start ボタンは無効。押してもカウントダウン開始しない。エラー表示は不要
- **負の数：** input type="number" の制約で防ぐ（実装依存。HTML5 仕様でも負の数は許可される環境もあるが、UI契約で最小値 1 を指定）
- **小数：** input type="number" で `step="1"` を指定。小数は入力されない

## 受け入れ条件

### AC-01: 初期状態
- Given 画面を初めて開いたとき
- When 何も操作していない
- Then 分の入力欄は空、残り時間は未表示、done は表示されない

### AC-02: 分を入力して開始
- Given 分の入力欄が空の初期状態
- When 分の入力欄に `3` と入力し、start ボタンを押す
- Then 残り時間に `03:00` と表示され、カウントダウンが始まる

### AC-03: カウントダウン進行
- Given カウントダウンが開始されて `03:00` が表示されている
- When 1 秒以上経過して、再度ページを確認する（または UI が更新される）
- Then 残り時間が `02:59` 以下に更新されている

### AC-04: 一時停止
- Given カウントダウン実行中で `02:30` が表示されている
- When pause ボタンを押す
- Then カウントダウンが停止し、`02:30` が表示されたまま変わらない

### AC-05: 再開
- Given 一時停止中で `02:30` が表示されている
- When start ボタンを押す
- Then `02:30` から続きのカウントダウンが再開される（`00:00` からではない）

### AC-06: リセット
- Given カウントダウン実行中で `02:00` が表示されている
- When reset ボタンを押す
- Then 残り時間が `03:00` に戻る（元々の分数に戻る）

### AC-07: リセット後、分の入力が有効に
- Given reset ボタンを押した直後
- When 分の入力欄に `5` と入力する
- Then 入力が受け付けられる

### AC-08: 終了時に done 表示
- Given カウントダウンが実行中で、開始時に 1 分を設定していた
- When 1 分経過して、残り時間が `00:00` になる
- Then done が表示される

### AC-09: done は消えない
- Given done が表示されている
- When 1 秒以上経過する
- Then done は表示されたまま消えない

### AC-10: done はリセットで消える
- Given done が表示されている
- When reset ボタンを押す
- Then done が消え、残り時間は元々の分数に戻る

### AC-11: 分が空のときは start 無効
- Given 分の入力欄が空の状態
- When start ボタンを押そうとする
- Then start ボタンが無効化されている、または押しても何も起きない

### AC-12: 分が 0 のときは start 無効
- Given 分の入力欄に `0` が入力されている
- When start ボタンを押そうとする
- Then start ボタンが無効化されている、または押しても何も起きない

## 決定事項
- D1: 空欄または 0 のときは開始しない。エラー表示は不要（Q1、Q2）
- D2: リセット後、分の入力欄は直前に設定していた分数に復帰（Q3）
- D3: done は自動に消えず、ユーザーが操作するまで表示（Q4）
- D4: 一時停止中に start を押すと、残り時間から続きが再開される（Q5）
- D5: 負の数・小数の扱いは input type="number" の制約に従う。最小値 1、step を 1 に指定（Q1）
- D6: ボタンの有効・無効制御は、一般的な UI パターンに従う。start は分が空または 0 のときに無効、pause は実行中のみ有効、reset はいつでも有効（Q2）
