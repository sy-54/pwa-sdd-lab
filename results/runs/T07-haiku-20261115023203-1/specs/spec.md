# 単語帳 外部仕様

> カード（表と裏）を一覧で管理し、追加・削除できる。学習では表から始まり、めくって裏を確認し、「覚えた」か「まだ」を選んで進む。
> 「まだ」のカードは覚えるまで同じ順序で繰り返し出る。データはストレージに保存され、アプリを開き直しても残る。学習途中での進捗は保存しない。
> すべての曖昧さが qa.md で決定済み。

## 画面と操作

### 一覧画面
- 入力フィールド
  - `card-front-input`：カードの表（テキスト）
  - `card-back-input`：カードの裏（テキスト）
- ボタン
  - `add-card`：カードを追加
  - `study-start`：学習を開始
- カード一覧（各カードは `card-item`）
  - `card-front`：表テキスト
  - `card-back`：裏テキスト
  - `card-delete`（ボタン）：このカードを削除

### 学習画面（学習中のみ表示）
- 全体：`study-view`
- 表示要素
  - `study-front`：現在のカードの表
  - `study-back`：裏（めくるまで `hidden` 属性で非表示）
  - `study-progress`：進度表示（例「2/5」）
- ボタン
  - `flip`：カードをめくる
  - `know`：「覚えた」を選択
  - `again`：「まだ」を選択

### 結果画面（学習完了時のみ表示）
- 全体：`study-result`
- 表示要素
  - `result-known`：1回で覚えた枚数（数字のみ）
- ボタン
  - `study-finish`：一覧に戻る

## 振る舞い

### カード追加
- 表または裏が空欄（前後の空白を除いても空）の場合、追加されない
- 有効な入力の場合、前後の空白を除去してカードを追加
- 追加後、両入力フィールドは空にされる
- カードは追加順に表示される

### 学習開始
- カード 1 枚以上で、`study-start` ボタンが機能する
- カード 0 件のときはボタンを押しても何も起きない
- 学習開始時、`study-view` が表示される
- 初回は最初のカード（追加順）の表が表示される

### 学習の進行
- カードの表が表示される状態では、`know` / `again` ボタンを押しても何も起きない
- `flip` ボタンを押すと、裏が表示される
- 裏が表示された後、`know` ボタンを押すと、次のカードへ進む
- 裏が表示された後、`again` ボタンを押すと、カードがキューの末尾に追加される
- 「また」のカードは常に同じ順序（追加順）で繰り返される
- 進度は「覚えた枚数/全体の枚数」で表示される

### 学習完了
- すべてのカードが「覚えた」状態になると、`study-result` が表示される
- 1 回で覚えた枚数が `result-known` に表示される
- `study-finish` ボタンで一覧画面に戻る

### カード削除
- `card-delete` ボタンを押すと、確認なしで即座にカードが削除される

### 保存と復元
- カード一覧は `storage` に保存される
- カード追加・削除時に保存される
- アプリを開き直してもカードが残る
- 学習の途中経過は保存されない（アプリ再読み込み時は一覧に戻る）
- ホームボタン（SDK 自動）で学習中でも一覧に戻ることができる

## エラー時の挙動

- 空またはスペースのみの入力で追加を押す：カードは追加されず、入力フィールドはそのまま残る
- カード 0 件で学習開始を押す：何も起きない
- 破損したストレージデータ：空の配列として扱い、空の一覧から開始

## 受け入れ条件

### AC-01: カード追加（有効入力）
- Given 一覧で表に "apple"、裏に "りんご" と入力
- When `add-card` ボタンを押す
- Then カードが一覧に表示され、入力フィールドは空になる

### AC-02: カード追加（空入力）
- Given 一覧で表が空、裏に "りんご" と入力
- When `add-card` ボタンを押す
- Then カードは追加されず、入力フィールドは変わらない

### AC-03: カード削除
- Given 一覧に 2 つのカード
- When 最初のカードの `card-delete` ボタンを押す
- Then そのカードが削除される

### AC-04: 学習開始
- Given 一覧に 2 つのカード
- When `study-start` ボタンを押す
- Then `study-view` が表示され、最初のカードの表が `study-front` に表示される

### AC-05: 学習開始（カード 0 件）
- Given 一覧にカードがない
- When `study-start` ボタンを押す
- Then 何も起きない

### AC-06: カードをめくる
- Given 学習画面でカードの表が表示され、裏は `hidden`
- When `flip` ボタンを押す
- Then `study-back` が表示される

### AC-07: 「覚えた」で進む
- Given 学習画面でカードがめくられ裏が表示
- When `know` ボタンを押す
- Then 次のカードが表示され、`study-progress` が増加

### AC-08: 「まだ」で繰り返す
- Given 学習画面で 2 つのカード、最初がめくられている
- When `again` ボタンを押す
- Then 2 番目が表示され、最初は後で繰り返す

### AC-09: 学習完了
- Given すべてのカードを「覚えた」と選択
- When 最後のカードを選択
- Then `study-result` が表示され、`result-known` に枚数が表示される

### AC-10: 結果から一覧に戻る
- Given `study-result` が表示
- When `study-finish` ボタンを押す
- Then 一覧画面が表示される

### AC-11: データ永続化
- Given 3 つのカードを登録
- When アプリを閉じて開き直す
- Then カードが一覧に表示される

## 決定事項

- D1: 表または裏が空欄のカードは追加されない。前後の空白は取り除き、追加後は両方の入力欄を空にする（Q1）
- D2: カード 0 件のときは学習開始ボタンを押しても何も起きない（Q2）
- D3: 学習途中でアプリを閉じたり再読み込みした場合は一覧に戻る（Q3）
- D4: 「また」のカードが繰り返される際の順序は常に同じ順序（追加順）（Q4）
- D5: カード削除時に確認ダイアログは不要。すぐに削除する（Q5）
