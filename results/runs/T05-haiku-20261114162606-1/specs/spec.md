# 支出メモ 外部仕様

> 使ったお金をその場で記録する。金額と分類を入れて追加ボタンを押すだけ。
> 記録は今月の日付で分類され、合計は「今月」の集計値が表示される。
> 5つの決定事項（曖昧さの解決）があり、すべて確認済み。

## 画面と操作
- **入力エリア**
  - 金額：`input type="number"`、`data-testid="amount"`。プレースホルダーは「金額」。1円以上の整数のみ入力可能
  - 分類：`select`、`data-testid="category"`。選択肢は `<option value="food">食費</option>`、`<option value="daily">日用品</option>`、`<option value="transport">交通</option>`、`<option value="other">その他</option>`。初期選択値は「food」
  - 追加ボタン：`button`、`data-testid="add"`。テキストは「追加」
- **合計表示**
  - 今月の合計：`data-testid="total"`。表示形式は「今月 ¥1,200」（数字と3桁区切りのカンマのみ）
  - 分類ごとの合計（Should）：各分類に対して「食費 ¥1,000」の形式で表示。今月分のみ
- **記録一覧**
  - 各記録：`div`、`data-testid="expense-item"`。その中に以下の要素を含む
    - 金額表示：`data-testid="expense-amount"`。表示形式は「¥1,000」
    - 分類表示：`data-testid="expense-category"`。分類名の日本語表示（例：「食費」）
    - 削除ボタン：`data-testid="expense-delete"`。テキストは「削除」

## 振る舞い
- **初期状態**：記録がない場合、一覧は空。合計は「今月 ¥0」。分類ごとの合計も0ドルで表示
- **追加操作**：金額と分類を入力して「追加」ボタンを押すと、新しい記録が一覧の最上部に追加される。入力フィールドはクリアされ、分類は「food」に戻る
- **金額入力の制約**：1円以上の整数のみ。0円以下や0は入力不可（ブラウザのデフォルト制約）。不正な値を入力した場合、「追加」ボタンを押しても記録されない
- **並び順**：新しい記録ほど上に表示（新しい順）
- **今月の定義**：1月1日から12月31日までの期間。複数年にまたがる場合、現在の暦年の「今月」のみを集計
- **保存と復元**：記録は Storage API で保存。ブラウザを閉じて開き直しても、記録は残る
- **削除後の状態**：削除した記録は一覧から消える。合計は自動的に再計算される

## エラー時の挙動
- **金額が入力されていない場合**：「追加」ボタンを押しても何も起きない
- **分類が選択されていない場合**：ブラウザの`select`のデフォルト動作により、常に選択肢の中から1つが選ばれている状態（初期値は「food」）なので、この状態は発生しない
- **削除操作**：削除ボタンを押すと、確認ダイアログを表示。ユーザーが「OK」を選んだ場合のみ削除。「キャンセル」を選んだ場合は何も起きない
- **保存失敗**：Storage API の失敗時は、エラーメッセージをトーストで表示。データは変更されない

## 受け入れ条件
### AC-01: 新しい記録を追加する
- Given 記録がない状態
- When 金額を「1000」、分類を「food」に入力して「追加」ボタンを押す
- Then `expense-item` に1件の記録が表示され、`expense-amount` に「¥1,000」、`expense-category` に「食費」が表示される

### AC-02: 複数の記録を追加し、新しい順に表示される
- Given 記録が1件ある状態（金額1000、分類food）
- When 金額を「500」、分類を「daily」に入力して「追加」ボタンを押す
- Then `expense-item` が2件になり、最初の記録は新しく追加した「500」の記録、2番目は「1000」の記録

### AC-03: 今月の合計を表示する
- Given 記録が2件ある状態（1000 + 500）
- When 画面を確認する
- Then `total` に「今月 ¥1,500」と表示される

### AC-04: 分類ごとの合計を表示する
- Given 記録が3件ある状態（food 1000、daily 500、transport 300）
- When 画面を確認する
- Then 分類ごとの合計が表示される（食費 ¥1,000、日用品 ¥500、交通 ¥300、その他 ¥0）

### AC-05: 記録を削除する
- Given 記録が1件ある状態（金額1000）
- When 削除ボタンを押して確認ダイアログで「OK」を選ぶ
- Then 記録が削除され、`expense-item` は0件、合計は「今月 ¥0」になる

### AC-06: 削除を キャンセルする
- Given 記録が1件ある状態（金額1000）
- When 削除ボタンを押して確認ダイアログで「キャンセル」を選ぶ
- Then 記録は削除されず、`expense-item` は1件のまま、合計は「今月 ¥1,000」のまま

### AC-07: 初期値は食費
- Given アプリを起動した直後
- When 分類フィールドを確認する
- Then `category` の選択値は「food」

### AC-08: 追加後に入力フィールドをクリア
- Given 金額が「100」に設定されている
- When 「追加」ボタンを押す
- Then `amount` フィールドが空、`category` が「food」に戻る

### AC-09: 無効な金額では追加されない
- Given 金額フィールドが空の状態
- When 「追加」ボタンを押す
- Then 記録は追加されない

### AC-10: ページをリロードしても記録が残る
- Given 記録が1件ある状態（金額1000）
- When ページをリロードする
- Then 記録が表示され、合計は「今月 ¥1,000」のまま

### AC-11: 3桁区切りのカンマが表示される
- Given 金額を「12345」で記録した状態
- When 画面を確認する
- Then `expense-amount` に「¥12,345」、`total` に「今月 ¥12,345」と表示される

## 決定事項
- D1: 「今月」は1月1日から12月31日までの期間（Q1）
- D2: 金額は1円以上の整数のみ入力可能（0円以下や0は不可）（Q2）
- D3: 分類の初期選択値は「food」（Q3）
- D4: 削除時に確認ダイアログを表示する（Q4）
- D5: 記録の並び順は新しい順（Q5）
