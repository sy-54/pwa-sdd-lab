# カウンタ 外部仕様

> ボタンで数値を増減・リセットする単一画面アプリ。値は常にlocalStorageに自動保存し、再読み込み後も復元する。
> カウント値は0以上の整数。増減の幅を1/5/10から選べ、目標達成時に表示される。
> 未決事項なし。

## 画面と操作
- ルート要素 `data-testid="app-root"` 内に、現在値表示 `data-testid="count"`（数字のみのテキスト）と、ボタン3つ（`data-testid="inc"`、`"dec"`、`"reset"`）を表示する。
- 増減の幅を選ぶ `select` 要素 `data-testid="step"`（値: `1`, `5`, `10`）を表示する。
- 目標回数を入力する `input type="number"` 要素 `data-testid="goal"` を表示する。
- 現在値が目標値以上のとき、`data-testid="goal-reached"` で達成表示を表示する。
- `inc` を押すと現在値に選んだ幅を加算する。
- `dec` を押すと現在値から選んだ幅を減算する。ただし0未満にはしない（選んだ幅より小さい値では0で止まる）。
- `reset` を押すと現在値を0にする。目標値は保ったままにする。

## 振る舞い
- 初期状態：保存データがなければ `count` は0、`step` は1、`goal` は空。
- `count` と `step`、`goal` の状態が変わるたびに、すべてをlocalStorageへ即時保存する。
- 再読み込み時：保存値があればそれを復元し表示する。
- `step` は常に1～10の範囲内の値。前回選んだ値を再度開いたときに復元する。
- `goal` は0以上の整数、空でも可。
- 下限は0。`dec` で0未満にしない（選んだ幅より小さい値では0で止まる）。
- `count` >= `goal` のとき、`goal-reached` を表示する（`goal` が空のときは表示しない）。
- 上限なし（実質 `Number.MAX_SAFE_INTEGER` まで、それ以上の挙動は規定しない）。

## エラー時の挙動
- 保存データが存在しない、パースできない、0以上の整数でない場合は、0として扱い、同時にlocalStorageを初期値で上書きする。
- `step` の保存値が1/5/10以外の場合は1として扱い、localStorageを1で上書きする。
- `goal` の保存値が0以上の整数でない場合は空として扱い、localStorageを削除する。

## 受け入れ条件
### AC-01: 初期表示
- Given localStorageに保存データがない状態でアプリを開く
- When 画面を表示する
- Then `count` に `0` と表示される

### AC-02: incで増える
- Given `count` が `0` の状態
- When `inc` を1回押す
- Then `count` に `1` と表示される

### AC-03: decは0未満にならない
- Given `count` が `0` の状態
- When `dec` を1回押す
- Then `count` に `0` と表示される

### AC-04: resetで0に戻る
- Given `count` が `3` の状態（`inc` を3回押した状態）
- When `reset` を押す
- Then `count` に `0` と表示される

### AC-05: 再読み込みで値が残る
- Given `inc` を2回押して `count` が `2` の状態
- When ページを再読み込みする
- Then `count` に `2` と表示される

### AC-06: 壊れた保存データは0として初期化
- Given localStorageの保存値が不正な文字列（数値でも整数でもない値）になっている状態
- When 画面を表示する
- Then `count` に `0` と表示され、保存データも `0` に上書きされる

### AC-07: stepの初期値は1
- Given localStorageに保存データがない状態でアプリを開く
- When 画面を表示する
- Then `step` に `1` が選択されている

### AC-08: step を選ぶと保存・復元される
- Given 初期状態で `step` は `1` を選んでいる
- When `step` ドロップダウンで `5` を選んでページを再読み込みする
- Then `step` に `5` が選択されている

### AC-09: stepが5のときincで5増える
- Given `count` が `0`、`step` が `5` の状態
- When `inc` を1回押す
- Then `count` に `5` と表示される

### AC-10: stepが5のときdecで0まで5減る
- Given `count` が `3`、`step` が `5` の状態
- When `dec` を1回押す
- Then `count` に `0` と表示される（5未満なので0で止まる）

### AC-11: 目標達成判定（>= 目標値）
- Given `goal` に `10` を入力、`count` が `0` の状態
- When `inc` を2回押して `count` が `10` になる
- Then `goal-reached` が表示される

### AC-12: 目標以下では達成表示なし
- Given `goal` に `10` を入力、`count` が `5` の状態
- When 画面を表示する
- Then `goal-reached` が表示されない

### AC-13: resetは目標値を保持
- Given `goal` に `10` を入力、`inc` で `count` を `20` にした状態
- When `reset` を押す
- Then `count` に `0` と表示され、`goal` には `10` が残っている

## 決定事項
### 初版（v1）
- D1: `dec` は0で下限、0未満にならない
- D2: `reset` は常に0に戻す
- D3: 増減のステップは常に1
- D4: 上限なし（実質無制限）
- D5: 壊れた保存データは0として初期化し上書きする

### 改訂版（v2）
- D1: 増減の幅選択で0未満にしない。選んだ幅より小さい値では0で止まる（A1）
- D2: 目標達成の判定基準は現在値が目標値以上（A2）
- D3: 目標達成後は現在値 >= 目標値のときだけ表示される（A3）
- D4: `step` のデフォルトは1。前回選んだ値を保存・復元する（A4）
- D5: `reset` は現在値を0に、目標値は保ったまま（A5）
