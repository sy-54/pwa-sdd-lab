# 単語帳 外部仕様

> カード（表/裏）を一覧で追加・削除し、学習開始で1枚ずつ出題してめくり、「覚えた」「まだ」を付けて進む。
> 「まだ」は同じ巡の残りの末尾へ回り混在して再出題、全部「覚えた」になると結果（1回で覚えた枚数）を表示する。
> カードは保存され再読み込み後も残るが、学習の途中経過（出題順・進捗）は保存しない。未決事項なし。

## 画面と操作
- エントリ：`apps/flashcards/index.html`（`apps/flashcards/manifest.json` も置く）、ルート要素：`data-testid="app-root"`
- 一覧画面（学習中以外は常に表示）
  - 入力 `card-front-input`、`card-back-input`、追加ボタン `add-card`
  - カードは追加した順（新しいカードは末尾）に並ぶ。各カード `card-item` の中に表 `card-front`、裏 `card-back`、削除 `card-delete`
  - 学習開始ボタン `study-start`
- 学習画面 `study-view`（学習中だけ表示）
  - 表 `study-front`、裏 `study-back`（めくるまで非表示）、めくる `flip`
  - 覚えた `know`、まだ `again`
  - 進み具合 `study-progress`：`覚えた枚数/全体の枚数`（例 `2/5`）
- 結果画面 `study-result`（学習が終わったときだけ表示）
  - `result-known`（1回で覚えた枚数。数字のみ）、一覧へ戻る `study-finish`

## 振る舞い
- 初期状態：カード0件、一覧画面。保存データがあれば読み込んで表示する
- カード追加：表・裏とも空でなければ末尾に追加し、入力欄を空にする
- カード削除：確認なしで即削除する（取り消し不可）
- 学習開始：カードが1件以上あるときのみ、現在の一覧の並び順で出題列を作り学習画面へ遷移する
- 出題：`study-front` に表を表示し `study-back` は非表示。`flip` を押すと `study-back` を表示する
- 「覚えた」：そのカードをこの学習の既覚えカウントに加え、出題列から除く。まだめくられていない次のカードへ進む
- 「まだ」：このカードを出題列の残り（未出題分）の末尾へ回し、次のカードへ進む（1巡の中で混在する）
- `study-progress` の分母は学習開始時のカード総数で固定、分子は「覚えた」と付けた（重複しない）カードの枚数
- 出題列が0件になったら学習終了。「1回で覚えた枚数」＝一度も「まだ」を付けずに「覚えた」になったカードの枚数を `result-known` に表示し、`study-result` を表示する
- `study-finish` で一覧画面へ戻る
- 保存：カードの追加・削除のたびにカード一覧を保存する。学習の途中経過（出題列・進捗・既覚え状態）は保存しない
- 再読み込み：常に一覧画面から始まる。保存されたカードは残るが、学習中だった場合も学習は再開しない

## エラー時の挙動
- 表・裏のいずれかが空欄のまま `add-card` を押しても追加しない（入力欄はそのまま。通知はしない）
- カードが0件のとき `study-start` を押しても学習は始まらない（一覧画面のまま）
- 保存データが壊れている（配列でない等）場合はカード0件として起動する
- `study-back` が非表示（めくる前）の間に `know`／`again` を押しても何も起きない

## 受け入れ条件
### AC-01: カードの追加
- Given 一覧画面で `card-front-input` に `apple`、`card-back-input` に `りんご` と入力した状態
- When `add-card` を押す
- Then `card-item` が1件増え、その中の `card-front` に `apple`、`card-back` に `りんご` と表示される

### AC-02: 空欄のまま追加
- Given `card-front-input` が空、`card-back-input` に `りんご` が入力された状態
- When `add-card` を押す
- Then `card-item` の件数は増えない

### AC-03: 学習開始とめくり
- Given カードが2件登録され、1件目の表が `apple`、裏が `りんご` である状態
- When `study-start` を押し、続けて `flip` を押す
- Then `study-front` に `apple`、`study-back` に `りんご` と表示される

### AC-04: まだの再出題（同一巡で混在）
- Given カードが2件（1件目: apple/りんご、2件目: dog/いぬ）登録され学習を開始した状態
- When `flip` を押して `again` を押し、次に出た2件目を `flip` して `know` を押す
- Then 次に `study-front` に再び `apple` と表示される

### AC-05: 全部覚えたら結果表示
- Given カードが1件登録され学習を開始し `flip` した状態
- When `know` を押す
- Then `study-result` が表示され、`result-known` に `1` と表示される

### AC-06: カードの削除
- Given `card-item` が2件ある状態
- When 1件目の `card-delete` を押す
- Then `card-item` の件数が1件になり、残ったカードは削除していない方である

### AC-07: 0件で学習開始を押す
- Given カードが0件の一覧画面
- When `study-start` を押す
- Then `study-view` は表示されず一覧画面のままである

### AC-08: 再読み込み後もカードが残る
- Given カードを1件追加した状態
- When ページを再読み込みする
- Then `card-item` が1件表示され、`card-front` に追加した表の文字列が表示される

### AC-09: めくる前に覚えた／まだを押しても無効
- Given 学習画面でカードの表が表示されめくっていない（`study-back` が非表示）状態
- When `know` を押す
- Then `study-progress` の表示は変化しない

## 決定事項
- D1: 表・裏いずれかが空欄なら追加しない。通知はしない（Q1-1）
- D2: カード0件で `study-start` を押しても学習は始まらない（Q1-2）
- D3: 「まだ」は直後に残りの未出題カードの末尾へ回り、1巡の中で混在する（Q2-B）
- D4: カード削除は確認なしで即削除する（Q3-B）
- D5: 一覧は追加順、学習の初回出題もその並び順（Q4-A）
- D6: 学習の途中経過は保存しない。再読み込みすると常に一覧画面に戻る（ラウンド2 Q1-A）
