# タイマー 外部仕様

> 分を指定してカウントダウンするタイマー。初期状態で 3 分がセットされており、開始・一時停止・リセット操作で制御できる。
> 状態（分の設定、残り時間、実行状態）は保存されず、ページを再度開くと 3 分にリセットされる。
> 回答済みの全質問により、仕様は確定。

## 画面と操作
- 分の入力欄：`<input type="number" data-testid="minutes" />` 初期値は 3、範囲 1～99 の整数のみ受け付ける。実行中（カウントダウン中）は disabled 状態
- 残り時間表示：`<div data-testid="time">MM:SS</div>` 現在の残り秒数を MM:SS 形式で表示（例：`03:00`、`00:15`）
- 開始ボタン：`<button data-testid="start">開始</button>`（初期状態と一時停止後に押せる。開始時にはカウントダウンを開始）
- 一時停止ボタン：`<button data-testid="pause">一時停止</button>`（カウントダウン中のみ表示・押可能）
- リセットボタン：`<button data-testid="reset">リセット</button>`（いつでも押可能）
- 終了表示：`<div data-testid="done">完了</div>`（時間が 0 に達したときのみ表示される）

## 振る舞い
- **初期状態**：分の入力欄は 3、残り時間は 03:00、ボタンは開始（押可能）と一時停止（非表示）とリセット（押可能）
- **カウントダウン実行**：開始を押すと、1秒ごとに残り時間が減少。分の入力欄は disabled 状態になる
- **一時停止**：一時停止ボタンを押すと、カウントダウンが停止し、残り時間は維持される。開始ボタンが再び押可能になる
- **タイムアップ**：残り時間が 0 に達すると、カウントダウンは自動で停止。終了表示が画面に表示され、同時に `notify.send()` で「タイマー完了」通知を送信
- **リセット**：リセットボタンを押すと、残り時間は分の入力欄の値に基づいて再計算、終了表示は消える。実行中だった場合は停止し、分の入力欄は enabled に戻る
- **状態保存**：ページを再度開いた場合、状態は保存されず、初期状態（3 分）に戻る

## エラー時の挙動
- **分の入力が 1 未満または 99 を超える場合**：入力値を受け付けず、最後に有効だった値を保持。UI には特別なエラー表示は出さない（HTML5 の number input の制約で最初から不正な値は送信できない）
- **分の入力が整数でない場合**：入力値を受け付けず、最後に有効だった値を保持
- **ページ中断から再開**：ページを開き直すと状態が失われ、初期状態（3 分）に戻る

## 受け入れ条件
### AC-01: 初期状態で 3 分がセットされている
- Given アプリを初回開放
- When ページが読み込まれた直後
- Then `minutes` に 3 が、`time` に「03:00」が表示される

### AC-02: 分の入力を変更すると残り時間が更新される
- Given 初期状態（3分セット済み）
- When `minutes` に 5 を入力
- Then `time` に「05:00」が表示される

### AC-03: 開始ボタンを押すとカウントダウンが開始される
- Given 初期状態
- When `start` ボタンを押してから 1 秒待機
- Then `time` の値が 1 秒減少して「02:59」に変わる

### AC-04: 実行中は分の入力欄が disabled になる
- Given 初期状態
- When `start` ボタンを押してカウントダウンを開始
- Then `minutes` 要素に `disabled` 属性が付与される

### AC-05: 一時停止ボタンを押すとカウントダウンが停止する
- Given カウントダウンが実行中で、残り時間が「02:30」
- When `pause` ボタンを押す
- Then カウントダウンが停止し、`time` は「02:30」のままで変わらない

### AC-06: 一時停止後に開始ボタンを押すと再開される
- Given 一時停止中で、残り時間が「02:30」
- When `start` ボタンを押す
- Then カウントダウンが再開する（1秒後に「02:29」に変わる）

### AC-07: リセットボタンを押すと初期状態に戻る
- Given カウントダウンが実行中で、残り時間が「02:15」
- When `reset` ボタンを押す
- Then `time` が「03:00」に戻り、カウントダウンが停止する

### AC-08: リセット後は分の入力値がそのまま保持される
- Given カウントダウンが実行中で、分が 3 に設定されている
- When `reset` ボタンを押す
- Then `minutes` は 3 のままで、編集可能（disabled が外される）

### AC-09: タイムアップで done 表示が現れる
- Given カウントダウンが実行中で、残り時間が「00:00」に達する
- When 1 秒以上待機
- Then `done` 要素が表示される

### AC-10: タイムアップで通知が送信される
- Given カウントダウンが実行中で、残り時間が「00:00」に達する
- When タイマーがタイムアップ
- Then `notify.send()` が呼び出され、ユーザーに通知が送られる（テスト環境では `sdk-toast` で表示）

### AC-11: リセットで done 表示が消える
- Given タイムアップ後で `done` が表示されている状態
- When `reset` ボタンを押す
- Then `done` 要素が非表示になる

### AC-12: ページ再度開後は初期状態に戻る
- Given タイマーがカウントダウン中で、残り時間が「01:00」
- When ページを再度開く
- Then `minutes` に 3 が、`time` に「03:00」が表示される

## 決定事項
- D1: 時間になったら、画面に「完了」表示を出し、SDK の `notify.send()` で通知も送信する。アプリを開いている間だけ通知が有効。音は不要（A1）
- D2: 分の入力の初期値は 3、範囲は 1～99 の整数のみ（A2）
- D3: 実行中は分の入力欄を disabled にする（A3）
- D4: リセット後、分の入力欄の値はリセット前のままで保持される（A4）
- D5: done 表示はリセット時に消える。その他のタイミング（開始時など）での消滅は実装で判断。3 秒で自動消滅の挙動を採用（お任せ範囲）（A5 実装判断）
