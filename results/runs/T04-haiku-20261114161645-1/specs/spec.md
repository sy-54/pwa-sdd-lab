# 習慣トラッカー 外部仕様

> 習慣一覧を表示し、新規追加・チェック・削除ができる画面
> 各習慣について本日のチェック状態と連続日数をLocalStorageで保存
> 未チェック習慣の表示順を工夫し、見分けやすくする

## 画面と操作
- ルート要素：`data-testid="app-root"`
- 新規習慣入力欄：`data-testid="new-habit"`（テキスト入力）
- 追加ボタン：`data-testid="add-habit"`
- 習慣一覧：複数の要素が並ぶ
  - 各習慣：`data-testid="habit-item"`
    - 習慣名：`data-testid="habit-name"`（テキスト表示）
    - チェック欄：`data-testid="habit-check"`（`input type="checkbox"`、本日やったか）
    - 連続日数：`data-testid="habit-streak"`（テキスト表示、数字のみ）
    - 削除ボタン：`data-testid="habit-delete"`（ボタン）

## 振る舞い

### 初期状態
- 習慣一覧は空
- LocalStorageに保存されたデータがあれば、復元される

### 習慣の追加
- 入力欄に習慣名を入力し、追加ボタンを押すか Enter キーで追加
- 空文字列（空白のみ含む）の追加は許可しない
- 同じ名前の習慣は複数追加できない
- 新規追加時、連続日数は 0 に初期化される

### 本日のチェック状態
- 各習慣のチェック欄で、本日やったかどうかを記録
- チェック状態の変更時に即座にLocalStorageに保存

### 連続日数の計算
- チェック欄がチェック済みの場合、その習慣の連続日数を表示
- 連続日数は、過去のデータから計算される
- 計算方法：昨日チェック済みで、その前も連続していれば +1。昨日未チェックなら 1（本日から開始）
- 例）昨日チェック済み・本日未チェック時点 → 連続日数は 1（昨日のみ）。本日チェック時 → 2
- チェック外した場合、連続日数は 0 に初期化

### 習慣一覧の表示順序
- 未チェック習慣を上部に表示、チェック済み習慣を下部に表示
- 同じ状態（チェック済み/未チェック）内では追加順を保持

### 習慣の削除
- 削除ボタンを押すと確認ダイアログを表示
- ユーザーが削除を確認すると、その習慣と記録が削除される

### 保存と復元
- 習慣名、本日のチェック状態、連続日数、追加順序をLocalStorageに保存
- アプリ再起動時、LocalStorageから復元される

### 日付の判定
- 「本日」は、アプリを開いている環境での現在日付（ブラウザの Date オブジェクト）
- 翌日になった場合、未チェック習慣の連続日数は前日のまま保持

## エラー時の挙動

### 入力値のエラー
- 空文字列追加時：追加ボタンは有効なままで、何もしない
- 同じ名前の習慣追加時：追加ボタンは有効なままで、何もしない

### LocalStorageエラー
- LocalStorageが利用不可な場合、ブラウザのコンソールにエラーを出力し、データなしで起動
- LocalStorageのデータが破損している場合、無視して空の一覧から開始

## 受け入れ条件

### AC-01: 習慣を追加できる
- Given 習慣一覧が空である
- When 入力欄に「運動」と入力し、追加ボタンを押す
- Then `habit-item` が1つ表示され、`habit-name` に「運動」が表示される

### AC-02: 本日のチェック状態を記録できる
- Given 習慣「読書」が追加されている
- When `habit-check` をチェックする
- Then `habit-check` がチェック状態になり、LocalStorageに保存される

### AC-03: 連続日数が表示される
- Given 習慣「運動」が追加されており、本日チェック済み
- When 連続日数を確認する
- Then `habit-streak` に「1」が表示される

### AC-04: 連続日数が前日から継続する
- Given 習慣「筋トレ」が前日チェック済みで、連続日数が1である
- When 本日チェックする
- Then `habit-streak` に「2」が表示される

### AC-05: 連続日数はチェック外すと0になる
- Given 習慣「読書」が本日チェック済みで、連続日数が1である
- When `habit-check` をチェック外す
- Then `habit-streak` に「0」が表示される

### AC-06: 未チェック習慣が上部に表示される
- Given 習慣「運動」「読書」が追加されており、「運動」はチェック済み、「読書」は未チェック
- When 一覧を確認する
- Then 「読書」が「運動」よりも上に表示される

### AC-07: 習慣を削除できる
- Given 習慣「瞑想」が追加されている
- When `habit-delete` を押す
- Then 確認ダイアログが表示される
- When ダイアログで「削除」を確認する
- Then 「瞑想」が一覧から削除される

### AC-08: 空文字列の追加は許可しない
- Given 習慣一覧が表示されている
- When 入力欄を空のまま追加ボタンを押す
- Then 習慣は追加されず、入力欄は空のままである

### AC-09: 同じ名前の習慣は複数追加できない
- Given 習慣「運動」が追加されている
- When 入力欄に「運動」と入力し、追加ボタンを押す
- Then 習慣は追加されず、入力欄は空のままである

### AC-10: LocalStorageから復元される
- Given 習慣「読書」がチェック済みで保存されている
- When アプリを再度開く
- Then 習慣「読書」が表示され、チェック状態が保持されている

## 決定事項
- D1: 連続日数の計算は「昨日チェック済み、本日未チェック時点で1日」。本日チェック時は2日になる（Q1）
- D2: 空文字列の追加は許可しない。最大文字数は制限なし（Q2）
- D3: 同じ名前の習慣を複数追加できない（Q3）
- D4: 削除時は確認ダイアログを表示する（Q4）
- D5: 未チェック習慣の見分け方は自由に実装。リスト上部配置で対応（Q5）
