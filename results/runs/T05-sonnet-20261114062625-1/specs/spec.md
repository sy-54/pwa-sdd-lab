# 支出メモ 外部仕様

> 金額と分類を入力して記録を追加し、一覧（全期間・新しい順）と今月の合計を見る単一画面アプリ。
> 記録は `storage` に保存し、再読み込みや月をまたいでも一覧は残る。合計は開くたびに今月分だけ計算し直す。
> 未決事項はなし。

## 画面と操作
- `app-root` 内に単一画面。
  - 入力：`amount`（`input`。文字列で受け取り、数値として検証）、`category`（`select`。値は `food`／`daily`／`transport`／`other`、表示名は 食費／日用品／交通／その他。初期選択は `food`）、`add`（ボタン）
  - 合計：`total`（今月分の合計を表示）
  - 一覧：`expense-item` を記録ごとに表示。内部に `expense-amount`（金額）、`expense-category`（分類の表示名）、`expense-delete`（ボタン）
- 金額の表示（`expense-amount`・`total`）は数字と3桁区切りカンマのみ（例 `1,200`）。

## 振る舞い
- 初期状態：`amount` は空欄、`category` は `food`。保存済みの記録があれば一覧に表示し、`total` は今月分の合計（記録がなければ `0`）。
- 記録の保持：各記録は金額・分類・作成日時を持つ。`storage` の1つのキーに配列として保存し、追加・削除のたびに書き直す。
- 一覧は全期間の記録を対象にし、新しい記録が先頭（上）に来る順で表示する（月をまたいでも消えない）。
- `total` は現在のローカル年月に作成日時が一致する記録の金額を合計し、画面を表示するたびに計算し直す（Should の分類別合計は今回実装しない）。
- 追加：`add` を押すと `amount` を検証する。1円以上の整数なら新しい記録を作成し、一覧の先頭に加えて保存し、`amount` を空欄に戻す（`category` の選択は保持し、連続入力しやすくする）。
- 削除：`expense-delete` を押すと `ui.confirm('この記録を削除しますか？')` で確認する。OK ならその記録を一覧と保存データから取り除く。キャンセルなら何も変えない。
- 一覧が0件のときは `expense-item` を1つも表示しない（特別な案内文は出さない）。

## エラー時の挙動
- `amount` が0以下・小数・空欄・数字以外のときに `add` を押すと、記録は追加されず、`amount` の入力値も変えず、`ui.toast` でエラーを知らせる。
- 保存データが配列でない、または要素が金額・分類の形を満たさない場合は、読み込み時に記録なし（空の一覧、`total` は `0`）として扱う。

## 受け入れ条件
### AC-01: 記録を追加する
- Given `amount` に `1200`、`category` に `食費` を選んだ状態
- When `add` を押す
- Then 先頭の `expense-item` の `expense-amount` に `1,200`、`expense-category` に `食費` と表示される

### AC-02: 新しい記録が先頭に来る
- Given 金額 `1000`（食費）の記録が1件ある状態
- When `amount` に `500`、`category` に `日用品` を選んで `add` を押す
- Then 先頭の `expense-item` の `expense-amount` に `500` と表示される

### AC-03: 今月の合計
- Given 記録がない状態
- When 今月の日付で金額 `1200`（食費）と `500`（日用品）を追加する
- Then `total` に `1,700` と表示される

### AC-04: 削除する
- Given `expense-item` が1件ある状態
- When `expense-delete` を押し、`ui.confirm` で OK を選ぶ
- Then その `expense-item` が一覧から消え、`total` が削除後の値に更新される

### AC-05: 削除をキャンセルする
- Given `expense-item` が1件ある状態
- When `expense-delete` を押し、`ui.confirm` でキャンセルを選ぶ
- Then `expense-item` の件数は変わらず残る

### AC-06: 不正な金額はエラーで知らせる
- Given `amount` に `0`（または空欄・`1.5`・`abc`）を入力した状態
- When `add` を押す
- Then `expense-item` の件数は変わらず、`ui.toast` でエラーメッセージが表示される

### AC-07: 保存して再読み込みしても残る
- Given 今月の日付で金額 `1200`（食費）を追加した状態
- When ページを再読み込みする
- Then `expense-item` が1件表示され、`expense-amount` に `1,200` と表示される

### AC-08: 月が変わっても一覧は残り、合計だけ変わる
- Given 先月の日付で保存された金額 `1000` の記録のみがある状態
- When 今月の日付でアプリを開く
- Then `total` に `0` と表示され、一覧にはその記録の `expense-item` が表示される

## 決定事項
- D1: 金額は1円以上の整数のみ許可。0以下・小数・空欄・数字以外の入力で `add` を押した場合は追加せず、`ui.toast` でエラーを知らせる（Q1）
- D2: 一覧は新しい記録が先頭（上）に来る順で表示する（Q2）
- D3: Should の「分類ごとの今月の合計」は今回実装しない（Mustのみ）（Q3）
- D4: `category` の初期選択値は先頭の「食費」（`food`）（Q4）
- D5: 削除確認の文言は「この記録を削除しますか？」で固定する（Q5）
- D6: 「記録の一覧」は全期間の記録を対象にし、「今月の合計」は現在の年月の記録だけを対象にする（requirements.md で両者の表現が分かれていることから推論。削除以外に記録が消える手段はない）
