# 単語帳 外部仕様

> 表と裏のテキストを登録してカード一覧を管理し、学習では1枚ずつ表を見て覚えたか判定し、覚えるまで繰り返す。
> カードと学習状態はローカルストレージに保存され、アプリ再起動後も復元される。学習途中でアプリを閉じると一覧に戻る。
> 決定事項：ボタン無効でバリデーション、カード削除は確認なし、「1回で覚えた」は初見で一度も「まだ」を押さないカード。

## 画面と操作

### 一覧画面（初期状態）
- 表入力欄（`data-testid="card-front-input"`）：カード表のテキスト
- 裏入力欄（`data-testid="card-back-input"`）：カード裏のテキスト
- 追加ボタン（`data-testid="add-card"`）：両入力欄が埋まるまで無効
- 学習開始ボタン（`data-testid="study-start"`）：カード1枚以上で有効
- カード一覧：各カード（`data-testid="card-item"`）に表示内容（`data-testid="card-front"`）と削除ボタン（`data-testid="card-delete"`）

### 学習画面
- 表示時：学習画面（`data-testid="study-view"`）のみ、一覧画面は非表示
- 表（`data-testid="study-front"`）：現在のカード表
- 裏（`data-testid="card-back"`）：非表示（めくるまで隠す）
- めくるボタン（`data-testid="flip"`）：表から裏を表示
- 進捗（`data-testid="study-progress"`）：`記憶した枚数/全カード数` の形式
- 判定ボタン：「覚えた」（`data-testid="know"`）、「まだ」（`data-testid="again"`）

### 結果画面
- 表示時：結果画面（`data-testid="study-result"`）のみ表示
- 1回で覚えた枚数（`data-testid="result-known"`）：数字のみ
- 一覧へ戻るボタン（`data-testid="study-finish"`）

## 振る舞い

### 初期状態と保存
- アプリ起動時：ローカルストレージからカード一覧を復元。なければ空の一覧。
- カード追加：入力欄から追加、入力欄をクリア、一覧の最後に追加。ローカルストレージに保存。
- カード削除：確認ダイアログなしで即座に削除。ローカルストレージに保存。

### 学習フロー
- 学習開始：カードを学習順序で取得（追加順）。学習画面に遷移。進捗は `0/全体数`。
- めくる：ボタン押下で裏を表示。
- 判定：「覚えた」または「まだ」を押下。
  - 「覚えた」：そのカードを完了扱い。進捗に `+1`。次のカードへ。
  - 「まだ」：そのカードをキューの最後に移動。進捗変わらず。次のカードへ。
- 全カード完了：結果画面へ。「1回で覚えた枚数」を表示。
- 一覧へ戻る：学習状態をリセット（途中経過は保存しない）。一覧画面へ。

### 状態管理
- 1回で覚えた枚数：初見で「まだ」を一度も押さずに「覚えた」と判定されたカード数。
- 学習中にアプリを閉じた場合：一覧に戻る。途中経過は保存しない。次回学習開始時は最初から。

## エラー時の挙動

### 入力エラー
- 表が空：追加ボタン無効。
- 裏が空：追加ボタン無効。
- 両方空：追加ボタン無効。

### 状態エラー
- カード0枚で学習開始ボタン押下：何も起きない（ボタンは無効）。
- 学習中のカード削除：学習画面では一覧が非表示なため、操作不可。

### ストレージエラー
- ローカルストレージが満杯の場合、追加時に保存失敗。エラーをコンソールに出力。UI上の状態は、追加ボタン押下前に戻す。

## 受け入れ条件

### AC-01: カード追加（表・裏が埋まる）
- Given 一覧画面、入力欄が空
- When 表に「apple」、裏に「りんご」を入力し、追加ボタンを押す
- Then カード一覧に「apple」が表示され、入力欄は空になる

### AC-02: 追加ボタン無効（表が空）
- Given 一覧画面、表が空、裏に「text」
- When 追加ボタンを見る
- Then 追加ボタンは無効（グレーアウト）

### AC-03: 追加ボタン無効（裏が空）
- Given 一覧画面、表に「text」、裏が空
- When 追加ボタンを見る
- Then 追加ボタンは無効

### AC-04: カード削除（確認なし）
- Given 一覧画面、「apple」カードが存在
- When 「apple」カードの削除ボタンを押す
- Then 「apple」カードが一覧から消える

### AC-05: 学習開始ボタン無効（カード0枚）
- Given 一覧画面、カードが0枚
- When 学習開始ボタンを押す
- Then 何も起きない

### AC-06: 学習開始（カード1枚以上）
- Given 一覧画面、「apple/りんご」「book/本」カードが存在
- When 学習開始ボタンを押す
- Then 学習画面に遷移し、「apple」が表示、進捗は「0/2」

### AC-07: めくってから判定
- Given 学習画面、表に「apple」が表示、裏は非表示
- When めくるボタンを押す
- Then 裏に「りんご」が表示される

### AC-08: 「覚えた」で次へ
- Given 学習画面、裏が表示
- When 「覚えた」ボタンを押す
- Then 進捗が「1/2」に更新、表に「book」が表示

### AC-09: 「まだ」で繰り返し
- Given 学習画面、表に「apple」、1枚のみカードがある
- When めくる、「まだ」ボタンを押す
- Then 裏が非表示に戻り、表に「apple」が再表示

### AC-10: 全カード完了で結果画面
- Given 学習画面、全カードで「覚えた」を押した
- When 最後のカードで「覚えた」を押す
- Then 結果画面に遷移し、「2」が表示（全2枚）

### AC-11: 1回で覚えた枚数（初見で「覚えた」）
- Given 学習画面、「apple」「book」「car」カード、学習開始
- When 「apple」で「覚えた」、「book」で「まだ」、繰り返し「book」で「覚えた」、「car」で「覚えた」
- Then 結果画面で「2」が表示（apple と car のみ）

### AC-12: カード一覧へ保存
- Given 一覧画面、「apple/りんご」を追加
- When アプリを閉じて再起動
- Then 「apple」カードが残存

### AC-13: 学習途中でアプリを閉じる
- Given 学習中、1枚目で「覚えた」を押した状態
- When アプリを再起動
- Then 一覧画面に遷移、学習状態はリセット

## 決定事項
- D1: 空のカード追加はできない。追加ボタンは表・裏が両方埋まるまで無効（Q1、推奨A採用）
- D2: カード0枚では学習開始できない。ボタンは無効（Q2、A2「押しても何も起きない」を「ボタン無効」で実装）
- D3: カード削除は確認ダイアログなしで即座に削除（Q3、A3）
- D4: 学習途中でアプリを閉じた場合、一覧に戻る。途中経過は保存しない（Q4、A4）
- D5: 「1回で覚えた枚数」は、初見で「まだ」を一度も押さずに「覚えた」にしたカード数（Q5、A5）
