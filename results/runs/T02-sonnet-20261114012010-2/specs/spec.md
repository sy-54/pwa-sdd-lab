# ToDo 外部仕様

> やることを追加・完了切替・削除できるシンプルなリスト。残り件数（未完了の数）を表示する。
> 保存先はSDKのstorage領域。再読み込みしても内容が残る。
> 未決事項なし。入力検証と保存データ破損時の挙動を決定事項に明記。

## 画面と操作
- ルート要素 `data-testid="app-root"`。
- 入力欄 `data-testid="new-todo"`（テキスト入力）と追加ボタン `data-testid="add"`。
- Enterキー押下でも「追加」ボタンと同じ動作をする。
- 項目一覧：各項目は `data-testid="todo-item"`。内部に以下を持つ。
  - `data-testid="todo-text"`：やることの内容
  - `data-testid="todo-toggle"`：`input type="checkbox"`。完了状態を切り替える
  - `data-testid="todo-delete"`：削除ボタン。押すと即削除（確認なし）
- 完了済みの項目は `todo-text` に打ち消し線など見た目で区別する（CSSクラス付与）。
- 残り件数 `data-testid="todo-count"`：未完了の件数をテキスト（数字のみ）で表示。

## 振る舞い
- 初期状態：保存データがなければ項目0件、`todo-count` は `0`。
- 追加：入力欄の値の前後空白を除いた文字列が空でなければ、新しい項目（未完了）をリストの末尾に追加し、入力欄を空にする。空文字・空白のみの場合は何もしない（入力欄はそのまま）。
- 文字数の上限はなし。
- 完了切替：`todo-toggle` を操作すると、その項目の完了／未完了が反転する。
- 削除：`todo-delete` を押すとその項目を即座にリストから除去する。
- 並び順：追加した順（先入れ先出し）。並べ替え機能はない。
- 保存：追加・切替・削除の操作のたびに、全項目（内容・完了状態）をlocalStorageへ保存する。
- 復元：アプリ起動時にlocalStorageから全項目を読み込み、保存されていた順序・完了状態のまま表示する。

## エラー時の挙動
- 保存データが存在しない、または期待する形式（配列、各要素が内容と完了状態を持つ）でない場合：エラー表示はせず、空のリスト（0件）として起動する。このとき壊れていた保存データは上書きせず、次の操作（追加等）の保存時に正しい形式へ置き換わる。

## 受け入れ条件
### AC-01: やることを追加できる
- Given 入力欄が空でリストが0件
- When `new-todo` に「牛乳を買う」と入力して `add` を押す
- Then `todo-item` が1件表示され、その `todo-text` が「牛乳を買う」、`todo-count` が `1`

### AC-02: 空・空白のみの入力は追加されない
- Given リストが0件
- When `new-todo` に空白のみ（例：`"   "`）を入力して `add` を押す
- Then `todo-item` は0件のまま、`todo-count` は `0`

### AC-03: 完了・未完了を切り替えられる
- Given 「牛乳を買う」が未完了で1件ある（`todo-count` が `1`）
- When その項目の `todo-toggle` をチェックする
- Then その項目は完了状態の見た目になり、`todo-count` が `0`

### AC-04: 削除できる
- Given 項目が2件ある
- When 1件目の `todo-delete` を押す
- Then `todo-item` が1件になり、残った項目は元の2件目の内容と一致する

### AC-05: 残り件数は未完了の件数を表す
- Given 項目が3件あり、そのうち1件が完了済み
- When 画面を表示する
- Then `todo-count` が `2`

### AC-06: 再読み込みしても内容が残る
- Given 「洗濯する」を追加し完了にした状態で保存済み
- When ページを再読み込みする
- Then `todo-item` が1件表示され、その項目は完了状態、`todo-text` が「洗濯する」

### AC-07: 壊れた保存データは空リストとして起動する
- Given 保存データの形式が不正（配列でない）
- When ページを開く
- Then `todo-item` は0件、`todo-count` が `0`

## 決定事項
- D1: 空・空白のみの入力は追加しない（Q1）
- D2: `todo-count` は未完了の件数を表示する（Q2）
- D3: タイトルの文字数に上限を設けない（Q3）
- D4: 削除は確認なしの即削除（Q4）
- D5: 保存データの形式が不正な場合は空のリストとして起動する（Q5）
