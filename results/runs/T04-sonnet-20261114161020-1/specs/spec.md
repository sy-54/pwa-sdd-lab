# 習慣トラッカー 外部仕様

> 習慣を追加・削除し、今日やったかをチェックすると、連続日数が自動で表示される1画面アプリ。
> 履歴は日付の配列として保存し、連続日数は表示のたびに今日の日付から計算し直す。
> 未決事項なし。レビューではAC-05/06の連続日数の判定条件を重点的に見てほしい。

## 画面と操作
- ルート要素：`data-testid="app-root"`
- 習慣追加：入力欄 `data-testid="new-habit"`、追加ボタン `data-testid="add-habit"`
- 習慣一覧：各習慣を `data-testid="habit-item"` で表示し、追加した順（末尾に追加）に並べる
  - 習慣名：`data-testid="habit-name"`
  - 今日やったチェック：`data-testid="habit-check"`（`input type="checkbox"`）
  - 連続日数：`data-testid="habit-streak"`（数字のみのテキスト）
  - 削除ボタン：`data-testid="habit-delete"`

## 振る舞い
- 初期状態：習慣は0件。`storage` から復元できなければ0件として表示する
- 保存単位：全習慣をまとめて1つのキーに保存する。各習慣は「名前」と「チェックした日付（`YYYY-MM-DD`）の配列」を持つ。チェックボックスの状態や連続日数は保存せず、都度この配列から導く
- 追加：入力欄の値の前後空白を除いた文字列が空なら何もしない。既存の習慣名（同じく前後空白を除いた文字列）と完全一致する場合は追加しない。それ以外は新しい習慣（チェック日付0件）を一覧の末尾に追加し、入力欄を空にする
- チェック：オンにすると端末のローカル日付の「今日」をチェック日付配列に追加、オフにすると配列から取り除く。変更ごとに保存する
- 連続日数（表示のたびに「今日」から計算し直す）
  - 今日がチェック日付配列にある：今日から1日ずつ遡り、連続して配列にある日数を数える
  - 今日がなく、昨日がチェック日付配列にある：昨日から1日ずつ遡り、連続して配列にある日数を数える
  - どちらもない：0
- 見分けやすさ（Should）：今日のチェックが入っていない `habit-item` に、枠線や文字色など目立つスタイルを付ける。並び順は変えない
- 削除：`habit-delete` を押すと `ui.confirm` で確認する。OKならその習慣（名前とチェック日付）を一覧から削除して保存する。キャンセルなら何も変えない

## エラー時の挙動
- 入力欄が空または空白のみで追加ボタンを押す：一覧・保存データを変えず、エラー表示もしない
- 既存と同じ名前（前後空白を除いて完全一致）で追加ボタンを押す：一覧・保存データを変えず、エラー表示もしない。入力欄の内容はそのまま残す
- 保存データが壊れている（配列でない、要素に名前やチェック日付がない等）：その習慣は無視し、残りの読める習慣だけを表示する。保存データが全く読めない場合は0件として表示する

## 受け入れ条件
### AC-01: 習慣を追加できる
- Given 習慣が0件
- When `new-habit` に「筋トレ」と入力して `add-habit` を押す
- Then `habit-item` が1件表示され、その `habit-name` が「筋トレ」になる

### AC-02: 今日やったをチェックできる
- Given 習慣「読書」が1件あり、`habit-check` が未チェック
- When `habit-check` をチェックする
- Then `habit-check` がチェック済みになり、`habit-streak` に 1 と表示される

### AC-03: チェックを外せる
- Given 習慣「読書」の `habit-check` がチェック済みで `habit-streak` が 1
- When `habit-check` を外す
- Then `habit-check` が未チェックになり、`habit-streak` に 0 と表示される

### AC-04: 連続日数が続く
- Given 習慣があり、今日を含め3日連続でチェック済み（今日はまだチェックしていない）
- When 画面を開く
- Then `habit-streak` に 3 と表示される

### AC-05: 2日以上途切れると0になる
- Given 習慣の最後にチェックした日が2日前で、それ以降チェックしていない
- When 画面を開き直す
- Then `habit-streak` に 0 と表示される

### AC-06: 削除は確認してから行われる
- Given 習慣「散歩」が1件ある
- When `habit-delete` を押して `ui.confirm` で OK を選ぶ
- Then 「散歩」の `habit-item` が一覧から消える

### AC-07: 削除をキャンセルすると消えない
- Given 習慣「散歩」が1件ある
- When `habit-delete` を押して `ui.confirm` で キャンセル を選ぶ
- Then 「散歩」の `habit-item` が一覧に残る

### AC-08: 再読み込み後も記録が残る
- Given 習慣「読書」を追加し `habit-check` をチェックした
- When ページを再読み込みする
- Then `habit-item` に「読書」が表示され、`habit-check` がチェック済みのままになる

### AC-09: 空の入力では追加されない
- Given 習慣が0件
- When `new-habit` を空のまま `add-habit` を押す
- Then `habit-item` は0件のまま

### AC-10: 同じ名前は追加できない
- Given 習慣「筋トレ」が1件ある
- When `new-habit` に「筋トレ」と入力して `add-habit` を押す
- Then `habit-item` は1件のまま

### AC-11: 未チェックの習慣が見分けやすい
- Given 習慣「読書」の `habit-check` が未チェック
- When 画面を開く
- Then 「読書」の `habit-item` に未チェック用の目立つスタイル（クラスなど）が付いている

## 決定事項
- D1: 連続日数は、最後にチェックした日が今日または昨日のときだけ、そこから遡って数える。今日も昨日もチェックがなければ0（Q1）
- D2: 削除は `ui.confirm` で確認してから行う（Q2）
- D3: 入力欄が空のまま追加しても、エラー表示はしない（Q3）
- D4: 同じ名前（前後空白を除き完全一致）の習慣は追加できない。エラー表示はしない（Q4）
- D5: 今日未チェックの習慣は目立つスタイルを付け、並び順は変えない（Q5）
